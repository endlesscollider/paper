# 灵巧手方案综述：从欠驱动到全驱动

> **为什么要读这篇**：灵巧操作是机器人学习领域最热门的方向之一，而灵巧手的硬件设计直接决定了你能做什么样的任务、能用什么样的算法。这篇文章系统梳理：灵巧手有哪些主流方案、各自怎么驱动、自由度怎么分配、指尖感知怎么做，以及开源方案的成本和可复现性。

## 0. 为什么灵巧手这么难

人手有 **27 个自由度**（4 指各 4 DoF + 拇指 5 DoF + 腕部 2~3 DoF），**17000+ 个触觉感受器**，能执行从穿针引线到大力抓握的全谱操作。要在机器人上复现这种能力，面临三大挑战：

1. **机械挑战**：在手掌大小的空间里塞进 16~24 个独立驱动的关节
2. **感知挑战**：指尖需要高分辨率的触觉反馈（力、滑移、接触几何）
3. **控制挑战**：高维动作空间（16~24 维）+ 接触动力学极其复杂

本文聚焦前两个（硬件问题），控制问题留给算法文章。

## 1. 灵巧手的核心设计维度

### 1.1 自由度（DoF）设计

| 方案 | DoF 数 | 代表产品 | 设计理念 |
|------|--------|---------|----------|
| 简单夹爪 | 1~2 | Robotiq 2F-85 | 只做抓/放，不做操作 |
| 欠驱动手 | 5~10 | Yale OpenHand, Robotiq 3-Finger | 少量电机通过机械耦合驱动多关节 |
| 中等 DoF | 12~16 | Allegro Hand, LEAP Hand | 每指 3~4 个独立 DoF |
| 高 DoF | 20~24 | Shadow Dexterous Hand | 接近人手的完整自由度 |

**关键概念——欠驱动 vs 全驱动**：

- **全驱动（Fully Actuated）**：每个关节都有独立的驱动器。能独立控制每个关节角度 → 可以做精细操作（如旋转螺丝、翻转物体）
- **欠驱动（Under-Actuated）**：驱动器数量 < 关节数量。一根腱绳同时驱动一根手指的三个关节 → 只能控制"抓紧/松开"，不能独立控制每个指节

**对 RL 的影响**：全驱动手的动作空间维度 = 自由度数量，策略需要输出更高维的 action。欠驱动手的动作空间小（如 5 维=每指一个抓力），但能完成的任务有限。

### 1.2 驱动方式

灵巧手最核心的工程难题：**怎么在手掌大小的空间里驱动 16+ 个关节**。

三种主要方案：

#### 方案 A：腱绳驱动（Tendon-Driven）

**原理**：电机放在前臂（或手掌底座），通过钢丝/线缆（腱绳）远程拉动手指关节。类似人手的肌腱结构。

```mermaid
flowchart LR
    M["电机<br/>（在前臂）"] -->|腱绳| P["滑轮/导向"] -->|腱绳| J["手指关节"]
```

**优点**：
- 手指本身可以非常轻薄（不含电机）
- 驱动力大（多圈绕线+大电机）
- 手指惯量极小→高速操作

**缺点**：
- 腱绳松弛/磨损→需要维护
- 绳路复杂→装配困难
- 标定和建模困难（绳的弹性、摩擦）
- 非线性传动→力控精度受限

**代表**：Shadow Dexterous Hand、Robonaut 2 Hand、Stanford Model O

#### 方案 B：连杆直驱（Link-Driven / Gear-Driven）

**原理**：每个关节里直接放一个微型电机+减速器，通过齿轮或连杆传动。

**优点**：
- 传动关系简单明确——电机角度直接对应关节角度
- 无绳索松弛问题
- 力控线性度好
- 维护简单

**缺点**：
- 手指体积大（要塞电机进去）
- 手指重量大→惯量大→高速操作困难
- 空间限制了电机尺寸→扭矩有限

**代表**：Allegro Hand、LEAP Hand、Ability Hand

#### 方案 C：气动/液压（Pneumatic / Hydraulic）

**原理**：用气压或液压驱动人工肌肉或活塞来弯曲手指。

**优点**：
- 出力大
- 天然柔顺（气体可压缩→被动力限制）
- 轻量化

**缺点**：
- 需要气泵/液压源→系统体积大
- 控制精度差（气体压缩性→位置不精确）
- 响应慢
- 漏气/漏油问题

**代表**：RBO Hand 2（柏林工大）、一些软体手

**总结**：目前学术界的主流是**连杆直驱**（工程简单、可复现性好）和**腱绳驱动**（性能上限高但工程复杂）。气动方案在研究软体操作时使用，但不适合需要精确控制的场景。

## 2. 主流商用灵巧手详解

### 2.1 Allegro Hand（Wonik Robotics）

| 项目 | 参数 |
|------|------|
| DoF | 16（4 指 × 4 关节） |
| 驱动方式 | 连杆直驱（每关节一个无刷电机） |
| 电机 | 定制微型 BLDC |
| 控制接口 | CAN 总线，333 Hz 位置/力矩控制 |
| 指尖传感 | 无（需外加） |
| 重量 | 1.1 kg |
| 价格 | ~$15,000~$20,000 |

**特点**：
- 学术界使用最广泛的灵巧手
- 4 指设计（无小指），拇指对掌
- 每个关节独立力矩控制→适合 RL 研究
- OpenAI 的 Rubik's Cube 论文就是用 Allegro Hand 的定制版

**局限**：
- 没有触觉传感器（需要自己加 BioTac 或其他方案）
- 关节速度较慢（适合精细操作，不适合快速抓取）
- 无法做指尖滚动操作（指尖是硬壳）

### 2.2 Shadow Dexterous Hand（Shadow Robot）

| 项目 | 参数 |
|------|------|
| DoF | 24（5 指 + 腕部） |
| 驱动方式 | 腱绳驱动（40 根腱绳 by 20 个电机） |
| 电机 | 无刷电机，位于前臂壳体内 |
| 控制接口 | EtherCAT，1 kHz |
| 指尖传感 | 可选 BioTac（额外费用） |
| 重量 | 4.2 kg（含前臂） |
| 价格 | ~$100,000+ |

**特点**：
- 最接近人手的商用灵巧手
- DoF 最多，可做几乎所有人手动作
- OpenAI 早期的 in-hand manipulation 研究使用

**局限**：
- 极其昂贵
- 腱绳维护成本高（需要定期更换、调张力）
- 体积大（需要前臂空间装电机）
- 可靠性挑战（绳断→整指失效）

### 2.3 Ability Hand（PSYONIC）

| 项目 | 参数 |
|------|------|
| DoF | 6（独立驱动） + 10（耦合/欠驱动） |
| 驱动方式 | 微型无刷电机 + 行星减速器 |
| 控制接口 | UART/USB，最高 300 Hz |
| 指尖传感 | 内置压力传感器（每指 1 个） |
| 重量 | 0.5 kg |
| 价格 | ~$10,000（研究版） |

**特点**：
- 原为假肢设计，兼顾抓握力和灵巧性
- 每指有独立的卷/展和屈/伸，拇指对掌
- 尺寸接近真人手
- 相对便宜且耐用

**局限**：
- 不是完全全驱动——部分关节耦合
- 控制频率偏低
- 触觉精度有限（不是高分辨率触觉）

### 2.4 Inspire Hand（因时机器人）

| 项目 | 参数 |
|------|------|
| DoF | 6（每指 1 个弯曲 + 拇指对掌） |
| 驱动方式 | 直线电机 + 连杆 |
| 控制接口 | RS-485, 最高 100 Hz |
| 指尖传感 | 无 |
| 重量 | 0.54 kg |
| 价格 | ~¥20,000~¥50,000 |

**特点**：
- 国产方案，性价比高
- 主要用于简单抓握（不追求指尖操作）
- 多个国内机器人团队使用

**局限**：
- DoF 太少，不支持精细 in-hand manipulation
- 主要是"夹爪+的升级版"而非真正灵巧手

## 3. 开源灵巧手方案（可复现）

### 3.1 LEAP Hand（CMU, 2023）

**论文**：*LEAP Hand: Low-Cost, Efficient, and Anthropomorphic Hand for Robot Learning*

| 项目 | 参数 |
|------|------|
| DoF | 16（4 指 × 4 关节） |
| 驱动方式 | **连杆直驱**（Dynamixel XC330 舵机） |
| 电机 | Dynamixel XC330-M288-T（无刷，位置+电流模式） |
| 控制接口 | USB/RS-485，~20 Hz（位置模式） |
| 指尖传感 | 无（但留有安装空间） |
| 总成本 | **~$2,000**（纯硬件，不含臂） |
| 开源 | ✅ CAD + 装配说明 + 控制代码全部开源 |

**设计亮点**：
- **全 3D 打印结构**——不需要任何 CNC 加工
- 使用廉价的 Dynamixel 舵机，可全球购买
- 布局受 Allegro 启发但成本降低 10 倍
- 已被多个 RL 研究组复现（CMU Dexterous Group、UC Berkeley 等）

**机械结构**：

```mermaid
flowchart TD
    subgraph 一根手指（4 DoF）
        MCP_AA["MCP 侧摆<br/>Dynamixel #1"] --> MCP_FE["MCP 屈伸<br/>Dynamixel #2"]
        MCP_FE --> PIP["PIP 屈伸<br/>Dynamixel #3"]
        PIP --> DIP["DIP 屈伸<br/>Dynamixel #4"]
    end
```

每个关节是一个独立的 Dynamixel 舵机，通过 3D 打印连杆直接驱动。优势是系统可靠——没有绳索松弛问题，坏了换一个舵机就行。

**局限**：
- Dynamixel XC330 的通信频率受限（总线上 16 个舵机时约 20~30 Hz）
- 力矩较小（XC330 额定 0.6 N·m）→ 大力抓握受限
- 无触觉传感

### 3.2 Faive Hand（Fai Robotics / 东京大学, 2023）

| 项目 | 参数 |
|------|------|
| DoF | 16 |
| 驱动方式 | **腱绳驱动**（电机在手背/手腕） |
| 电机 | 微型舵机 |
| 特色 | 拇指有 4 DoF 对掌能力 |
| 总成本 | ~$1,000~$2,000 |
| 开源 | ✅ 部分开源 |

**特点**：腱绳方案但成本极低。手指非常轻薄，惯量小，适合高速操作。Stanford 的一些灵巧操作工作用了类似方案。

### 3.3 Dexhand（开源社区）

| 项目 | 参数 |
|------|------|
| DoF | 20 |
| 驱动方式 | 腱绳驱动 |
| 总成本 | < $1,000 |
| 开源 | ✅ 完全开源 |

**特点**：社区驱动的低成本方案，追求人手级别的 DoF。适合研究但工程成熟度较低。

### 3.4 开源方案对比

| 方案 | DoF | 驱动 | 成本 | 成熟度 | 控制频率 | RL 友好度 |
|------|-----|------|------|--------|----------|-----------|
| LEAP Hand | 16 | 直驱 | $2,000 | ★★★★ | 20~30 Hz | ★★★ |
| Faive Hand | 16 | 腱绳 | $1,500 | ★★★ | ~50 Hz | ★★★ |
| Dexhand | 20 | 腱绳 | $800 | ★★ | 不确定 | ★★ |

**推荐**：如果你是做 RL 研究、需要可复现的灵巧手，**LEAP Hand 是目前的最佳选择**——成熟、可靠、社区活跃、有大量已发表论文验证。

## 4. 指尖感知：触觉传感

灵巧操作离不开触觉反馈。没有触觉，手指不知道"有没有碰到东西"、"东西在不在滑"、"抓力够不够"。

### 4.1 触觉传感器类型

| 类型 | 原理 | 代表产品 | 分辨率 | 优点 | 缺点 |
|------|------|---------|--------|------|------|
| 电阻式 | 压力改变导电材料电阻 | FSR 薄膜传感器 | 低（单点力） | 便宜、耐用 | 只测法向力，无空间分辨率 |
| 电容式 | 压力改变极板间距→电容变化 | — | 中~高 | 灵敏度高 | 布线复杂、EMI 敏感 |
| 视触觉 | 摄像头拍摄弹性体变形 | **GelSight**, DIGIT, Taxim | **极高** | 力+几何+滑移全能测 | 体积较大、需图像处理 |
| 压电/PVDF | 形变产生电荷 | BioTac（已停产） | 高 | 动态响应好 | 贵、不易集成 |
| 磁感应式 | 磁体位移改变霍尔信号 | Reskin, AnySkin | 中~高 | 薄、柔性 | 标定复杂 |

### 4.2 GelSight / DIGIT：视触觉传感器

**原理**：
1. 手指表面覆盖一层弹性凝胶
2. 凝胶背面涂有反光涂层
3. LED 从不同方向照亮凝胶背面
4. 微型摄像头从内部拍摄凝胶表面的变形

**能测什么**：
- 接触面的三维几何形状（凹凸纹理）
- 法向力分布
- 切向力（通过凝胶的侧向变形）
- 滑移检测

**优势**：一个传感器同时获得力、几何、滑移三类信息，且空间分辨率极高（相机像素级别）。

**在 RL 中的应用**：很多灵巧操作论文把 GelSight/DIGIT 的图像直接作为 observation 输入 CNN → 策略可以学习基于触觉的操作（如判断抓稳了没有、物体在没在旋转）。

### 4.3 AnySkin / ReSkin：磁感应触觉

**原理**：
1. 在弹性皮肤中嵌入小磁体
2. 皮肤下方有磁力计阵列（如 MLX90393）
3. 外力使皮肤变形→磁体位移→磁力计读数变化

**优势**：
- 极薄（< 3mm），可贴合曲面
- 可更换皮肤（磨损后换一块新的）
- 成本低（~$10/片）

**局限**：
- 空间分辨率不如视触觉
- 需要标定（磁场-力的映射因个体差异而不同）

## 5. 灵巧手的 RL 接口设计

从算法角度看，灵巧手就是一个**高维动作空间**。接口设计直接影响训练效率。

### 5.1 Action Space 的常见选择

| Action Space | 维度（16 DoF 手） | 说明 |
|-------------|-------------------|------|
| 关节位置 | 16 | 目标角度，舵机/驱动器自行伺服 |
| 关节位置增量 | 16 | 当前角度 + delta |
| 关节速度 | 16 | 目标角速度 |
| 关节力矩 | 16 | 目标扭矩 |
| 指尖位置 (IK) | 12（4指×3D） | 逆运动学计算关节角 |

**经验**：
- **位置增量（delta position）** 是目前最常用的 action space——训练稳定、sim-to-real gap 小
- 力矩 action 理论上最灵活，但训练难度大（需要精确的动力学模型）
- 指尖位置可以降维但丢失了一些细节控制

### 5.2 Observation Space

| 信息 | 维度 | 来源 |
|------|------|------|
| 关节位置 | 16 | 编码器 |
| 关节速度 | 16 | 编码器微分 |
| 关节力矩（可选） | 16 | 电流反馈 |
| 指尖触觉（可选） | N × (力/图像) | 触觉传感器 |
| 物体位置/姿态（可选） | 7 (xyz + quat) | 相机/动捕 |
| 腕部力/力矩（可选） | 6 | 六维力传感器 |

### 5.3 控制频率对训练的影响

- **仿真中**：通常 20~50 Hz（物理步长更小但 action 不需要那么频繁）
- **真机 LEAP Hand**：受 Dynamixel 通信限制，约 20~30 Hz
- **真机 Allegro**：333 Hz（CAN 总线）→ 策略可以更高频，但通常 20~50 Hz 推理+插值

**频率越高**，策略越能做精细的力调节；**频率越低**，策略需要预测更长的未来 → 通常用 action chunking 弥补。

## 7. 近年趋势与展望

1. **开源生态爆发**：LEAP Hand 带动了一批低成本可复现方案。未来会有更多 sub-$1000 的全驱动灵巧手出现。

2. **视触觉传感成为标配**：DIGIT/GelSight 的成本已降到 $100/指量级，越来越多方案默认集成触觉。

3. **学习驱动的设计**：传统灵巧手设计基于运动学优化，新趋势是"硬件-算法协同设计"——根据 RL 训练的难易程度来选择 DoF 配置和传感布局。

4. **腱绳 vs 直驱的融合**：Model O（Stanford）等新设计试图结合两者优点——核心关节直驱保证可靠性，附加关节腱绳保证轻量化。

5. **人形手的商业化**：随着人形机器人热潮（Figure、Tesla Bot、Unitree H1），灵巧手从纯学术走向商业量产，成本有望快速下降。

## 8. 总结

| 维度 | 关键结论 |
|------|---------|
| 驱动方式 | 连杆直驱最可靠可复现，腱绳性能上限高但工程难度大 |
| DoF 选择 | 16 DoF 是 RL 研究的甜蜜点——足够做 in-hand manipulation，又不至于维度爆炸 |
| 触觉 | 视触觉（GelSight/DIGIT）是分辨率和信息量的最优解 |
| 推荐入门 | LEAP Hand（$2,000 + 全开源 + 社区活跃） |
