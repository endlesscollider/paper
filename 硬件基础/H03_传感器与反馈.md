# 传感器与反馈：编码器、力传感器、触觉

> **为什么要读这篇**：没有传感器，机器人就是"瞎子"——电机不知道转到了哪里，手指不知道碰到了什么，控制器不知道输出了多少力。这篇文章系统梳理机器人关节和末端最常用的三类传感器：位置编码器、力/力矩传感器、触觉传感器。

## 1. 位置编码器：电机转了多少

### 1.1 为什么需要编码器

[电机驱动与控制](/硬件基础/H02_电机驱动与控制)中讲到，FOC 算法需要**实时知道转子角度**才能做 Park 变换；位置环需要知道当前角度才能伺服。编码器就是提供这个信息的传感器。

### 1.2 增量式编码器（Incremental Encoder）

**原理**：光栅盘上有均匀刻痕。光源穿过刻痕，光电传感器检测到明暗交替→产生脉冲信号。数脉冲数就知道转了多少。

**特点**：
- 输出：A/B 两路正交脉冲（可判断方向）+ Z 零位脉冲
- 分辨率：500~10000 线/圈（×4 细分后 2000~40000 脉冲/圈）
- **上电后不知道绝对位置**——需要先回零

**应用**：工业伺服电机标配。

### 1.3 绝对式编码器（Absolute Encoder）

**原理**：编码盘上的图案对应唯一角度值（如格雷码或正弦/余弦信号）。上电即知道当前角度，无需回零。

**两种主流类型**：

| 类型 | 原理 | 分辨率 | 优点 | 缺点 |
|------|------|--------|------|------|
| 光学式 | 光栅+光电检测 | 极高（17~23 bit） | 精度最好 | 怕灰尘、成本高 |
| **磁编码器** | 旋转磁铁+霍尔/磁阻传感器 | 12~14 bit | 便宜、抗污染、小巧 | 精度略低 |

**机器人关节中的主流**：**磁编码器**（如 AS5047P、AS5600）。价格 ¥5~30，分辨率 14 bit（16384 步/圈 ≈ 0.022°），对机器人关节完全够用。

### 1.4 编码器安装位置

| 安装位置 | 含义 | 优缺点 |
|---------|------|--------|
| 电机轴（减速器前） | 测的是电机转过的角度 | 高分辨率（乘以减速比后关节精度很高），但不含减速器间隙 |
| 关节输出轴（减速器后） | 测的是关节实际角度 | 包含了间隙影响→更真实，但分辨率要求更高 |
| **两侧都装** | 双编码器方案 | 可以同时精确定位+补偿间隙（Franka 就是这么做的） |

## 2. 力/力矩传感器

### 2.1 六维力/力矩传感器（6-Axis F/T Sensor）

**测什么**：三个方向的力 ($F_x$, $F_y$, $F_z$) + 三个方向的力矩 ($M_x$, $M_y$, $M_z$)。

**原理**：弹性体（金属块）上贴应变片。外力使弹性体微小变形→应变片电阻变化→通过惠斯通电桥测量→标定矩阵换算为 6 维力/力矩。

**典型产品**：

| 产品 | 量程 | 分辨率 | 频率 | 价格 |
|------|------|--------|------|------|
| ATI Mini45 | Fx/Fy ±290N, Fz ±580N | 0.06 N | 7 kHz | ~¥5~8 万 |
| OnRobot HEX-E | ±200 N | 0.2 N | 1 kHz | ~¥2~3 万 |
| 坤维 KWR75 | ±500 N | 0.1 N | 1 kHz | ~¥1~2 万 |

**安装位置**：通常装在机械臂末端法兰和工具之间（"腕力传感器"）。

**用途**：
- 力控装配（检测接触力并调整运动）
- 碰撞检测（力突变→停止）
- 遥操作力反馈
- RL 的 observation（末端接触力）

### 2.2 关节力矩传感器

**原理**：与六维力传感器类似，但只测一个方向的扭矩（关节轴方向）。安装在减速器输出端。

**代表**：Franka 每个关节内置的力矩传感器。

**优势**：可以测量每个关节上的外部扭矩→不用末端力传感器就能做碰撞检测和力控。

### 2.3 电流估计力矩（无传感器方案）

如果没有力矩传感器，可以通过电机电流反推力矩：

$$
\tau_{\text{ext}} \approx K_t \cdot i_q \cdot N \cdot \eta - \tau_{\text{gravity}} - \tau_{\text{friction}}
$$

**这个公式在做什么**：通过测量电机电流，减去已知的重力和摩擦补偿，估算外部施加在关节上的力矩。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 | 说明 |
|------|------|------|
| $\tau_{\text{ext}}$ | 外部力矩估计 | 碰撞/接触产生的扭矩 |
| $K_t$ | 电机扭矩常数 | N·m/A |
| $i_q$ | q 轴电流 | FOC 测量值 |
| $N$ | 减速比 | 电机扭矩×N = 关节扭矩 |
| $\eta$ | 传动效率 | 摩擦损失 |
| $\tau_{\text{gravity}}$ | 重力力矩 | 由动力学模型算出 |
| $\tau_{\text{friction}}$ | 摩擦力矩 | 需要辨识 |

**数值代入**：$K_t = 0.05$, $i_q = 3$ A, $N = 50$, $\eta = 0.8$, $\tau_{\text{gravity}} = 2.0$ N·m, $\tau_{\text{friction}} = 0.3$ N·m：

$$
\tau_{\text{ext}} = 0.05 \times 3 \times 50 \times 0.8 - 2.0 - 0.3 = 6.0 - 2.3 = 3.7\text{ N·m}
$$

**局限**：这种估计精度受限于摩擦模型的准确性。谐波减速器摩擦大且非线性→估计误差大。准直驱方案摩擦小→电流估力更准确。

**为什么是这个形式**：牛顿第二定律在旋转系统上的应用。关节扭矩 = 电机输出扭矩 - 重力 - 摩擦 - 外部扭矩。知道前三项就能反推第四项。
:::

## 3. 触觉传感器

触觉传感器的详细分类和原理已在 [灵巧手方案综述](/硬件基础/H05_灵巧手方案综述#4-指尖感知触觉传感) 中介绍。这里补充一些通用信息：

### 3.1 选型建议

| 你的需求 | 推荐方案 | 理由 |
|---------|---------|------|
| 简单接触检测 | FSR 薄膜 (¥5~20/个) | 便宜耐用，判断"碰没碰" |
| 抓握力控制 | 电容式阵列 | 可测力分布 |
| 精细操作 + 滑移检测 | GelSight / DIGIT | 信息量最大 |
| 全手覆盖 | AnySkin / ReSkin | 薄膜+可更换 |
| 高频动态力 | PVDF 压电薄膜 | 响应快，适合检测振动/滑移 |

## 4. 总结

| 传感器类型 | 测什么 | 安装在哪 | 对控制的贡献 |
|-----------|--------|---------|-------------|
| 磁编码器 | 关节角度 | 电机轴 / 输出轴 | 位置环 + FOC |
| 六维力传感器 | 末端力/力矩 | 腕部法兰 | 力控 + 碰撞检测 |
| 关节力矩传感器 | 单关节扭矩 | 减速器后 | 碰撞检测 + 精确力控 |
| 触觉传感器 | 接触力/几何/滑移 | 指尖/手掌 | 灵巧操作 |
| 电流传感器 | 相电流 | 驱动板 | FOC + 无传感器力估计 |
