# DoRA: Weight-Decomposed Low-Rank Adaptation

> **论文信息**：Liu et al., ICML 2024  
> **一句话概括**：将权重矩阵分解为**方向分量（direction）**和**幅度分量（magnitude）**，用 LoRA 只适配方向，用独立的标量向量适配幅度——让 PEFT 的学习模式更接近全参数微调，效果系统性优于 LoRA。

**相关阅读**：
- [LoRA 低秩适配基础](/前置知识/000x_前置知识_LoRA低秩适配基础) — LoRA 原理
- [LoRA 原始论文精读](./055_LoRA_低秩适配微调大模型) — LoRA 的技术细节与局限

---

## 贯穿全文的例子

> 微调 LLaMA-7B 做常识问答。
>
> **LoRA 的行为**：$\Delta W = BA$ 同时改变了权重的方向和大小，且这两种改变耦合在一起。
>
> **DoRA 的行为**：
> - 方向改变：由 LoRA 部分的 $BA$ 负责（通过归一化提取方向）
> - 幅度改变：由独立的可学习向量 $m$ 负责
>
> 这种解耦让学习更高效——模型可以独立地决定"朝哪个方向调"和"调多大幅度"。

## 一、论文动机

### 1.1 一个关键观察：全参数微调如何改变权重？

论文首先分析了全参数微调时，权重变化 $\Delta W$ 的特征。他们将权重分解为**方向**和**幅度**两个分量（类似 Weight Normalization 的分解）：

$$
W = m \cdot \frac{V}{\|V\|_c}
$$

**这个公式在做什么**：把一个权重矩阵拆成"方向"和"幅度"两个独立部分——$V/\|V\|_c$ 只负责指向哪个方向，$m$ 只负责缩放多大，两者可以分别研究、分别优化。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $V \in \mathbb{R}^{d\times k}$ | **原始权重（未归一化）** | 权重矩阵本身，同时混着方向和大小信息 |
| $\|V\|_c$ | **列长度计算器** | 按列算 L2 范数，得到 $\mathbb{R}^{1\times k}$ 的标量向量，每列一个"长度" |
| $V/\|V\|_c$ | **纯方向** | 每一列都除以自己的长度，变成单位向量——只保留"指向哪"，丢掉"多长" |
| $m \in \mathbb{R}^{1\times k}$ | **幅度旋钮** | 每列一个缩放因子，决定这一列最终有多"长" |

**用人话读**："权重 = 方向盘（指向哪个方向）× 油门（踩多深）——把这两件事拆成两个独立的东西分别控制。"

**为什么是这个形式**：这是 Weight Normalization 的标准分解方式（除以自身范数得到单位方向，再乘一个独立标量控制长度），DoRA 借用这个分解去分析全参数微调的变化模式。
:::

其中：
- $V \in \mathbb{R}^{d \times k}$：方向矩阵（未归一化的权重）
- $\|V\|_c$：按列计算的 L2 范数，$\|V\|_c \in \mathbb{R}^{1 \times k}$（每列一个标量）
- $m \in \mathbb{R}^{1 \times k}$：幅度向量（每列一个缩放因子）

**全参数微调时的变化模式**：
论文统计了预训练到微调的变化中，方向变化量和幅度变化量的关系：

| 分析维度 | 全参数微调 | LoRA |
|---------|-----------|------|
| 方向变化幅度 | 较大、平滑 | 较大、方差大 |
| 幅度变化幅度 | 较小、平滑 | 与方向变化**强相关** |
| 方向-幅度相关性 | **弱**（近乎独立） | **强**（耦合） |

**关键发现**：
> 全参数微调中，方向变化和幅度变化是**近似独立**的——模型分别学习"往哪调"和"调多少"。  
> 但 LoRA 中，由于 $\Delta W = BA$ 同时影响两者，方向和幅度的变化被**耦合在一起**，限制了学习效率。

### 1.2 Weight Normalization 的启发

Weight Normalization (Salimans & Kingma, 2016) 是一种经典的参数化技巧：

$$
W = g \cdot \frac{V}{\|V\|}
$$

**这个公式在做什么**：Weight Normalization 的原始形式——用一个标量 $g$ 单独控制整个权重矩阵的整体幅度，方向完全交给归一化后的 $V$。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $V$ | **原始权重矩阵** | 参数化时实际学习的矩阵，未归一化 |
| $\|V\|$ | **整体范数** | 对整个矩阵算一个标量范数（不像 DoRA 是按列算） |
| $V/\|V\|$ | **单位方向矩阵** | 归一化后长度固定为 1，只保留方向信息 |
| $g$ | **全局幅度旋钮** | 一个标量，控制整个矩阵的缩放大小 |

**用人话读**："把权重矩阵拆成一个方向矩阵（长度归一化为 1）和一个标量幅度，分别优化。"

**为什么是这个形式**：直接对权重矩阵梯度下降时，方向和长度的梯度会互相纠缠，拆开后优化景观更平滑，这是 Weight Normalization（Salimans & Kingma, 2016）的原始动机——DoRA 正是把这一思想借用到 LoRA 上。
:::

将标量 $g$（幅度）和矩阵 $V$（方向）分开优化，可以加速训练收敛。

DoRA 的核心 Insight：**把 Weight Normalization 的思想应用到 LoRA 上**——用 LoRA 适配方向，用独立参数适配幅度。

## 二、方法详解

### 2.1 完整公式

DoRA 将预训练权重 $W_0$ 分解为方向和幅度：

$$
W_0 = m_0 \cdot \frac{V_0}{\|V_0\|_c}
$$

**这个公式在做什么**：把预训练权重 $W_0$ 本身也做一次方向-幅度分解，作为后续 LoRA 适配的起点。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $W_0$ | **预训练权重** | 微调开始前，模型已经训练好的原始权重矩阵 |
| $V_0$ | **预训练方向矩阵** | 数值上等于 $W_0$ 本身（分解只是记号上的拆分，不改变数值） |
| $\|V_0\|_c$ | **预训练列范数** | 每列的 L2 范数 |
| $m_0 = \|W_0\|_c$ | **预训练幅度** | 初始幅度向量，直接等于 $W_0$ 的列范数 |

**用人话读**："预训练权重也可以看成'单位方向 × 幅度'的乘积，只是这里的方向和幅度都直接取自 $W_0$ 本身，什么都没变。"

**为什么是这个形式**：这一步是为 2.1 节 DoRA 的更新公式做准备——只有先把 $W_0$ 表示成方向×幅度的形式，才能说清楚"哪个部分交给 LoRA 学、哪个部分交给独立向量学"。
:::

其中 $m_0 = \|W_0\|_c$（预训练权重各列的 L2 范数）。

然后用 LoRA 适配方向部分：

$$
W' = m \cdot \frac{V_0 + \Delta V}{\|V_0 + \Delta V\|_c} = m \cdot \frac{V_0 + BA}{\|V_0 + BA\|_c}
$$

**这个公式在做什么**：这是 DoRA 的核心更新公式——用 LoRA（$BA$）修改方向，用独立的幅度向量 $m$ 重新缩放，两件事分开做。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $V_0 + BA$ | **修正后的方向候选** | 在预训练方向基础上叠加 LoRA 学到的方向修正 |
| $\|V_0+BA\|_c$ | **修正后列长度** | 算出叠加后每列的新长度，用来归一化 |
| $\frac{V_0+BA}{\|V_0+BA\|_c}$ | **提纯后的方向** | 只保留"指向哪"，把 $BA$ 带来的幅度变化过滤掉 |
| $m$ | **独立幅度控制器** | 单独学习的缩放向量，不受方向部分变化的干扰 |

**用人话读**："先让 LoRA 修改方向、算出新方向，再用一个完全独立的幅度向量重新决定缩放多大——方向和幅度两件事互不干扰。"

**为什么是这个形式**：直接用 $W_0+BA$（标准 LoRA）会让方向和幅度同时被 $BA$ 影响，耦合在一起；DoRA 先归一化掉 $BA$ 带来的幅度变化，再用独立的 $m$ 控制幅度，从而复现全参数微调中"方向-幅度近似独立"的模式（1.1 节的发现）。
:::

其中：
- $m \in \mathbb{R}^{1 \times k}$：**可学习的幅度向量**，初始化为 $m_0 = \|W_0\|_c$
- $\Delta V = BA$：**LoRA 适配的方向变化**
- $\frac{V_0 + BA}{\|V_0 + BA\|_c}$：归一化保证只改变方向

**逐项理解**：
1. $V_0 + BA$：在预训练方向基础上加上 LoRA 学到的方向修正
2. $\frac{V_0 + BA}{\|V_0 + BA\|_c}$：归一化到单位方向（按列归一化）
3. $m \cdot (\cdots)$：用独立的幅度向量重新缩放

### 2.3 参数量分析

DoRA 相比标准 LoRA 只多了一个幅度向量 $m \in \mathbb{R}^{1 \times k}$：

| 组件 | 参数量 |
|------|--------|
| 标准 LoRA | $dr + rk$ |
| DoRA | $dr + rk + k$ |
| 额外开销 | $k$（仅一个向量！） |

以 $d=k=4096$, $r=16$ 为例：
- LoRA 参数：$4096 \times 16 + 16 \times 4096 = 131,072$
- DoRA 额外：$4096$
- **额外开销占比**：$\frac{4096}{131072} = 3.1\%$ → 几乎可忽略

### 2.4 初始化

- **$A, B$**：与标准 LoRA 相同（$B=0$, $A$ 随机初始化）
- **$m$**：初始化为 $m_0 = \|W_0\|_c$（预训练权重各列的 L2 范数）

这确保了训练起点与预训练模型完全相同：
$$
W'|_{B=0} = m_0 \cdot \frac{V_0 + 0}{\|V_0\|_c} = \|W_0\|_c \cdot \frac{W_0}{\|W_0\|_c} = W_0 \quad \checkmark
$$

**这个公式在做什么**：验证初始化的正确性——在训练刚开始（$B=0$）时，DoRA 的公式必须精确还原出原始的预训练权重 $W_0$，不能有任何偏差。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $B=0$ | **训练起点** | LoRA 标准初始化，$B$ 矩阵全零 |
| $V_0+0$ | **方向不变** | $B=0$ 时 $BA=0$，方向矩阵退化回 $V_0$ 本身 |
| $m_0\cdot\frac{V_0}{\|V_0\|_c}$ | **代入初始幅度** | 用初始化好的 $m_0=\|W_0\|_c$ 代入 |
| $=W_0$ | **验证结果** | 化简后精确等于预训练权重，说明训练起点没有引入任何偏差 |

**用人话读**："在 $B=0$ 的初始状态下，把所有公式代入化简，结果正好等于原始预训练权重——说明 DoRA 的初始化和标准 LoRA 一样，训练一开始不会改变模型行为。"

**为什么要验证这一步**：任何参数高效微调（PEFT）方法都要求"训练起点 = 预训练模型"，否则相当于还没训练就已经改变了模型行为。这个恒等式就是 DoRA 满足这一要求的证明。
:::

### 2.5 梯度计算

DoRA 的前向传播涉及归一化操作，需要特别注意梯度流：

$$
\frac{\partial W'}{\partial B} = m \cdot \frac{\partial}{\partial B}\left[\frac{V_0 + BA}{\|V_0 + BA\|_c}\right]
$$

**这个公式在做什么**：算出 DoRA 前向传播对参数 $B$ 的梯度，暴露出"归一化"这一步会怎样改变梯度的方向。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\frac{\partial W'}{\partial B}$ | **待求梯度** | 反向传播时需要算出的、$W'$ 对 $B$ 的导数 |
| $m\cdot(\cdot)$ | **幅度部分照常提出** | $m$ 不依赖 $B$，可以直接提到求导符号外面 |
| $\frac{\partial}{\partial B}\left[\frac{V_0+BA}{\|V_0+BA\|_c}\right]$ | **归一化项的梯度** | 真正复杂的部分——对"矩阵除以自身范数"求导 |

**用人话读**："$W'$ 对 $B$ 的梯度，等于幅度 $m$ 乘以'归一化后的方向'对 $B$ 的梯度——后者的具体形式类似 Layer Normalization 的梯度。"

**为什么要单独强调这一步**：归一化操作的梯度会自动"投影掉"当前方向上的分量（后文解释类似 Layer Normalization），这意味着 $B$ 的更新天然只能让方向旋转、不能让它伸缩——这是 DoRA"方向和幅度解耦"在梯度层面的具体体现，不是巧合。
:::

归一化的梯度类似于 Layer Normalization：它会"投影掉"当前方向上的分量，只保留正交方向上的更新。这意味着：

> DoRA 的方向更新天然具有**正交投影**效果——它不会让权重在当前方向上伸缩（那是 $m$ 的工作），只会旋转到新方向。

## 四、为什么 DoRA 比 LoRA 好？深层分析

### 4.1 学习动力学分析

论文通过追踪训练过程中方向和幅度的变化轨迹，发现：

**LoRA 的问题**：
- 方向更新和幅度更新互相干扰
- 如果模型想"只旋转方向、不改大小"，LoRA 很难做到——因为 $BA$ 一定同时改变方向和大小
- 如果模型想"只缩放、不旋转"，LoRA 也做不好

**DoRA 的解决**：
- 方向更新（通过 $BA$）被归一化约束在方向子空间中
- 幅度更新（通过 $m$）完全独立
- 两者可以各自以最优的速率学习，互不干扰

### 4.2 几何直觉

考虑一个 2D 向量（方便可视化）：

```
LoRA 的 ΔW：
  只能沿固定的方向添加一个向量 → 同时改变方向和长度
  
DoRA 的更新：
  第一步：旋转（通过归一化的方向更新）→ 不改变长度
  第二步：缩放（通过 m 调整）→ 不改变方向
  
结果：DoRA 可以精确到达任何目标点，而 LoRA 可能需要"绕路"
```

### 4.3 与 Weight Normalization 的理论联系

Weight Normalization 的已知优势：
1. **解耦梯度方向和梯度大小**：让优化景观更平滑
2. **消除权重矩阵的尺度对梯度的影响**：加速收敛
3. **隐式正则化效果**：防止权重爆炸

DoRA 继承了这些优势，并将其限制在 LoRA 的低秩空间中。

## 五、实现细节

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DoRALinear(nn.Module):
    """DoRA 实现：方向用 LoRA 适配，幅度用独立向量适配"""
    
    def __init__(self, original_linear: nn.Linear, r: int = 16, alpha: int = 32):
        super().__init__()
        d, k = original_linear.out_features, original_linear.in_features
        
        # 冻结原始权重
        self.weight = original_linear.weight  # [d, k]
        self.weight.requires_grad = False
        
        # LoRA 参数（适配方向）
        self.lora_A = nn.Parameter(torch.randn(r, k) * 0.01)
        self.lora_B = nn.Parameter(torch.zeros(d, r))
        self.scaling = alpha / r
        
        # 幅度参数（独立可学习）
        # 初始化为原始权重各列的 L2 范数
        with torch.no_grad():
            self.magnitude = nn.Parameter(
                torch.norm(original_linear.weight, dim=0, keepdim=True)  # [1, k]
            )
    
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # 1. 计算方向更新后的权重
        delta_V = self.lora_B @ self.lora_A  # [d, k]
        V = self.weight + self.scaling * delta_V  # [d, k]
        
        # 2. 按列归一化（只保留方向）
        V_normalized = V / torch.norm(V, dim=0, keepdim=True)  # [d, k]
        
        # 3. 乘以可学习的幅度
        W_prime = self.magnitude * V_normalized  # [d, k]
        
        # 4. 前向传播
        return F.linear(x, W_prime, bias=None)
```

**实现注意事项**：
1. 归一化是按列（`dim=0`）进行的，每列独立归一化
2. `magnitude` 的形状是 `[1, k]`，对应每列一个缩放因子
3. 训练时需要对 `magnitude` 用较小的学习率（它变化幅度本身就小）

## 六、DoRA 的局限性

| 局限 | 描述 | 可能的解决 |
|------|------|-----------|
| 计算开销略增 | 每次前向需要计算列范数归一化 | 可以近似（如定期更新范数） |
| 合并不如 LoRA 简洁 | 合并后权重需要保留幅度信息 | 可以直接计算 $m \cdot V_{\text{norm}}$ 合并 |
| 推理时有少量额外计算 | 严格来说不是"零开销"（但可以预计算合并） | 推理前合并权重 |
| 理论分析不够完整 | 为什么方向-幅度分解刚好对应全参数微调的模式？ | 后续理论工作 |

## 七、总结

1. **发现了全参数微调中方向-幅度独立变化的模式**

3. **用 Weight Normalization 思想解耦方向和幅度适配**
4. **在几乎不增加参数的情况下系统性提升 LoRA 效果**
