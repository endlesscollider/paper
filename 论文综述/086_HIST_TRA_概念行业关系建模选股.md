## 一、HIST：隐式概念图建模

### 1.1 核心思想

每只股票的收益可以分解为两部分：
- **共享部分**：来自它所属的"概念"（行业、主题）的整体运动
- **个体部分**：股票自身独有的驱动力

$$
y_i = \underbrace{y_{\text{shared},i}}_{\text{概念级信号}} + \underbrace{y_{\text{specific},i}}_{\text{个股级信号}}
$$

**这个公式在做什么**：把一只股票的收益拆成"跟着概念板块走的那部分"和"股票自己独有的那部分"两块，分开建模再合起来预测。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $y_i$ | **股票 $i$ 的总收益** | 最终要预测的目标——这只股票未来的涨跌幅 |
| $y_{\text{shared},i}$ | **板块搭的顺风车** | 这只股票跟随所属概念（如"白酒"）集体运动带来的收益部分 |
| $y_{\text{specific},i}$ | **股票自己的独门驱动力** | 剔除板块效应后，股票自身独有的、和板块无关的收益部分 |

**用人话读**："一只股票的涨跌 = 它所属板块整体带来的涨跌 + 它自己独有的涨跌。"

**为什么是这个形式**：不同股票即使属于同一概念，也不会完全同涨同跌——把两部分拆开，能让模型既利用板块的共性信息，又保留个股的独特信息，而不是把所有股票粗暴地当成一个板块的复制品。
:::

> HIST 先用"概念"聚合相似股票的信息，再分离出每只股票的独有信息。

### 1.2 概念矩阵

HIST 使用一个预定义的**概念-股票关联矩阵** $C \in \mathbb{R}^{N \times K}$：

| 股票 | 白酒 | 新能源 | 消费龙头 | 科技 |
|------|------|--------|----------|------|
| 贵州茅台 | 1 | 0 | 1 | 0 |
| 五粮液 | 1 | 0 | 1 | 0 |
| 宁德时代 | 0 | 1 | 0 | 0 |
| 比亚迪 | 0 | 1 | 0 | 0 |
| 腾讯 | 0 | 0 | 0 | 1 |

$C_{ik} = 1$ 表示股票 $i$ 属于概念 $k$。

### 1.3 共享信息提取

**Step 1**：对每个概念 $k$，聚合所属股票的表示：

$$
\mathbf{g}_k = \frac{1}{|S_k|}\sum_{i \in S_k} \mathbf{h}_i
$$

**这个公式在做什么**：把属于同一概念（如"白酒"）的所有股票的表示向量取平均，得到这个概念的一个"代表向量"。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\mathbf{h}_i$ | **股票 $i$ 的个人档案** | 股票 $i$ 经过 GRU 编码后的表示向量 |
| $S_k$ | **概念 $k$ 的成员名单** | 属于概念 $k$（如"白酒"）的所有股票集合 |
| $\frac{1}{\|S_k\|}\sum_{i\in S_k}$ | **求平均的班委** | 把这个概念下所有成员的档案加起来除以人数 |
| $\mathbf{g}_k$ | **概念 $k$ 的代表脸** | 这个概念下所有股票的"平均画像"，代表整个板块的共性 |

**用人话读**："把'白酒'板块里所有股票的表示向量取平均，得到一个代表'白酒'这个概念整体状态的向量。"

**为什么是这个形式**：概念本身没有独立的观测数据，只能通过其成员股票的表示来间接刻画——简单平均是最直接的聚合方式，后续再用 attention（Step 2）让每只股票按需从这个"平均画像"里取信息。
:::

其中 $S_k$ 是属于概念 $k$ 的股票集合，$\mathbf{h}_i$ 是股票 $i$ 的 GRU 嵌入。

**Step 2**：概念表示通过 attention 分配回个股：

$$
\mathbf{h}_{\text{shared},i} = \sum_{k: C_{ik}=1} \alpha_{ik} \cdot \mathbf{g}_k, \quad \alpha_{ik} = \text{softmax}_k(\mathbf{h}_i^\top \mathbf{g}_k)
$$

**这个公式在做什么**：股票 $i$ 从它所属的多个概念代表向量里，按"和自己当前状态的匹配程度"做加权，汇总出属于自己的"共享信息"。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\mathbf{h}_i^\top \mathbf{g}_k$ | **匹配度打分** | 股票 $i$ 当前的表示和概念 $k$ 代表向量的内积，衡量两者有多"像" |
| $\alpha_{ik}=\text{softmax}_k(\cdot)$ | **注意力分配器** | 把匹配度打分归一化成一组权重，股票所属的多个概念之间竞争这份权重 |
| $C_{ik}=1$ | **资格筛选** | 只有股票 $i$ 真正所属的概念 $k$ 才参与这次加权（贵州茅台只在"白酒"和"消费龙头"两列参与竞争） |
| $\mathbf{h}_{\text{shared},i}$ | **股票拿到的板块红利** | 按权重汇总后得到的、代表"板块共性"的信息向量 |

**用人话读**："股票从自己所属的所有概念里，挑出当下最像自己的那个（或几个）概念，按相似程度分配权重，再把这些概念的代表向量加权求和，得到这只股票该拿到的板块信息。"

**为什么用 attention 而不是简单平均**：同一只股票可能同时属于多个概念（茅台既是"白酒"又是"消费龙头"），但不同时刻它的走势更像哪个概念是会变化的——attention 让权重随当前状态动态调整，而不是固定地把多个概念平均分摊。
:::

> 股票 $i$ 从它所属的多个概念中，根据当前状态选择性地接收信息。如果茅台今天的走势更像"消费龙头"而非"白酒"，attention 会给"消费龙头"更高权重。

**Step 3**：个体信息 = 总表示 - 共享部分：

$$
\mathbf{h}_{\text{specific},i} = \mathbf{h}_i - \mathbf{h}_{\text{shared},i}
$$

**这个公式在做什么**：把股票的原始表示减去刚才分配到的"板块共性信息"，剩下的就是这只股票独有的、板块解释不了的部分。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\mathbf{h}_i$ | **股票的完整档案** | 股票 $i$ 原始的 GRU 表示，包含板块共性和个体特性的混合体 |
| $\mathbf{h}_{\text{shared},i}$ | **已经分走的板块份额** | Step 2 算出的、这只股票从所属概念里拿到的共享信息 |
| $\mathbf{h}_{\text{specific},i}$ | **剩下的个体独有部分** | 从完整档案里减掉板块份额后，剩下解释不了的、股票自己的部分 |

**用人话读**："股票的完整信息减去它从所属板块分到的那部分，剩下的就是这只股票自己独有的信息。"

**为什么用直接减法**：这是最简单也最直接的"分解"方式——不需要额外参数，天然保证"共享部分 + 个体部分 = 原始表示"这个约束恒成立，逻辑上对应 1.1 节 $y_i = y_{\text{shared},i}+y_{\text{specific},i}$ 的分解思路。
:::

最终预测：$\hat{y}_i = \text{MLP}([\mathbf{h}_{\text{shared},i}; \mathbf{h}_{\text{specific},i}])$

## 二、TRA：时间路由适配器

### 2.1 核心思想

不同时期，市场运行的"模式"不同：
- 动量期：涨的继续涨（追涨策略有效）
- 反转期：涨多的回落（逆向策略有效）
- 波动期：大幅震荡（短线低吸高抛有效）

TRA 维护多个"专家"模型，用一个路由网络根据当前市场状态选择合适的专家。

### 2.2 模型结构

$$
\hat{y}_i = \sum_{m=1}^M w_m(c_t) \cdot f_m(\mathbf{x}_i)
$$

**这个公式在做什么**：让多个"专家"模型同时对同一只股票做预测，再根据当前市场状态动态决定每个专家的话语权，加权汇总成最终预测。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $f_m(\mathbf{x}_i)$ | **第 $m$ 位专家的判断** | 一个独立的 MLP head，专注学习某一类市场模式（如动量、反转） |
| $w_m(c_t)$ | **专家的当前话语权** | 路由网络根据第 $t$ 天的市场状态 $c_t$，给第 $m$ 个专家分配的权重，$\sum_m w_m=1$ |
| $\sum_{m=1}^M w_m(c_t)\cdot f_m(\mathbf{x}_i)$ | **合议后的最终决定** | 把所有专家的判断按当前话语权加权求和 |
| $M$ | **专家总数** | 论文中固定为 3（如动量、反转、波动三种模式各一个专家） |

**用人话读**："同时问 3 个专家股票会怎么走，再根据现在是什么市场行情决定每个专家的话该听多少，把他们的意见按权重加起来就是最终预测。"

**为什么用多个专家 + 动态权重，而不是单一模型**：单一模型被迫在"动量行情"和"反转行情"两种矛盾的规律之间取平均，学不到任何一种规律的精髓；拆成多个专家分别专注不同模式，再让路由网络按市场状态动态调配权重，就能在不同行情下切换到最合适的那个专家。
:::

> 路由网络看了最近的市场状态后说"现在是动量行情，给动量专家权重 0.7，给反转专家权重 0.2，给波动专家权重 0.1"。

### 2.3 路由网络

$$
\mathbf{w}(c_t) = \text{softmax}\left(\text{MLP}_{\text{router}}(c_t)\right) \in \mathbb{R}^M
$$

**这个公式在做什么**：用一个小型神经网络读取当前市场状态特征，输出一组分给各专家的权重（加起来等于 1）。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $c_t$ | **市场行情快照** | 第 $t$ 天的市场 context 特征，如近期收益率、波动率等 |
| $\text{MLP}_{\text{router}}(c_t)$ | **路由网络的原始判断** | 一个小型 MLP，把市场快照映射成 $M$ 个专家各自的原始打分 |
| $\text{softmax}(\cdot)$ | **归一化裁决** | 把 $M$ 个原始打分转换成一组非负且总和为 1 的权重 |
| $\mathbf{w}(c_t)\in\mathbb{R}^M$ | **最终的权重分配表** | 每个专家在当前市场状态下应该拿到的话语权 |

**用人话读**："路由网络看一眼当前市场的行情特征，就给每个专家打个分，再把打分归一化成权重，分数越高说明当前行情越适合这个专家发言。"

**为什么用 softmax 而不是直接输出打分**：softmax 保证输出天然满足"非负且总和为 1"的概率分布性质，这样才能直接作为公式 $\hat y_i=\sum_m w_m f_m$ 里的加权系数，不需要额外归一化。
:::

路由网络的输入 $c_t$ 通常包括：
- 市场指数近 5/10/20 天收益率
- 市场波动率
- 涨跌比
- 成交额变化率

### 2.4 训练

TRA 的训练有一个技巧：**不强制指定哪个专家对应哪种市场状态**——让模型自动学习分工。

损失 = 加权预测损失 + 专家多样性正则：

$$
L = \sum_t \ell\left(\sum_m w_m(c_t) f_m(x_t), y_t\right) + \beta \cdot \text{Diversity}(\{f_m\})
$$

**这个公式在做什么**：训练目标由两部分组成——让加权预测尽量准的常规损失，加上一个额外惩罚项，逼着不同专家学出不一样的判断方式，防止它们最后都学成同一个模型。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\sum_m w_m(c_t) f_m(x_t)$ | **合议后的最终预测** | 和 2.2 节的 $\hat y_i$ 是同一个东西——各专家按路由权重加权汇总的结果 |
| $\ell(\cdot, y_t)$ | **预测误差打分** | 衡量合议预测和真实收益 $y_t$ 差多少（如 MSE） |
| $\sum_t \ell(\cdot)$ | **全时间段总误差** | 把每一天的预测误差加起来，这是模型要做对的"本职工作" |
| $\text{Diversity}(\{f_m\})$ | **专家差异度打分** | 衡量 $M$ 个专家的预测/参数彼此有多不一样，越像会被惩罚得越重 |
| $\beta$ | **多样性的重视程度** | 控制"强迫专家分化"这件事在总损失里占多大比重，$\beta$ 越大越强制专家们各干各的 |

**用人话读**："训练时不仅要让加权后的预测和真实值接近，还要额外惩罚那些和别的专家学得太像的专家——逼着每个专家专精一种市场模式。"

**为什么需要多样性正则**：如果没有这一项，梯度下降完全可能让 $M$ 个专家收敛到同一组参数（等价于退化成单一模型），路由网络的"选择"也就失去意义——多样性正则从优化目标层面强制专家之间保持差异，这样路由网络才有真正不同的选项可以调度。
:::

多样性正则确保不同专家不会学到相同的模式（否则退化为单模型）。

## 四、工程实现要点

### 4.1 HIST 的概念矩阵获取

```python
# A 股概念数据获取（通过 Tushare 或 AKShare）
import akshare as ak

def get_concept_matrix(stock_codes):
    """获取股票-概念关联矩阵"""
    # 获取所有概念板块成分
    concepts = {}
    concept_list = ak.stock_board_concept_name_em()
    
    for _, row in concept_list.iterrows():
        concept_name = row['板块名称']
        members = ak.stock_board_concept_cons_em(symbol=concept_name)
        concepts[concept_name] = set(members['代码'].tolist())
    
    # 构建关联矩阵
    concept_names = list(concepts.keys())
    matrix = np.zeros((len(stock_codes), len(concept_names)))
    
    for j, concept in enumerate(concept_names):
        for i, code in enumerate(stock_codes):
            if code in concepts[concept]:
                matrix[i, j] = 1.0
    
    return matrix, concept_names
```

### 4.2 TRA 的路由网络

```python
class TemporalRoutingAdaptor(nn.Module):
    """TRA: 时间路由适配器"""
    
    def __init__(self, input_dim, hidden_dim, n_experts=3, context_dim=10):
        super().__init__()
        # 多个专家 head
        self.experts = nn.ModuleList([
            nn.Sequential(
                nn.Linear(input_dim, hidden_dim),
                nn.ReLU(),
                nn.Linear(hidden_dim, 1),
            ) for _ in range(n_experts)
        ])
        
        # 路由网络
        self.router = nn.Sequential(
            nn.Linear(context_dim, 32),
            nn.ReLU(),
            nn.Linear(32, n_experts),
            nn.Softmax(dim=-1),
        )
    
    def forward(self, stock_features, market_context):
        """
        stock_features: (N, input_dim) 每只股票的嵌入
        market_context: (context_dim,) 当天的市场状态特征
        """
        # 路由权重
        weights = self.router(market_context)  # (n_experts,)
        
        # 各专家预测
        expert_preds = torch.stack([
            expert(stock_features).squeeze(-1)  # (N,)
            for expert in self.experts
        ], dim=-1)  # (N, n_experts)
        
        # 加权汇总
        output = (expert_preds * weights.unsqueeze(0)).sum(dim=-1)  # (N,)
        return output
```

## 五、适合作为基准的原因

HIST 和 TRA 在 Qlib 中有**成熟的官方实现**、**20 个种子的可靠数据**、**标准化的评估流程**：

1. 可直接在 Qlib 框架下运行，不需要自己写 DataLoader
2. 结果可与其他 Qlib 模型直接对比
3. 作为"截面关系模型"的代表性基准，适合用来验证新方法的增量价值

## 六、总结

| 方法 | 核心贡献 | Qlib 年化/IR | 适合场景 |

| HIST | 概念驱动的共享/个体信息分离 | 9.87% / 1.37 | 有行业/概念先验 |
| TRA | 时间路由选择专家 | 9.20% / 1.28 | 市场状态频繁切换 |
| 两者结合 | 空间关系 + 时间路由 | 预期 >10% | 通用场景 |
