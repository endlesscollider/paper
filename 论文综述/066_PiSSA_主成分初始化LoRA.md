# PiSSA: Principal Singular Values and Singular Vectors Adaptation of Large Language Models

> **论文信息**：Meng et al., 2024  
> **一句话概括**：标准 LoRA 训练残差部分（$B=0$, $A$ 随机）；PiSSA 反过来——用权重矩阵的**主成分**（SVD 的前 $r$ 个分量）初始化 $A, B$，冻结残差部分。这样 LoRA 从一开始就处理最重要的信号，收敛更快、效果更好。

**相关阅读**：
- [LoRA 低秩适配基础](/前置知识/000x_前置知识_LoRA低秩适配基础) — LoRA 的标准初始化策略
- [AdaLoRA 精读](./057_AdaLoRA_自适应秩分配) — SVD 在 LoRA 中的另一种应用

---

## 贯穿全文的例子

> 考虑一个 Transformer 层的 $W_Q \in \mathbb{R}^{4096 \times 4096}$。对它做 SVD：
>
> $$W_Q = U \Sigma V^T = \underbrace{U_{:,1:r} \Sigma_{1:r} V_{:,1:r}^T}_{\text{主成分（前 r 个）}} + \underbrace{U_{:,r+1:} \Sigma_{r+1:} V_{:,r+1:}^T}_{\text{残差（后 d-r 个）}}$$
>
> - **LoRA 的做法**：冻结完整的 $W_Q$，从零开始学 $\Delta W = BA$
> - **PiSSA 的做法**：
>   - 冻结残差部分 $W_{\text{res}}$
>   - 用主成分初始化 LoRA：$B = U_{:,1:r}\Sigma_{1:r}^{1/2}$, $A = \Sigma_{1:r}^{1/2}V_{:,1:r}^T$
>   - 训练的起点就包含了原始权重中最重要的信息

---

## 一、论文动机

### 1.1 LoRA 初始化的问题

标准 LoRA：
- $B = 0$ → 训练起点的 LoRA 贡献为零
- $A \sim \mathcal{N}(0, \sigma^2)$ → 随机方向

**问题**：LoRA 需要从零开始，在训练中逐渐"发现"权重需要调整的方向。这个发现过程消耗了训练预算。

**能否让 LoRA 从一开始就"站在"正确的位置？**

### 1.2 关键观察

预训练权重矩阵 $W$ 的 SVD 分解中，前 $r$ 个奇异值/向量包含了最重要的信息。如果我们直接让 LoRA 的 $A, B$ 初始化为这些主成分，那么：

1. LoRA 从一开始就"知道"权重的主方向
2. 训练只需要在这些主方向上做微调
3. 冻结的部分是"不太重要"的残差

### 1.3 与 LoRA 的对比直觉

**类比**：
- **LoRA**：让一个新人（$B=0$）从零学起一门手艺。先给他所有工具（冻结完整 $W_0$），让他练习额外技能（$\Delta W = BA$）
- **PiSSA**：让一个已经掌握核心技能的学徒（$A, B$ = 主成分）继续精进。把他已经熟练的基础操作固定住（冻结残差），只在核心方向上优化

## 二、方法详解

### 2.1 SVD 分解

对预训练权重 $W_0 \in \mathbb{R}^{d \times k}$ 做截断 SVD：

$$
W_0 = U \Sigma V^T = \underbrace{U_r \Sigma_r V_r^T}_{W_{\text{principal}}} + \underbrace{U_{-r} \Sigma_{-r} V_{-r}^T}_{W_{\text{residual}}}
$$

**这个公式在做什么**：把预训练权重矩阵按"重要程度"拆成两块——奇异值最大的前 $r$ 个方向（主成分）和剩下的方向（残差），为后面"主成分交给 LoRA 训练、残差冻结"做准备。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $U\Sigma V^T$ | **完整 SVD 分解** | 把 $W_0$ 拆成"方向"（$U$、$V$）和"强度"（$\Sigma$，奇异值从大到小排列） |
| $U_r\Sigma_r V_r^T = W_{\text{principal}}$ | **权重里最重要的骨架** | 前 $r$ 个奇异值/向量组成的低秩近似，携带了 $W_0$ 中信息量最大的方向 |
| $U_{-r}\Sigma_{-r}V_{-r}^T = W_{\text{residual}}$ | **不太重要的细枝末节** | 剩下 $d-r$ 个方向，奇异值小，对输出影响相对次要 |

**用人话读**："把一个大矩阵按重要程度分成两半，前一半是它最核心的骨架，后一半是细节补充。"

**为什么是这个形式**：SVD 保证前 $r$ 个奇异值/向量组成的低秩矩阵是"秩不超过 $r$ 的最佳近似"（Eckart–Young 定理），这正是 LoRA 需要的性质——用一个低秩矩阵去代表"最值得优化的方向"。
:::

其中：
- $U_r \in \mathbb{R}^{d \times r}$：前 $r$ 个左奇异向量
- $\Sigma_r = \text{diag}(\sigma_1, ..., \sigma_r)$：前 $r$ 个奇异值
- $V_r \in \mathbb{R}^{k \times r}$：前 $r$ 个右奇异向量

### 2.2 PiSSA 的初始化

将主成分分配给 LoRA 的 $A, B$：

$$
B_{\text{init}} = U_r \Sigma_r^{1/2} \in \mathbb{R}^{d \times r}
$$

**这个公式在做什么**：把主成分的"左方向 + 一半强度"分配给 LoRA 的 $B$ 矩阵，作为它的初始值。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $U_r$ | **主成分的左方向** | SVD 里前 $r$ 个左奇异向量，描述"输出端"的主要方向 |
| $\Sigma_r^{1/2}$ | **强度的平方根** | 把奇异值开平方后分一半给 $B$，另一半留给 $A$（下一个公式），这样 $B_{\text{init}}A_{\text{init}}$ 才能还原出完整的 $\Sigma_r$ |
| $B_{\text{init}}\in\mathbb{R}^{d\times r}$ | **LoRA 的初始下投影** | 训练开始时 $B$ 不再是零矩阵，而是携带了权重的主要方向信息 |

**用人话读**："LoRA 的 $B$ 矩阵一开始就设成主成分的左方向乘以奇异值的平方根，不再是标准 LoRA 里的全零。"

**为什么是这个形式**：奇异值要在 $B$ 和 $A$ 之间各分一半（都取平方根），是为了让 $B_{\text{init}}A_{\text{init}} = U_r\Sigma_r V_r^T = W_{\text{principal}}$ 恰好等于主成分矩阵，从而保证训练起点不变。
:::

$$
A_{\text{init}} = \Sigma_r^{1/2} V_r^T \in \mathbb{R}^{r \times k}
$$

**这个公式在做什么**：把主成分的"右方向 + 另一半强度"分配给 LoRA 的 $A$ 矩阵。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\Sigma_r^{1/2}$ | **强度的另一半** | 与 $B_{\text{init}}$ 里的 $\Sigma_r^{1/2}$ 相乘后还原完整奇异值 |
| $V_r^T$ | **主成分的右方向** | SVD 里前 $r$ 个右奇异向量，描述"输入端"的主要方向 |
| $A_{\text{init}}\in\mathbb{R}^{r\times k}$ | **LoRA 的初始上投影** | 训练开始时 $A$ 不再是随机高斯噪声，而是携带了权重的主要方向信息 |

**用人话读**："LoRA 的 $A$ 矩阵一开始就设成奇异值的平方根乘以主成分的右方向，不再是标准 LoRA 里的随机初始化。"

**为什么是这个形式**：与 $B_{\text{init}}$ 对称地分配 $\Sigma_r^{1/2}$，两者相乘正好精确还原 $W_{\text{principal}}$，这是保证"训练起点 = 原始预训练模型"的关键设计。
:::

冻结残差部分：

$$
W_{\text{frozen}} = W_{\text{residual}} = W_0 - B_{\text{init}} A_{\text{init}}
$$

**这个公式在做什么**：定义训练过程中保持不变的那一部分权重——用原始权重减去刚分配给 LoRA 的主成分，剩下的残差就是要冻结的部分。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $W_0$ | **原始预训练权重** | 微调开始前的完整矩阵，未做任何改动 |
| $B_{\text{init}}A_{\text{init}}$ | **被 LoRA 拿走的主成分** | 恰好等于 $W_{\text{principal}}$，是刚才两个公式初始化后 $B,A$ 相乘的结果 |
| $W_{\text{frozen}}=W_{\text{residual}}$ | **被冻结的剩余部分** | 训练中梯度不会更新到这里，永远保持初始值 |

**用人话读**："把原始权重减掉分给 LoRA 的那部分主成分，剩下的差值就是接下来要冻结不动的残差。"

**为什么是这个形式**：这是和标准 LoRA 最大的区别——标准 LoRA 冻结的是完整的 $W_0$，PiSSA 冻结的是"减掉主成分之后"的残差，这样重要的信息交给可训练的 LoRA 去精调，次要信息才被冻住。
:::

### 2.3 前向传播

$$
h = W_{\text{frozen}} x + BAx
$$

**这个公式在做什么**：定义 PiSSA 的前向传播——输出等于"冻结部分的贡献"加上"可训练 LoRA 部分的贡献"。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $W_{\text{frozen}}x$ | **不变的底座** | 冻结的残差矩阵对输入的贡献，训练中恒定 |
| $BAx$ | **可训练的精调项** | LoRA 的低秩矩阵乘积对输入的贡献，随训练更新 |
| $h$ | **该层的输出** | 两部分相加得到的最终激活值 |

**用人话读**："这一层的输出 = 冻住不动的那部分权重算出来的结果，加上可训练的 LoRA 部分算出来的结果。"

**为什么是这个形式**：这和标准 LoRA 的前向公式形式完全一样，PiSSA 只是改变了 $W_{\text{frozen}}$、$B$、$A$ 的初始值，没有改变前向传播的结构，因此可以直接复用现有 LoRA 的推理和合并代码。
:::

训练开始时：
$$
W_{\text{frozen}} x + B_{\text{init}} A_{\text{init}} x = W_{\text{residual}} x + W_{\text{principal}} x = W_0 x
$$

**这个公式在做什么**：验证 PiSSA 初始化后的前向输出，在训练开始的第一步就精确等于原始预训练模型的输出，没有引入任何偏差。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $W_{\text{frozen}}x = W_{\text{residual}}x$ | **冻结部分的输出** | 残差矩阵对输入的贡献 |
| $B_{\text{init}}A_{\text{init}}x = W_{\text{principal}}x$ | **LoRA 初始状态的输出** | 由于 $B_{\text{init}}A_{\text{init}}$ 精确等于主成分矩阵，这一项正好是主成分对输入的贡献 |
| $W_{\text{residual}}x+W_{\text{principal}}x=W_0x$ | **两部分相加还原原始输出** | 残差 + 主成分 = 完整原始权重，所以输出和微调前完全一致 |

**用人话读**："残差部分的输出加上主成分部分的输出，正好等于用原始权重直接算出来的输出——训练还没开始，模型就和原来一模一样。"

**为什么是这个形式**：这是 PiSSA 设计的核心约束——虽然初始化方式变了，但必须保证训练起点等价于预训练模型（不能一上来就破坏模型能力），这一步推导就是对这个约束的验证。
:::

✅ 训练起点仍然等于原始预训练模型。

### 2.4 与标准 LoRA 的对比

| 方面 | 标准 LoRA | PiSSA |
|------|-----------|-------|
| 冻结的部分 | $W_0$（完整权重） | $W_{\text{residual}}$（残差） |
| 初始化 $B$ | 全零 | $U_r \Sigma_r^{1/2}$ |
| 初始化 $A$ | 随机 | $\Sigma_r^{1/2} V_r^T$ |
| 训练起点 | $BA = 0$ | $BA = W_{\text{principal}}$ |
| LoRA 的意义 | 从零学习增量 | 在主方向上精调 |

## 三、为什么 PiSSA 更好？

### 3.1 梯度信号更强

在训练初始阶段，标准 LoRA 的梯度：
$$
\frac{\partial \mathcal{L}}{\partial B} = \frac{\partial \mathcal{L}}{\partial h} (A_{\text{random}} x)^T
$$

**这个公式在做什么**：算出标准 LoRA 里 $B$ 矩阵在训练第一步收到的梯度，暴露出它依赖一个随机方向、信息量不确定的问题。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\dfrac{\partial\mathcal{L}}{\partial h}$ | **从后面传回来的误差信号** | 损失函数对该层输出 $h$ 的梯度，由反向传播链式法则给出 |
| $A_{\text{random}}x$ | **随机方向的投影** | 标准 LoRA 里 $A$ 是随机高斯初始化的，这一项衡量输入 $x$ 在一个随机方向上的分量 |
| $\dfrac{\partial\mathcal{L}}{\partial B}$ | **$B$ 收到的更新信号** | 决定 $B$ 这一步该往哪个方向、多大幅度更新 |

**用人话读**："$B$ 的梯度 = 误差信号乘以输入在一个随机方向上的投影——这个投影本身跟权重的重要性毫无关系。"

**为什么是这个形式**：这是标准反向传播链式法则的直接结果，问题不在公式本身，而在于 $A_{\text{random}}$ 是随机初始化的，导致这个梯度信号在训练初期缺乏方向性。
:::

PiSSA 的梯度：
$$
\frac{\partial \mathcal{L}}{\partial B} = \frac{\partial \mathcal{L}}{\partial h} (\Sigma_r^{1/2} V_r^T x)^T
$$

**这个公式在做什么**：算出 PiSSA 里 $B$ 矩阵在训练第一步收到的梯度，展示它天然沿着权重最重要的方向，信息量比标准 LoRA 更大。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\dfrac{\partial\mathcal{L}}{\partial h}$ | **同样的误差信号** | 和标准 LoRA 完全一样，来自反向传播 |
| $V_r^Tx$ | **沿主方向的投影** | $V_r$ 是 SVD 给出的权重最重要方向，这一项衡量输入 $x$ 在这些方向上的分量，比随机方向更有信息量 |
| $\Sigma_r^{1/2}V_r^Tx$ | **按重要性加权的投影** | 再乘上奇异值的平方根，让更重要的方向在梯度里占更大权重 |

**用人话读**："PiSSA 里 $B$ 的梯度 = 误差信号乘以输入在权重最重要方向上的投影——这个投影天生就携带了权重的关键信息，不是随机噪声。"

**为什么是这个形式**：$A$ 的初始化从随机换成了 $\Sigma_r^{1/2}V_r^T$，梯度公式的结构不变，但代入的 $A$ 不同，导致训练一开始梯度信号就更有方向性、信息量更大，这正是 PiSSA 收敛更快的数学根源。
:::

### 3.2 优化景观更平滑

PiSSA 的训练本质上是在主成分子空间内的微调。这个子空间：
- 包含了权重中变化最大的方向
- 对应最大的奇异值 → 梯度信号最强
- 优化景观相对平滑（高曲率方向）

而 LoRA 需要从随机方向开始，可能在平坦区域浪费训练步数。

### 3.3 数学解释

标准 LoRA 训练等价于在约束 $\text{rank}(\Delta W) \leq r$ 下最小化 loss。其最优解 $\Delta W^*$ 的 SVD 对应着 loss landscape 中变化最大的 $r$ 个方向。

PiSSA 用预训练权重的主成分初始化，相当于给了优化一个**更好的起点**——它假设"预训练权重中最重要的方向在微调中也最重要"。这个假设通常是成立的。

## 五、实现细节

### 5.1 SVD 计算开销

对 $W \in \mathbb{R}^{d \times k}$ 做 rank-$r$ 截断 SVD：
- 复杂度：$O(dk \cdot r)$
- LLaMA-7B 所有线性层 SVD：约 5~10 分钟（在 GPU 上）
- **只需做一次**（在训练开始前）

### 5.2 使用 Fast SVD

对于大矩阵，使用随机化 SVD（`torch.svd_lowrank`）可以显著加速：

```python
import torch

def init_pissa(weight: torch.Tensor, r: int):
    """用 PiSSA 初始化 LoRA 的 A 和 B"""
    # 随机化截断 SVD（比完整 SVD 快得多）
    U, S, Vh = torch.svd_lowrank(weight.float(), q=r)
    # U: [d, r], S: [r], Vh: [r, k]
    
    # PiSSA 初始化
    sqrt_S = torch.diag(S.sqrt())
    B_init = U @ sqrt_S          # [d, r]
    A_init = sqrt_S @ Vh         # [r, k]
    
    # 残差（冻结部分）
    W_residual = weight - B_init @ A_init
    
    return B_init, A_init, W_residual

# 使用示例
B, A, W_res = init_pissa(layer.weight.data, r=16)
```

### 5.3 与 Hugging Face PEFT 的集成

```python
from peft import LoraConfig, get_peft_model

config = LoraConfig(
    r=16,
    lora_alpha=16,
    init_lora_weights="pissa",  # 使用 PiSSA 初始化！
    target_modules="all-linear",
)

model = get_peft_model(base_model, config)
```

## 六、PiSSA 的局限

| 局限 | 描述 | 影响 |
|------|------|------|
| 需要预计算 SVD | 增加初始化时间（5~10 分钟） | 训练前一次性开销 |
| 残差不能共享 | 每层的 $W_{\text{residual}}$ 不同 → 存储与标准 LoRA 相同 | 无额外存储节省 |
| 假设可能不成立 | "预训练主成分方向 = 微调重要方向"不一定对 | 极端域外任务可能不适用 |
| 合并方式不同 | 合并后是 $W_{\text{residual}} + BA$，需要重新计算 | 小问题 |

---

## 七、与其他初始化方法的对比

| 方法 | 初始化 A | 初始化 B | 理论依据 |
|------|---------|---------|---------|
| 标准 LoRA | 随机 | 零 | 保证起点 = 预训练 |
| PiSSA | $\Sigma_r^{1/2} V_r^T$ | $U_r \Sigma_r^{1/2}$ | 主成分方向最重要 |
| OLoRA (2024) | 正交随机 | 正交随机 | 保持梯度流的正交性 |
| LoRA-GA (2024) | 基于梯度近似 SVD | 基于梯度近似 SVD | 直接对齐梯度方向 |

## 八、总结

### 核心贡献

1. **提出了基于 SVD 主成分的 LoRA 初始化方法**
2. **将"什么被冻结"从完整权重改为残差**——让 LoRA 管理最重要的部分
3. **收敛速度提升 1.5~1.7 倍**
4. **最终效果系统性优于标准 LoRA**

### 适用建议

- **训练预算有限**（步数少）：PiSSA 优势更大（快速收敛）
- **标准任务**：PiSSA 稳定优于 LoRA
- **极端域外任务**：可能不如标准 LoRA（预训练主方向可能不相关）
- **与其他改进组合**：PiSSA 可以与 LoRA+、rsLoRA、HiddenKey 等组合使用
