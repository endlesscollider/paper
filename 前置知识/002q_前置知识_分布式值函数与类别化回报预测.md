# 前置知识：分布式值函数与类别化回报预测

> **一句话**：不去直接回归一个数字当作"价值"，而是把价值可能落在的范围切成很多个格子，让网络去猜"落在每个格子里的概率"——这样训练更稳、更能应对回报分布本身参差不齐、量级悬殊的情况。

## 一、动机：为什么不直接回归价值

训练一个 Value 网络 $V_\phi(s)$ 最直接的做法是让它输出一个标量，用均方误差（MSE）拟合真实回报：

$$
\mathcal{L}_{\text{MSE}} = \left(V_\phi(s) - R\right)^2
$$

**这个公式在做什么**：让网络输出的价值 $V_\phi(s)$ 直接逼近真实回报 $R$ 这个数字，用平方误差衡量差多远——这是最朴素的"猜一个数"式训练方式。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $V_\phi(s)$ | **网络的猜测** | 价值网络看到状态 $s$，直接输出一个标量数字 |
| $R$ | **真实回报** | 这条轨迹实际拿到的（折扣）总回报，训练的目标值 |
| $V_\phi(s) - R$ | **猜测偏差** | 网络猜的数和真实数字差多少 |
| $(\cdot)^2$ | **平方惩罚** | 差得越多惩罚越重，且保证非负 |

**用人话读**："网络猜一个数字代表这个状态的价值，猜的数字和真实回报差多少，差的平方就是损失。"

**为什么这个形式会出问题**：MSE 隐含假设"真实回报只有一个确定的期望值"，但如果回报本身是多峰分布（比如"成功"和"失败"对应两个完全不同的数值），MSE 只能拟合这两个峰的平均值，这个平均值不代表任何真实结局；而且不同任务的回报量级差异大时，MSE 的梯度幅度会剧烈波动，训练不稳定。
:::

这在两种情况下会出问题：

1. **回报分布是多峰的**：同一个状态下，不同的未来可能导致差异巨大的回报（比如"抓取成功"和"抓取失败"分别对应完全不同的数值）。MSE 只能拟合"条件期望"这个单一数字，会把两个峰的位置平均成一个不代表任何真实结果的中间值。
2. **量级差异大、outlier 敏感**：如果不同任务/不同阶段的回报数值范围差异悬殊（比如有的任务奖励是 0~1，有的是 0~1000），MSE 的梯度幅度会剧烈波动，训练不稳定。

**分类分布回归（categorical regression）**把问题从"猜一个数"变成"猜一个概率分布"：先把价值的可能取值范围切成 $B$ 个离散的格子（bin），网络输出一个 $B$ 维的概率向量，训练目标是让这个概率向量尽量匹配"真实回报落在哪个格子"这件事。

## 二、核心公式：类别化回报预测

### Step 1：这个公式在做什么

给定一个状态 $s_t$（和可选的语言条件 $\ell$），网络 $p_\phi(V \mid s_t, \ell)$ 输出一个 $B$ 维的概率分布（比如 $B=201$ 个 bin）。训练目标是让这个分布的"重心"匹配真实观测到的回报 $R_t$。做法是：把 $R_t$ 离散化成落在哪个 bin（记为 $R_t^B$），然后用交叉熵拉近网络输出的分布和"$R_t^B$ 这个 bin 概率为 1，其余为 0"的目标分布：

$$
\mathcal{L}_{\text{cat}}(\phi) = \mathbb{E}_{\tau}\left[\sum_{s_t \in \tau} H\big(R_t^B(\tau),\, p_\phi(V \mid s_t, \ell)\big)\right]
$$

**这个公式在做什么**：让网络在"回报究竟落在哪个格子"这件事上，尽量把概率押对地方——把价值回归问题变成一个 $B$ 类分类问题，用交叉熵训练。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $R_t^B(\tau)$ | **真实标签** | 真实回报离散化后落入的 bin 编号（或对应的 one-hot 向量） |
| $p_\phi(V\mid s_t,\ell)$ | **网络的猜测分布** | 网络输出的 $B$ 维概率向量，代表价值落在每个 bin 的置信度 |
| $H(\cdot,\cdot)$ | **分布差距打分器** | 交叉熵，衡量"真实标签分布"和"网络预测分布"之间差多远 |
| $\sum_{s_t\in\tau}$ | **逐步累加** | 把一条轨迹里每个时间步的交叉熵加总 |
| $\mathbb{E}_\tau[\cdot]$ | **批次平均** | 对训练集里采样到的轨迹取平均，实践中就是 mini-batch 均值 |

**用人话读**："网络对每个状态猜一个概率分布，说'价值落在哪个格子的可能性有多大'，用交叉熵把这个猜测和真实落在的格子对齐。"

**为什么是这个形式（为什么不用 MSE）**：交叉熵对应的是分类问题的标准损失，天然能表达多峰分布——网络完全可以在两个不相邻的 bin 上都给高概率，代表"这个状态下未来有两种可能结局"，而 MSE 只能拟合单一期望值，会把多峰结构强行抹平。此外分类损失对 outlier 更鲁棒，异常大的回报值只影响一个 bin 的目标概率，不会像 MSE 那样让梯度幅度随误差平方增长。
:::

### Step 2：逐符号拆解

| 符号 | 数学含义 | 具体是什么 | 典型值/维度 |
|------|---------|-----------|-------------|
| $\tau$ | 一条完整轨迹（状态-动作-奖励序列） | 训练数据集里的一条 episode | — |
| $R_t(\tau) = \sum_{t'=t}^{T} r_{t'}$ | 从 $t$ 到轨迹结束的真实经验回报 | Monte Carlo 估计，不需要 bootstrap | 标量 |
| $B$ | bin 的总数 | 把价值区间切成的格子数 | 例如 201 |
| $R_t^B(\tau)$ | 把 $R_t(\tau)$ 离散化后落入的 bin 编号（或对应的 one-hot/软标签向量） | 训练目标 | $\{1,\dots,B\}$ |
| $p_\phi(V \mid s_t,\ell)$ | 网络输出的 $B$ 维概率分布 | softmax 输出，代表价值落在每个 bin 的置信度 | $\Delta^B$（$B$ 维单纯形） |
| $H(\cdot,\cdot)$ | 交叉熵 | 衡量两个分布之间的差距，真实标签分布 vs 网络预测分布 | 标量，越小越好 |

**这一项的梯度方向**：交叉熵会把网络预测分布中"真实 bin 对应位置"的概率往上推，其余 bin 的概率往下压——本质上是一个 $B$ 类分类问题。

### Step 3：数值代入

假设简化为 $B=5$ 个 bin，代表价值区间 $[-1, 0]$ 均分为 5 段：$[-1,-0.8), [-0.8,-0.6), [-0.6,-0.4), [-0.4,-0.2), [-0.2,0]$，对应 bin 编号 1~5。

某条轨迹在 $t$ 时刻的真实回报离散化后落在 bin 3（即 $[-0.6,-0.4)$），真实标签是 one-hot 向量 $[0,0,1,0,0]$。

假设网络当前输出 $p_\phi = [0.05, 0.10, 0.50, 0.25, 0.10]$：

$$
H = -\sum_{b=1}^{5} y_b \log p_b = -\big(0\cdot\log0.05 + 0\cdot\log0.10 + 1\cdot\log0.50 + 0\cdot\log0.25 + 0\cdot\log0.10\big) = -\log 0.50 \approx 0.693
$$

**这个公式在做什么**：把交叉熵的通用定义代入这个具体的 5-bin 例子——因为真实标签是 one-hot（只有 bin 3 为 1），求和式里只剩一项，交叉熵直接等于 $-\log(\text{网络在正确 bin 上给的概率})$。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $y_b$ | **真实标签的第 $b$ 位** | one-hot 向量 $[0,0,1,0,0]$ 的分量，只有 $b=3$ 时为 1 |
| $\log p_b$ | **网络在第 $b$ 个 bin 上的置信度（对数）** | 网络预测概率取对数，概率越低这个值越负 |
| $-\sum_b y_b\log p_b$ | **只挑真实 bin 那一项** | 因为 $y_b$ 除了 bin 3 全是 0，求和后只剩 $-\log p_3=-\log 0.50$ |
| $0.693$ | **当前损失值** | 网络在正确 bin 上只给了 50% 置信度，损失不算小 |

**用人话读**："因为真实标签只有一个 bin 是 1，交叉熵就直接等于负的、网络在那个正确 bin 上给出概率的对数——网络越自信地押对，损失越小。"

**为什么是这个形式**：这是交叉熵在 one-hot 标签下的自然化简，不需要额外设计——它直接继承了上面 $\mathcal{L}_{\text{cat}}$ 公式的定义，只是代入了具体数字。
:::

如果网络预测更准确，比如 $p_\phi = [0.02, 0.05, 0.80, 0.10, 0.03]$，则 $H = -\log 0.80 \approx 0.223$，loss 更小。梯度会持续把 bin 3 的概率往上推、其余 bin 往下压，直到网络的分布集中在正确的 bin 附近。

**为什么是这个形式（为什么不用 MSE）**：交叉熵对应的是"分类问题"的标准损失，天然能表达多峰分布（网络完全可以在两个不相邻的 bin 上都给高概率，代表"这个状态下未来有两种可能结局"），而 MSE 只能拟合单一期望值，会把这种多峰结构强行"抹平"成一个不代表任何真实结局的中间数。此外，分类损失对 outlier 更鲁棒——一个异常大的回报值只会影响一个 bin 的目标概率，不会像 MSE 那样让梯度幅度随误差平方增长。

### 从分布还原一个标量价值

训练好之后，如果下游需要一个标量价值（比如计算 advantage），可以用分布的期望还原：

$$
V_\phi(s,\ell) = \sum_{b=1}^{B} p_\phi(V=b \mid s,\ell)\cdot v(b)
$$

**这个公式在做什么**：把"每个格子的概率"和"每个格子代表的数值"做加权平均，得到一个连续的期望价值估计，供后续 advantage 计算使用。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $p_\phi(V=b\mid s,\ell)$ | **落在第 $b$ 格的概率** | 网络输出分布在 bin $b$ 上的置信度 |
| $v(b)$ | **第 $b$ 格代表的数值** | 通常取该 bin 区间的中心值，如 bin 3 的中心值 $-0.5$ |
| $\sum_{b=1}^B p_\phi(\cdot)\cdot v(b)$ | **加权平均（期望）** | 把每个格子的"数值 × 概率"加总，得到分布的期望值 |

**用人话读**："把每个格子代表的数值，按网络给这个格子的置信度加权平均一下，就还原出一个连续的价值估计。"

**为什么是这个形式**：分类分布本身只输出"每个 bin 的概率"，但很多下游计算（如 advantage $A=R-V$）需要一个标量，用离散分布的期望值就是最自然的还原方式——不引入任何新假设，纯粹是概率论里"随机变量的期望"定义。
:::

延续上面的数值例子，用 $v(1..5) = [-0.9,-0.7,-0.5,-0.3,-0.1]$（取每个区间中点）和网络输出 $p_\phi = [0.02, 0.05, 0.80, 0.10, 0.03]$：

$$
V_\phi = 0.02\times(-0.9) + 0.05\times(-0.7) + 0.80\times(-0.5) + 0.10\times(-0.3) + 0.03\times(-0.1) = -0.018 - 0.035 - 0.400 - 0.030 - 0.003 = -0.486
$$

**这个公式在做什么**：把上面的抽象期望公式代入具体的 5 个 bin 中心值和网络输出概率，算出一个具体的标量价值估计。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $0.02\times(-0.9),\ldots$ | **每个格子的贡献** | 每个 bin 的概率乘以它代表的数值，得到这个 bin 对最终期望的贡献量 |
| $-0.018-0.035-0.400-0.030-0.003$ | **五个贡献相加前的明细** | 逐项列出，方便核对求和过程 |
| $-0.486$ | **最终的标量价值估计** | 五项加总后的结果，可以直接拿去算 advantage |

**用人话读**："网络主要把 80% 的置信度押在了 bin 3（中心值 -0.5），所以最终的期望价值也很接近 -0.5，稍微被其他小概率的 bin 拉高或拉低了一点。"

**为什么是这个形式**：这就是上面期望公式的直接数值代入，没有额外设计——验证了"网络输出分布主要集中在哪个 bin，还原出的标量价值就接近那个 bin 的中心值"这一直觉。
:::

这个 $-0.486$ 就是可以直接拿去计算 advantage 的标量价值估计。

## 三、Two-Hot 编码：解决"离散化误差"

上面的做法有一个粗糙之处：真实回报值很少正好落在某个 bin 的中心，用硬性的 one-hot 标签会丢失"这个值到底更靠近哪个 bin 一点"的信息。**Two-Hot 编码**的做法是：如果真实值落在 bin $b$ 和 $b+1$ 之间，就把标签"摊"在这两个相邻 bin 上，按距离反比分配权重，而不是把全部概率押给最近的那一个 bin。

**数值例子**：假设 bin 中心分别是 $-0.5$（bin 3）和 $-0.3$（bin 4），真实回报是 $-0.42$，正好在两者之间偏 bin 3 一侧：
- 到 bin 3 的距离：$0.08$，到 bin 4 的距离：$0.12$
- 归一化权重（距离越近权重越大）：bin 3 权重 $= 0.12/(0.08+0.12) = 0.6$，bin 4 权重 $= 0.08/(0.08+0.12) = 0.4$
- 标签变成 $[0,0,0.6,0.4,0]$ 而不是硬性的 $[0,0,1,0,0]$

这样训练出来的分布对真实数值的定位更精细，尤其在 bin 数量有限、回报量级差异大的多任务场景中效果更好（DreamerV3 用这种方式编码奖励预测，详见 [DreamerV3 精读](/论文综述/089_DreamerV3_通用世界模型RL) 2.3 节）。

## 四、在机器人 RL 中的典型用途

分布式值函数常被用作"多任务、多阶段"场景下的 Critic，因为：

1. **不同任务的回报量级天差地别**：用分类分布 + 归一化的 bin 区间（比如统一映射到 $(-1,0)$），可以让同一套超参数适配所有任务。
2. **能捕捉"进度"信息**：如果 bin 对应"距离成功还差多少步"，网络输出的分布形态本身就能可视化任务进展是否顺利（哪一步开始价值突然下降，说明策略在那一步犯错）。
3. **训练稳定**：分类交叉熵的梯度幅度天然被 softmax 限制在合理范围内，不会像 MSE 一样因为个别异常大的回报值产生剧烈梯度。

具体应用可参考 [RECAP：从真实部署经验中 RL 学习](/论文综述/016_RECAP_从真实部署经验中RL学习)，其中的多任务价值函数就是用 201 个 bin 的分类分布预测"距离任务成功还剩多少步"。

## 五、总结

| 概念 | 核心要点 |
|------|---------|
| 问题 | 标量回归（MSE）无法表达多峰回报分布，且对量级差异敏感 |
| 方案 | 把价值离散化成 $B$ 个 bin，用交叉熵训练分类分布 |
| Two-Hot | 把标签摊到相邻两个 bin 上，减少离散化误差 |
| 还原标量 | 用分布的期望 $\sum_b p(b) v(b)$ 得到连续价值估计 |
| 典型应用 | DreamerV3（奖励预测）、RECAP（多任务 Critic） |
