# 数值优化基础：梯度下降与牛顿法

> 几乎所有迭代式 IK 算法的本质都是某种数值优化——把"找到满足 FK 方程的关节角"转化为"最小化位姿误差函数"。本文介绍最核心的三种优化方法：梯度下降、牛顿法、Levenberg-Marquardt（阻尼最小二乘），它们分别对应 IK 中的 $J^T$ 法、$J^{-1}$ 法和 DLS 法。

**知识链接**：
- [逆运动学系列：雅可比迭代法](/系列/ik_deep_dive/03_雅可比迭代法IK)（下游应用）

## 1. 问题设定

给定一个目标函数 $F: \mathbb{R}^n \to \mathbb{R}$，求：

$$
\mathbf{q}^* = \arg\min_{\mathbf{q}} F(\mathbf{q})
$$

**这个公式在做什么**：找到使 $F$ 取最小值的参数 $\mathbf{q}^*$。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 |
|------|------|
| $F(\mathbf{q})$ | 目标函数（标量） |
| $\mathbf{q} \in \mathbb{R}^n$ | 待优化变量 |
| $\arg\min$ | 使目标函数取最小值的参数值 |

在 IK 中：$F(\mathbf{q}) = \frac{1}{2}\|f(\mathbf{q}) - \mathbf{x}_d\|^2$（末端位姿误差的平方）。当 $F = 0$ 时就是精确的 IK 解。

**数值代入**：2-DOF 平面臂，目标 $(1.2, 0.5)$，当前 $\mathbf{q} = (20°, 50°)$ 时 FK 输出 $(1.15, 0.55)$：

$$
F = \frac{1}{2}[(1.2-1.15)^2 + (0.5-0.55)^2] = \frac{1}{2}[0.0025 + 0.0025] = 0.0025
$$

优化器要找到 $\mathbf{q}^*$ 使 $F \to 0$。

**为什么是这个形式**：平方范数使得 $F$ 是光滑的（可微），且 $F \ge 0$，$F = 0$ 当且仅当 IK 精确满足。
:::

## 2. 梯度下降

最简单的迭代法：沿负梯度方向走一步。

$$
\mathbf{q}_{k+1} = \mathbf{q}_k - \alpha \nabla F(\mathbf{q}_k)
$$

**这个公式在做什么**：每步沿着函数值下降最快的方向移动一小步。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 |
|------|------|
| $\nabla F = \frac{\partial F}{\partial \mathbf{q}}$ | 梯度向量（$n$ 维），指向函数值增长最快的方向 |
| $\alpha$ | 步长/学习率，控制每步走多远 |
| $-\nabla F$ | 负梯度方向 = 函数值下降最快方向 |

对于 IK 的 $F = \frac{1}{2}\|f(\mathbf{q}) - \mathbf{x}_d\|^2$：

$$
\nabla F = J^T(\mathbf{q})(f(\mathbf{q}) - \mathbf{x}_d) = -J^T \Delta\mathbf{x}
$$

所以梯度下降法做 IK 就是：$\Delta\mathbf{q} = \alpha J^T \Delta\mathbf{x}$——正是[雅可比转置法](/系列/ik_deep_dive/03_雅可比迭代法IK)。

**数值代入**：$\nabla F = (-0.099, -0.031)^T$（来自第 3 章的 $J^T$ 计算），$\alpha = 0.5$：

$$
\mathbf{q}_{\text{new}} = \mathbf{q} + 0.5 \times (0.099, 0.031)^T
$$

每步移动量很小，但方向保证正确。

**为什么是这个形式**：梯度是局部一阶近似的最优下降方向（在球邻域约束下）。简单、稳定，但收敛慢（线性收敛率）。
:::

**收敛速度**：线性收敛（$\|F_{k+1}\| \le c \|F_k\|$，$c < 1$）。可能需要上百步。

## 3. 牛顿法（Gauss-Newton）

利用二阶信息（Hessian 或其近似）加速收敛：

$$
\mathbf{q}_{k+1} = \mathbf{q}_k - [H(\mathbf{q}_k)]^{-1} \nabla F(\mathbf{q}_k)
$$

**这个公式在做什么**：用目标函数的二次近似找到极小值点，一步跳到近似的最优解。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 |
|------|------|
| $H = \nabla^2 F$ | Hessian 矩阵（$n \times n$），描述目标函数的"曲率" |
| $H^{-1} \nabla F$ | 用曲率校正梯度方向——在"平坦"方向走大步，"陡峭"方向走小步 |

对最小二乘问题 $F = \frac{1}{2}\|\mathbf{r}(\mathbf{q})\|^2$（$\mathbf{r} = f(\mathbf{q}) - \mathbf{x}_d$），Gauss-Newton 近似 $H \approx J^T J$：

$$
\Delta\mathbf{q} = -(J^T J)^{-1} J^T \mathbf{r} = -J^+ \mathbf{r} = J^+ \Delta\mathbf{x}
$$

这就是雅可比伪逆法！Gauss-Newton = 伪逆 IK。

**数值代入**：2×2 系统，$J^{-1}$ 存在时直接 $\Delta\mathbf{q} = J^{-1}\Delta\mathbf{x}$ 一步到位。对 2-DOF 非奇异情况，通常 2-5 步就收敛到 sub-mm。

**为什么是这个形式**：牛顿法利用了函数的局部曲率信息，所以能比只用一阶信息的梯度下降快得多——接近最优解时可以达到二次收敛率（误差每步平方缩小）。
:::

**收敛速度**：二次收敛（$\|F_{k+1}\| \le c\|F_k\|^2$）。但在奇异点 $J^TJ$ 不可逆 → 爆炸。

## 4. Levenberg-Marquardt（阻尼最小二乘）

LM 是梯度下降和 Gauss-Newton 的**自适应插值**：

$$
\Delta\mathbf{q} = -(J^T J + \lambda I)^{-1} J^T \mathbf{r}
$$

**这个公式在做什么**：$\lambda$ 大时接近梯度下降（保守、稳定），$\lambda$ 小时接近牛顿法（激进、快速）。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 |
|------|------|
| $\lambda$ | 阻尼参数。$\lambda \to 0$：纯 Gauss-Newton。$\lambda \to \infty$：纯梯度下降 |
| $J^TJ + \lambda I$ | 加了对角正则的 Hessian 近似，保证正定可逆 |

**等价于 IK 中的 DLS**：把 $J^T(JJ^T + \lambda^2 I)^{-1}$ 的另一种等价写法就是 $(J^TJ + \lambda^2 I)^{-1}J^T$。两者数学等价（Woodbury 恒等式），只是计算复杂度不同（取决于 $n$ 和 6 哪个大）。

**自适应策略**：
- 如果这一步函数值下降了 → $\lambda$ 减小（更信任牛顿步）
- 如果这一步函数值反而上升了 → $\lambda$ 增大（回退到梯度下降）

**数值代入**：$J^TJ$ 最小特征值 $= 0.0001$（接近奇异），$\lambda = 0.01$：
- 无阻尼：增益 $= 1/0.0001 = 10000$（爆炸）
- 有阻尼：增益 $= 1/(0.0001 + 0.01) = 99$（可控）

**为什么是这个形式**：LM 兼具梯度下降的全局收敛性和牛顿法的局部快速收敛。它是非线性最小二乘问题（IK 就是一个）的"标准求解器"。
:::

---

## 5. 三种方法的统一视角

| 方法 | IK 中的对应 | 更新公式 | 收敛速度 | 奇异稳定性 |
|------|-------------|----------|----------|------------|
| 梯度下降 | $J^T$ 法 | $\alpha J^T \Delta x$ | 线性 | ✅ |
| Gauss-Newton | $J^+$ 法 | $J^+ \Delta x$ | 二次 | ❌ |
| LM | DLS 法 | $(J^TJ + \lambda I)^{-1}J^T \Delta x$ | 自适应 | ✅ |

这三种方法可以看作同一个框架的不同参数选择——它们都是在"用线性近似修正当前解"，区别只在于如何处理不同方向上的步长缩放。
