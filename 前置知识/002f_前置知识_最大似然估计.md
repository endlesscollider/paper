# 前置知识：最大似然估计（Maximum Likelihood Estimation）

> **为什么要读这篇**：当你写 `loss = F.mse_loss(pred, target)` 或 `loss = F.cross_entropy(logits, labels)` 时，本质上你在做最大似然估计（MLE）。MLE 是"训练一个概率模型"的最基本框架——它把"学习参数"这件事变成"最大化数据在模型下的概率"。理解 MLE，你就能理解为什么 MSE 对应高斯假设、交叉熵对应分类假设、扩散模型的 loss 对应高斯条件概率。

## 贯穿全文的例子

> **场景**：收集了一个机器人抓取数据集——100 次示范，每次记录了状态 $s$ 和专家执行的动作 $a^*$。
> 我们想训练一个策略网络 $\pi_\theta(a|s)$，让它"模仿"专家的行为。
> 问题是：**"模仿得好"该怎么量化？** → MLE 的答案是：让专家动作在策略分布下的概率尽可能大。

---

## 第一部分：MLE 的直觉

### 1.1 核心问题

给定数据 $\mathcal{D} = \{x_1, x_2, \ldots, x_N\}$，和一个参数化的概率模型 $p_\theta(x)$。

**目标**：找到参数 $\theta^*$，使得数据在这个模型下"最可能出现"。

> **一句话**：在所有可能的 $\theta$ 中，选那个"最能解释已有数据"的。

### 1.2 "似然"是什么

**似然函数**（Likelihood）= 把数据固定、把参数当变量，看概率怎么变化：

$$
\mathcal{L}(\theta) = p_\theta(x_1, x_2, \ldots, x_N)
$$

注意区分：
- $p_\theta(x)$：固定 $\theta$，$x$ 是变量 → 这是概率（密度）
- $\mathcal{L}(\theta) = p_\theta(x)$：固定 $x$（已观测），$\theta$ 是变量 → 这是似然

**数值例子**：

掷硬币 10 次，观测到 7 次正面。模型是 $p_\theta(\text{正面}) = \theta$。

- $\theta = 0.5$ 时：$\mathcal{L}(0.5) = \binom{10}{7} 0.5^7 \times 0.5^3 = 0.117$
- $\theta = 0.7$ 时：$\mathcal{L}(0.7) = \binom{10}{7} 0.7^7 \times 0.3^3 = 0.267$
- $\theta = 0.9$ 时：$\mathcal{L}(0.9) = \binom{10}{7} 0.9^7 \times 0.1^3 = 0.057$

$\theta = 0.7$ 的似然最大——MLE 选择 $\theta^* = 0.7$。直觉上很合理：10 次观测到 7 次正面 → 最可能的正面概率就是 7/10。

### 1.3 为什么要取 log

实际中数据量 $N$ 很大（如 10000），似然是 $N$ 个概率的乘积——数值极小。取 log 后乘法变加法：

$$
\log \mathcal{L}(\theta) = \sum_{i=1}^N \log p_\theta(x_i)
$$

最大化 $\log \mathcal{L}$ 和最大化 $\mathcal{L}$ 等价（log 是单调函数）。除以 $N$ 得到**平均对数似然**：

$$
\theta^* = \arg\max_\theta \frac{1}{N}\sum_{i=1}^N \log p_\theta(x_i)
$$

> 这个形式 = "数据上 log-probability 的经验平均"。在代码里就是 `.mean()`。

## 第二部分：MLE 推导出常见 Loss

### 2.1 高斯假设 → MSE Loss

假设模型输出一个预测值 $\hat{y}_\theta(x)$，真实值 $y$ 围绕 $\hat{y}$ 满足高斯分布：

$$
p_\theta(y|x) = \mathcal{N}(y;\, \hat{y}_\theta(x),\, \sigma^2)
$$

取 log：

$$
\log p_\theta(y|x) = -\frac{(y - \hat{y}_\theta(x))^2}{2\sigma^2} - \frac{1}{2}\log(2\pi\sigma^2)
$$

最大化 log-likelihood 等价于最小化：

$$
\text{Loss} = \frac{1}{N}\sum_{i=1}^N (y_i - \hat{y}_\theta(x_i))^2
$$

> **结论**：MSE loss = 高斯假设下的 MLE。$\sigma$ 是常数（不影响最优 $\theta$），所以代码里通常省略。

**为什么是这个形式**：如果你相信"预测误差服从高斯分布"（大多数连续回归问题的合理假设），那 MSE 就是最优的 loss。如果误差分布不是高斯（比如有重尾），MSE 就不是最优的——应该换成对应分布的负对数似然。

### 2.2 行为克隆 = 高斯策略的 MLE

在机器人例子中：

$$
\theta^* = \arg\max_\theta \sum_{i=1}^N \log \pi_\theta(a_i^*|s_i)
$$

如果 $\pi_\theta(a|s) = \mathcal{N}(a;\, \mu_\theta(s), \sigma^2 I)$，展开后：

$$
\theta^* = \arg\min_\theta \sum_{i=1}^N \|a_i^* - \mu_\theta(s_i)\|^2
$$

这就是**行为克隆（Behavioral Cloning）的 MSE loss**。所以行为克隆的本质是：在高斯策略假设下，对专家数据做最大似然估计。

详见 [行为克隆与 RL 微调范式](/前置知识/000d_前置知识_行为克隆与RL微调范式)。

### 2.3 分类 → 交叉熵 Loss

对于离散分类任务，模型输出各类别的概率 $p_\theta(y=c|x) = \text{softmax}(f_\theta(x))_c$。

MLE 目标：

$$
\theta^* = \arg\max_\theta \sum_{i=1}^N \log p_\theta(y_i|x_i)
$$

最大化 log-prob 等价于最小化负 log-prob：

$$
\text{Loss} = -\frac{1}{N}\sum_{i=1}^N \log p_\theta(y_i|x_i) = \text{CrossEntropyLoss}
$$

> **结论**：交叉熵 loss = 离散分类下的 MLE。

### 2.4 扩散模型的 MSE loss

扩散模型训练中，每一步的去噪被建模为高斯：

$$
p_\theta(x_{t-1}|x_t) = \mathcal{N}(x_{t-1};\, \mu_\theta(x_t, t),\, \sigma_t^2 I)
$$

MLE 推导后（经过一系列简化）得到：

$$
\text{Loss} = \mathbb{E}_{t, x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]
$$

"预测噪声的 MSE"本质上是"高斯条件分布的 MLE"。完整推导见 [对数似然与变分下界](/前置知识/000e_前置知识_对数似然与变分下界)。

## 第三部分：MLE 的性质与局限

### 3.1 MLE 的好性质

| 性质 | 含义 | 条件 |
|------|------|------|
| 一致性 | $N \to \infty$ 时 $\theta^* \to \theta_{\text{true}}$ | 真实分布在模型族中 |
| 渐近正态 | 估计量的分布趋向高斯 | $N$ 足够大 |
| 渐近有效 | 方差达到 Cramér-Rao 下界 | 在所有一致估计中方差最小 |

### 3.2 MLE 的局限

| 局限 | 说明 | 解决方案 |
|------|------|---------|
| 过拟合 | 数据少时 MLE 会拟合噪声 | 正则化 / MAP 估计 / 贝叶斯方法 |
| 模型假设错误 | 如果真实分布不在模型族中，MLE 找到的是"最近的" | 使用更灵活的模型（如 Flow） |
| Mode covering | MLE 倾向"覆盖所有模态"，分布被摊开 | 对比：GAN 是 mode seeking |

### 3.3 MLE vs MAP

MAP（最大后验估计）是 MLE 的扩展，加入了先验：

$$
\theta^*_{\text{MAP}} = \arg\max_\theta \left[\sum_{i=1}^N \log p_\theta(x_i) + \log p(\theta)\right]
$$

如果先验 $p(\theta) = \mathcal{N}(0, \frac{1}{\lambda}I)$，那 $\log p(\theta) = -\frac{\lambda}{2}\|\theta\|^2 + \text{const}$。

代入得到：

$$
\theta^*_{\text{MAP}} = \arg\min_\theta \left[\text{NLL}(\theta) + \frac{\lambda}{2}\|\theta\|^2\right]
$$

> **结论**：L2 正则化 = 高斯先验下的 MAP 估计。Weight decay 不是随便加的——它有贝叶斯解释。

## 第四部分：代码中的 MLE

所有常见 loss 都是 MLE 的特殊情况。下面展示这个对应关系在代码中的体现：

```python
import torch
import torch.nn.functional as F
from torch.distributions import Normal

# ===== 回归问题：MSE = 高斯 MLE =====
pred = model(x)                          # 模型预测 ŷ
target = y                               # 真实值

# 写法 1：直接用 MSE（本质是高斯 MLE，σ=1）
loss_mse = F.mse_loss(pred, target)

# 写法 2：显式的负对数似然（等价，但能调 σ）
dist = Normal(pred, sigma)
loss_nll = -dist.log_prob(target).mean()  # 负的平均 log-likelihood

# ===== 分类问题：CrossEntropy = 离散 MLE =====
logits = classifier(x)                   # 未归一化的 log-prob
labels = y                               # 整数类别标签
loss_ce = F.cross_entropy(logits, labels) # = -log p(y|x) 的平均
```

```python
# ===== 行为克隆：高斯策略的 MLE =====
mu_theta = policy_net(states)             # 策略网络输出均值
expert_actions = demonstrations           # 专家动作

# 写法 1：MSE（隐含 σ=常数）
bc_loss = F.mse_loss(mu_theta, expert_actions)

# 写法 2：显式 log-likelihood
dist = Normal(mu_theta, sigma)
bc_loss = -dist.log_prob(expert_actions).sum(dim=-1).mean()
```

**代码 ↔ 数学对应**：

| 代码 | 数学 |
|------|------|
| `F.mse_loss(pred, target)` | $\frac{1}{N}\sum_i (y_i - \hat{y}_i)^2 = -2\sigma^2 \cdot \frac{1}{N}\sum_i \log p_\theta(y_i|x_i) + \text{const}$ |
| `F.cross_entropy(logits, labels)` | $-\frac{1}{N}\sum_i \log p_\theta(y_i|x_i)$ |
| `-dist.log_prob(x).mean()` | $-\frac{1}{N}\sum_i \log p_\theta(x_i)$（通用形式） |

## 第五部分：MLE 在 RL 中的位置

在 RL 的不同阶段，MLE 扮演不同角色：

| 阶段 | 用法 | 对应 loss |
|------|------|----------|
| 预训练（行为克隆） | 最大化专家动作的概率 | MSE / NLL |
| 世界模型训练 | 最大化观测到的 $(s, a, s')$ 转移的概率 | 转移分布的 NLL |
| RL 微调 | **不用 MLE**——改用策略梯度（最大化期望回报，不是数据概率） | PPO clip loss |
| 扩散策略训练 | 最大化去噪步骤的条件概率 | 噪声预测 MSE |

**关键区别**：
- MLE 说的是"让模型拟合**已有数据**"
- RL 说的是"让策略获得**最大奖励**"

行为克隆（MLE）只是起点；RL 微调才能让策略超越专家。但理解 MLE 是理解"为什么行为克隆的 loss 长这样"以及"为什么扩散模型训练用 MSE"的前提。

## 总结

| 概念 | 一句话 |
|------|--------|
| 似然 $\mathcal{L}(\theta)$ | "数据固定，看哪个参数能让数据最可能出现" |
| MLE | 选择似然最大的 $\theta$ |
| 对数似然 | 取 log 让乘法变加法，数值稳定 |
| 高斯 + MLE = MSE | 假设误差服从高斯 → 最优 loss 就是均方误差 |
| 分类 + MLE = 交叉熵 | 假设标签是离散 → 最优 loss 就是交叉熵 |
| MLE vs RL | MLE 拟合数据，RL 最大化奖励——两个不同的目标 |
| L2 正则 = MAP | 加入高斯先验后的 MLE 扩展 |
