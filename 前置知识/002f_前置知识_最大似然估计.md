# 前置知识：最大似然估计（Maximum Likelihood Estimation）

> **为什么要读这篇**：当你写 `loss = F.mse_loss(pred, target)` 或 `loss = F.cross_entropy(logits, labels)` 时，本质上你在做最大似然估计（MLE）。MLE 是"训练一个概率模型"的最基本框架——它把"学习参数"这件事变成"最大化数据在模型下的概率"。理解 MLE，你就能理解为什么 MSE 对应高斯假设、交叉熵对应分类假设、扩散模型的 loss 对应高斯条件概率。

## 贯穿全文的例子

> **场景**：收集了一个机器人抓取数据集——100 次示范，每次记录了状态 $s$ 和专家执行的动作 $a^*$。
> 我们想训练一个策略网络 $\pi_\theta(a|s)$，让它"模仿"专家的行为。
> 问题是：**"模仿得好"该怎么量化？** → MLE 的答案是：让专家动作在策略分布下的概率尽可能大。

## 第一部分：MLE 的直觉

### 1.1 核心问题

给定数据 $\mathcal{D} = \{x_1, x_2, \ldots, x_N\}$，和一个参数化的概率模型 $p_\theta(x)$。

**目标**：找到参数 $\theta^*$，使得数据在这个模型下"最可能出现"。

> **一句话**：在所有可能的 $\theta$ 中，选那个"最能解释已有数据"的。

### 1.2 "似然"是什么

**似然函数**（Likelihood）= 把数据固定、把参数当变量，看概率怎么变化：

$$
\mathcal{L}(\theta) = p_\theta(x_1, x_2, \ldots, x_N)
$$

**这个公式在做什么**：把数据固定住、把参数 $\theta$ 当成变量，看"在这组参数下，观测到这批数据的概率是多少"——这个概率作为 $\theta$ 的函数，就叫似然函数。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $x_1, x_2, \ldots, x_N$ | **已经发生的数据** | 固定不变，是我们手里收集到的观测 |
| $\theta$ | **待求的参数** | 模型里唯一的变量，MLE 要在所有可能的 $\theta$ 里挑一个 |
| $p_\theta(x_1,\ldots,x_N)$ | **数据的联合概率** | 给定参数 $\theta$ 之后，模型认为这批数据出现的概率有多大 |
| $\mathcal{L}(\theta)$ | **似然函数** | 把上面的联合概率重新看成 $\theta$ 的函数——同一个数学表达式，视角换了 |

**用人话读**："固定住已经观测到的数据，换不同的参数 $\theta$ 试一遍，看哪个 $\theta$ 让这批数据显得最不意外。"

**为什么是这个形式**：概率模型 $p_\theta(x)$ 本来是"给定参数看数据分布"，MLE 反过来问"给定数据，哪个参数最合理"——只是把同一个函数的自变量从 $x$ 换成 $\theta$，这个视角转换就是似然函数存在的意义。
:::

注意区分：
- $p_\theta(x)$：固定 $\theta$，$x$ 是变量 → 这是概率（密度）
- $\mathcal{L}(\theta) = p_\theta(x)$：固定 $x$（已观测），$\theta$ 是变量 → 这是似然

**数值例子**：

掷硬币 10 次，观测到 7 次正面。模型是 $p_\theta(\text{正面}) = \theta$。

- $\theta = 0.5$ 时：$\mathcal{L}(0.5) = \binom{10}{7} 0.5^7 \times 0.5^3 = 0.117$
- $\theta = 0.7$ 时：$\mathcal{L}(0.7) = \binom{10}{7} 0.7^7 \times 0.3^3 = 0.267$
- $\theta = 0.9$ 时：$\mathcal{L}(0.9) = \binom{10}{7} 0.9^7 \times 0.1^3 = 0.057$

$\theta = 0.7$ 的似然最大——MLE 选择 $\theta^* = 0.7$。直觉上很合理：10 次观测到 7 次正面 → 最可能的正面概率就是 7/10。

### 1.3 为什么要取 log

实际中数据量 $N$ 很大（如 10000），似然是 $N$ 个概率的乘积——数值极小。取 log 后乘法变加法：

$$
\log \mathcal{L}(\theta) = \sum_{i=1}^N \log p_\theta(x_i)
$$

**这个公式在做什么**：把 $N$ 个概率的乘积，通过取对数变成 $N$ 个 log-概率的加和——数值上更稳定，且不改变哪个 $\theta$ 是最优的。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $p_\theta(x_i)$ | **单个数据点的概率** | 第 $i$ 个观测在当前参数下的概率（密度） |
| $\log p_\theta(x_i)$ | **对数概率** | 把概率换成对数尺度，避免多个小于 1 的数相乘时数值下溢 |
| $\sum_{i=1}^N(\cdot)$ | **N 个数据点累加** | 假设数据独立，联合概率的对数就等于各自对数概率相加 |
| $\log\mathcal{L}(\theta)$ | **对数似然** | 整个数据集在参数 $\theta$ 下的对数似然值 |

**用人话读**："把每个数据点的对数概率加起来，就是整批数据的对数似然，加法比乘法在数值上稳得多。"

**为什么是这个形式**：$\log$ 是单调递增函数，最大化 $\log\mathcal{L}(\theta)$ 和最大化 $\mathcal{L}(\theta)$ 得到的是同一个 $\theta^*$；同时把乘法变成加法能避免 $N$ 很大时概率乘积趋近于 0 造成的数值下溢。
:::

最大化 $\log \mathcal{L}$ 和最大化 $\mathcal{L}$ 等价（log 是单调函数）。除以 $N$ 得到**平均对数似然**：

$$
\theta^* = \arg\max_\theta \frac{1}{N}\sum_{i=1}^N \log p_\theta(x_i)
$$

**这个公式在做什么**：正式给出 MLE 的优化目标——在所有参数里挑出使"数据上对数概率的经验平均"最大的那一个。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\frac{1}{N}\sum_{i=1}^N \log p_\theta(x_i)$ | **平均对数似然** | 把总和除以样本数，变成"每个数据点平均贡献多少对数概率" |
| $\arg\max_\theta(\cdot)$ | **最优参数选择器** | 遍历所有可能的 $\theta$，返回让目标值最大的那一个 |
| $\theta^*$ | **MLE 解** | 训练结束后网络收敛到的参数 |

**用人话读**："在所有参数里，挑一个能让数据平均对数概率最大的，这就是最大似然估计的解。"

**为什么除以 $N$**：除以 $N$ 不改变最优 $\theta^*$（常数缩放不影响 $\arg\max$），但让目标值的量级和数据量 $N$ 无关，方便和 mini-batch 训练对应——代码里的 `.mean()` 就是这个除以 $N$ 的操作。
:::

## 第二部分：MLE 推导出常见 Loss

### 2.1 高斯假设 → MSE Loss

假设模型输出一个预测值 $\hat{y}_\theta(x)$，真实值 $y$ 围绕 $\hat{y}$ 满足高斯分布：

$$
p_\theta(y|x) = \mathcal{N}(y;\, \hat{y}_\theta(x),\, \sigma^2)
$$

**这个公式在做什么**：给回归问题的输出加一个概率假设——真实值 $y$ 不是精确等于预测值，而是围绕预测值 $\hat{y}_\theta(x)$ 服从高斯分布，方差是 $\sigma^2$。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\hat{y}_\theta(x)$ | **网络的预测值** | 模型对输入 $x$ 给出的中心预测 |
| $\sigma^2$ | **假设的噪声方差** | 描述真实值围绕预测值波动的幅度，通常设为常数 |
| $\mathcal{N}(y;\,\hat{y}_\theta(x),\,\sigma^2)$ | **高斯条件分布** | 把"预测一个值"重新表述为"预测一个以 $\hat{y}$ 为中心、方差 $\sigma^2$ 的分布" |

**用人话读**："真实值 $y$ 大概率落在预测值 $\hat{y}$ 附近，偏离越远概率越小，偏离程度服从高斯分布。"

**为什么是这个形式**：把回归问题写成概率模型，才能套用 MLE 框架——直接预测一个点没有"概率"可言，但预测一个分布就可以问"观测到的 $y$ 在这个分布下概率是多少"，进而定义似然。
:::

取 log：

$$
\log p_\theta(y|x) = -\frac{(y - \hat{y}_\theta(x))^2}{2\sigma^2} - \frac{1}{2}\log(2\pi\sigma^2)
$$

**这个公式在做什么**：把高斯分布的概率密度取对数展开，拆成一个和预测误差有关的项、和一个与 $\theta$ 无关的常数项。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $-\dfrac{(y-\hat{y}_\theta(x))^2}{2\sigma^2}$ | **误差惩罚项** | 预测值离真实值越远，这一项越负（对数似然越低） |
| $-\dfrac{1}{2}\log(2\pi\sigma^2)$ | **归一化常数** | 高斯分布公式里的常数部分，只和 $\sigma$ 有关，不含 $\theta$ |

**用人话读**："高斯分布的对数概率，本质上就是负的平方误差，外加一个不影响优化的常数。"

**为什么是这个形式**：这是把 $\mathcal{N}(y;\hat{y},\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(y-\hat y)^2}{2\sigma^2}\right)$ 直接取对数得到的结果——$\exp$ 和 $\log$ 抵消后只剩平方项和常数项。
:::

最大化 log-likelihood 等价于最小化：

$$
\text{Loss} = \frac{1}{N}\sum_{i=1}^N (y_i - \hat{y}_\theta(x_i))^2
$$

**这个公式在做什么**：把"最大化高斯对数似然"转成一个等价的最小化问题——由于常数项和负号，最大化对数似然正好等价于最小化均方误差。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $(y_i - \hat{y}_\theta(x_i))^2$ | **单点平方误差** | 第 $i$ 个样本预测值和真实值差的平方 |
| $\frac{1}{N}\sum_{i=1}^N(\cdot)$ | **批次平均** | 对所有样本的平方误差取平均 |
| $\text{Loss}$ | **待最小化的目标** | 训练时梯度下降真正优化的量 |

**用人话读**："去掉常数项和负号，最大化高斯对数似然就变成了最小化预测值和真实值的均方误差。"

**为什么是这个形式**：$\sigma$ 是常数，不影响最优 $\theta$，所以代码里通常直接省略，只留下平方误差项——这正是 `F.mse_loss` 的数学来源。
:::

**结论**：MSE loss = 高斯假设下的 MLE。如果你相信"预测误差服从高斯分布"（大多数连续回归问题的合理假设），那 MSE 就是最优的 loss。如果误差分布不是高斯（比如有重尾），MSE 就不是最优的——应该换成对应分布的负对数似然。

### 2.2 行为克隆 = 高斯策略的 MLE

在机器人例子中：

$$
\theta^* = \arg\max_\theta \sum_{i=1}^N \log \pi_\theta(a_i^*|s_i)
$$

**这个公式在做什么**：把行为克隆写成 MLE 问题——找一组策略参数 $\theta$，让专家在每个状态下实际执行的动作 $a_i^*$ 在策略分布下的对数概率总和最大。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $s_i, a_i^*$ | **一条示范数据** | 专家在状态 $s_i$ 下实际执行的动作 $a_i^*$ |
| $\pi_\theta(a_i^*|s_i)$ | **策略给这个动作打的概率** | 参数为 $\theta$ 的策略网络，在 $s_i$ 下认为 $a_i^*$ 的概率是多少 |
| $\sum_{i=1}^N \log(\cdot)$ | **N 条示范累加对数概率** | 把所有示范数据的对数概率加起来 |
| $\arg\max_\theta(\cdot)$ | **最优策略参数** | 找到让专家动作整体最"合理"的那组参数 |

**用人话读**："调整策略参数，让专家实际做出的每一个动作，在策略眼里都显得尽可能'合理'（概率尽可能高）。"

**为什么是这个形式**：这就是把 MLE 框架直接套用到策略学习上——数据从"观测 $x$"换成了"专家的(状态,动作)对"，模型从 $p_\theta(x)$ 换成了策略 $\pi_\theta(a|s)$，其余推导完全一致。
:::

如果 $\pi_\theta(a|s) = \mathcal{N}(a;\, \mu_\theta(s), \sigma^2 I)$，展开后：

$$
\theta^* = \arg\min_\theta \sum_{i=1}^N \|a_i^* - \mu_\theta(s_i)\|^2
$$

**这个公式在做什么**：把高斯策略假设代入上一步的 MLE 目标后展开，最终变成一个熟悉的最小化平方误差问题。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\mu_\theta(s_i)$ | **策略网络输出的均值动作** | 高斯策略假设下，网络直接输出动作分布的中心 |
| $\|a_i^* - \mu_\theta(s_i)\|^2$ | **动作预测误差** | 专家动作和网络预测均值之间的欧氏距离平方 |
| $\arg\min_\theta \sum_i(\cdot)$ | **最优参数** | 让所有示范上的预测误差总和最小 |

**用人话读**："让策略网络输出的动作尽量贴近专家实际做的动作，贴近程度用平方误差衡量。"

**为什么是这个形式**：这一步的推导和 2.1 节高斯假设推出 MSE 完全一样——只是把"预测值 $\hat y_\theta(x)$"换成了"策略输出 $\mu_\theta(s)$"，本质是同一个数学结构在不同任务上的复用。
:::

这就是**行为克隆（Behavioral Cloning）的 MSE loss**。所以行为克隆的本质是：在高斯策略假设下，对专家数据做最大似然估计。

详见 [行为克隆与 RL 微调范式](/前置知识/000d_前置知识_行为克隆与RL微调范式)。

### 2.3 分类 → 交叉熵 Loss

对于离散分类任务，模型输出各类别的概率 $p_\theta(y=c|x) = \text{softmax}(f_\theta(x))_c$。

MLE 目标：

$$
\theta^* = \arg\max_\theta \sum_{i=1}^N \log p_\theta(y_i|x_i)
$$

**这个公式在做什么**：把分类任务写成 MLE 问题——找一组参数 $\theta$，让每个样本真实标签 $y_i$ 在模型输出的分类分布下的对数概率总和最大。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $p_\theta(y_i|x_i)$ | **模型给真实标签打的概率** | softmax 输出里，真实类别 $y_i$ 那一维的概率值 |
| $\sum_{i=1}^N\log(\cdot)$ | **N 个样本累加对数概率** | 假设样本独立，联合对数概率等于各自对数概率相加 |
| $\arg\max_\theta(\cdot)$ | **最优分类器参数** | 让所有样本的真实标签整体获得最高概率 |

**用人话读**："调整分类器参数，让每张图（或每个样本）的真实类别都被模型打出尽可能高的概率。"

**为什么是这个形式**：和高斯回归、行为克隆一样，这是把 MLE 框架套到离散标签上——模型分布从 $\mathcal{N}(\cdot)$ 换成了 $\text{softmax}(\cdot)$，其余的推导结构完全一致。
:::

最大化 log-prob 等价于最小化负 log-prob：

$$
\text{Loss} = -\frac{1}{N}\sum_{i=1}^N \log p_\theta(y_i|x_i) = \text{CrossEntropyLoss}
$$

**这个公式在做什么**：把上一步"最大化对数概率"转成等价的"最小化负对数概率"，这正是深度学习框架里 `CrossEntropyLoss` 的数学定义。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $-\log p_\theta(y_i|x_i)$ | **单样本负对数概率** | 模型给真实标签的概率越低，这个值越大（惩罚越重） |
| $\frac{1}{N}\sum_{i=1}^N(\cdot)$ | **批次平均** | 对所有样本的负对数概率取平均 |
| $\text{CrossEntropyLoss}$ | **代码里的交叉熵损失** | 和这个数学表达式完全等价 |

**用人话读**："每个样本，真实标签的概率越低，损失就越大；把所有样本的损失平均起来，就是交叉熵损失。"

**为什么是这个形式**：加负号是为了把"最大化"问题转成深度学习框架统一使用的"最小化"问题，数值上完全等价，只是符号习惯。
:::

**结论**：交叉熵 loss = 离散分类下的 MLE。

### 2.4 扩散模型的 MSE loss

扩散模型训练中，每一步的去噪被建模为高斯：

$$
p_\theta(x_{t-1}|x_t) = \mathcal{N}(x_{t-1};\, \mu_\theta(x_t, t),\, \sigma_t^2 I)
$$

**这个公式在做什么**：把扩散模型的每一步"去噪"也建模成高斯条件分布——给定当前带噪样本 $x_t$，下一步（更干净的）$x_{t-1}$ 围绕网络预测的均值 $\mu_\theta(x_t,t)$ 服从高斯分布。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $x_t$ | **当前时刻的带噪样本** | 扩散过程第 $t$ 步的状态，噪声程度由 $t$ 决定 |
| $\mu_\theta(x_t, t)$ | **网络预测的去噪均值** | 网络看到 $x_t$ 和时刻 $t$，猜测更干净的 $x_{t-1}$ 应该在哪 |
| $\sigma_t^2$ | **该步的噪声方差** | 通常是预先设定好的调度值，不是网络输出 |
| $p_\theta(x_{t-1}|x_t)$ | **单步去噪分布** | 整个去噪链条上的一环，和 2.1 节的高斯回归结构完全一样 |

**用人话读**："每一步去噪，都假设更干净的样本围绕网络猜测的中心呈高斯分布，猜得越准，方差越小越好。"

**为什么是这个形式**：扩散模型的正向过程（加噪）是已知的高斯马尔可夫链，逆向过程（去噪）在理论上也可以证明近似服从高斯分布，这让每一步的训练目标能重新套用 2.1 节"高斯 MLE = MSE"的推导。
:::

MLE 推导后（经过一系列简化）得到：

$$
\text{Loss} = \mathbb{E}_{t, x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]
$$

**这个公式在做什么**：把每一步去噪的高斯 MLE 目标，经过重参数化和简化后，变成一个更简单的形式——训练网络去预测加进去的噪声 $\epsilon$，用 MSE 衡量预测好坏。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\epsilon$ | **真实加入的噪声** | 前向过程中实际叠加到 $x_0$ 上的高斯噪声 |
| $\epsilon_\theta(x_t, t)$ | **网络对噪声的猜测** | 网络看到带噪样本 $x_t$ 和时刻 $t$，猜测里面混入的噪声是什么 |
| $\|\epsilon - \epsilon_\theta(x_t,t)\|^2$ | **噪声预测误差** | 猜测的噪声和真实噪声之间的平方误差 |
| $\mathbb{E}_{t,x_0,\epsilon}[\cdot]$ | **训练时的随机采样** | 随机采样时间步 $t$、原始数据 $x_0$、噪声 $\epsilon$，对这些随机性取期望，训练中用 mini-batch 蒙特卡洛近似 |

**用人话读**："随机抽一个时间步和一个加噪样本，让网络猜猜混入的噪声是什么，猜得和真实噪声差多少就是 loss。"

**为什么是这个形式**：直接优化每步高斯分布的对数似然涉及 $\mu_\theta$，经过重参数化技巧后可以证明等价于让网络预测噪声 $\epsilon$，形式上退化成了和 2.1 节一样的 MSE，但物理含义换成了"预测噪声"而不是"预测标签"。完整推导见 [对数似然与变分下界](/前置知识/000e_前置知识_对数似然与变分下界)。
:::

"预测噪声的 MSE"本质上是"高斯条件分布的 MLE"。

## 第三部分：MLE 的性质与局限

### 3.1 MLE 的好性质

| 性质 | 含义 | 条件 |
|------|------|------|
| 一致性 | $N \to \infty$ 时 $\theta^* \to \theta_{\text{true}}$ | 真实分布在模型族中 |
| 渐近正态 | 估计量的分布趋向高斯 | $N$ 足够大 |
| 渐近有效 | 方差达到 Cramér-Rao 下界 | 在所有一致估计中方差最小 |

### 3.2 MLE 的局限

| 局限 | 说明 | 解决方案 |
|------|------|---------|
| 过拟合 | 数据少时 MLE 会拟合噪声 | 正则化 / MAP 估计 / 贝叶斯方法 |
| 模型假设错误 | 如果真实分布不在模型族中，MLE 找到的是"最近的" | 使用更灵活的模型（如 Flow） |
| Mode covering | MLE 倾向"覆盖所有模态"，分布被摊开 | 对比：GAN 是 mode seeking |

### 3.3 MLE vs MAP

MAP（最大后验估计）是 MLE 的扩展，加入了先验：

$$
\theta^*_{\text{MAP}} = \arg\max_\theta \left[\sum_{i=1}^N \log p_\theta(x_i) + \log p(\theta)\right]
$$

**这个公式在做什么**：在 MLE 的目标基础上加一项"参数本身的先验概率"——不仅要让数据看起来合理，还要让参数 $\theta$ 本身在先验分布下也"合理"，两者一起构成 MAP（最大后验估计）的目标。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\sum_{i=1}^N \log p_\theta(x_i)$ | **纯 MLE 项** | 和之前一样，衡量参数对数据的拟合程度 |
| $p(\theta)$ | **参数的先验分布** | 训练前就设定好的、关于 $\theta$ "应该长什么样"的主观假设 |
| $\log p(\theta)$ | **先验的对数概率** | 越偏离先验假设（如离 0 太远），这一项越小 |
| $\theta^*_{\text{MAP}}$ | **MAP 解** | 同时兼顾"拟合数据"和"符合先验"两个目标后的最优参数 |

**用人话读**："不仅要让数据显得合理，还要让参数本身也不要偏离我们事先设定的假设太远，两者一起决定最终的参数。"

**为什么是这个形式**：这是贝叶斯公式 $p(\theta|\mathcal{D}) \propto p(\mathcal{D}|\theta)p(\theta)$ 两边取对数后的直接结果——MAP 就是在贝叶斯后验分布上取 $\arg\max$，比纯 MLE 多了一个先验修正项。
:::

如果先验 $p(\theta) = \mathcal{N}(0, \frac{1}{\lambda}I)$，那 $\log p(\theta) = -\frac{\lambda}{2}\|\theta\|^2 + \text{const}$。

代入得到：

$$
\theta^*_{\text{MAP}} = \arg\min_\theta \left[\text{NLL}(\theta) + \frac{\lambda}{2}\|\theta\|^2\right]
$$

**这个公式在做什么**：把高斯先验代入上一步的 MAP 目标后化简，得到一个熟悉的形式——负对数似然（NLL）加上一个 L2 正则化项。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\text{NLL}(\theta)$ | **负对数似然** | 纯 MLE 项取负号后的形式，也就是 $-\sum_i\log p_\theta(x_i)$ |
| $\frac{\lambda}{2}\|\theta\|^2$ | **L2 正则化项** | 惩罚参数的大小，$\lambda$ 越大惩罚越重，让参数不会长得太大 |
| $\arg\min_\theta[\cdot]$ | **最优参数** | 同时最小化拟合误差和参数大小的加权和 |

**用人话读**："在最小化数据拟合误差的同时，也要惩罚参数本身长得太大——这两个目标加权相加后取最小。"

**为什么是这个形式**：高斯先验 $\mathcal{N}(0,\frac{1}{\lambda}I)$ 取对数后正好是一个负的平方项（加常数），代入 MAP 目标、把最大化变成最小化后，先验项自然就变成了 L2 正则化——这正是 weight decay 有贝叶斯解释的原因。
:::

**结论**：L2 正则化 = 高斯先验下的 MAP 估计。Weight decay 不是随便加的——它有贝叶斯解释。

## 第四部分：代码中的 MLE

所有常见 loss 都是 MLE 的特殊情况。下面展示这个对应关系在代码中的体现：

```python
import torch
import torch.nn.functional as F
from torch.distributions import Normal

# ===== 回归问题：MSE = 高斯 MLE =====
pred = model(x)                          # 模型预测 ŷ
target = y                               # 真实值

# 写法 1：直接用 MSE（本质是高斯 MLE，σ=1）
loss_mse = F.mse_loss(pred, target)

# 写法 2：显式的负对数似然（等价，但能调 σ）
dist = Normal(pred, sigma)
loss_nll = -dist.log_prob(target).mean()  # 负的平均 log-likelihood

# ===== 分类问题：CrossEntropy = 离散 MLE =====
logits = classifier(x)                   # 未归一化的 log-prob
labels = y                               # 整数类别标签
loss_ce = F.cross_entropy(logits, labels) # = -log p(y|x) 的平均
```

```python
# ===== 行为克隆：高斯策略的 MLE =====
mu_theta = policy_net(states)             # 策略网络输出均值
expert_actions = demonstrations           # 专家动作

# 写法 1：MSE（隐含 σ=常数）
bc_loss = F.mse_loss(mu_theta, expert_actions)

# 写法 2：显式 log-likelihood
dist = Normal(mu_theta, sigma)
bc_loss = -dist.log_prob(expert_actions).sum(dim=-1).mean()
```

**代码 ↔ 数学对应**：

| 代码 | 数学 |
|------|------|
| `F.mse_loss(pred, target)` | $\frac{1}{N}\sum_i (y_i - \hat{y}_i)^2 = -2\sigma^2 \cdot \frac{1}{N}\sum_i \log p_\theta(y_i|x_i) + \text{const}$ |
| `F.cross_entropy(logits, labels)` | $-\frac{1}{N}\sum_i \log p_\theta(y_i|x_i)$ |
| `-dist.log_prob(x).mean()` | $-\frac{1}{N}\sum_i \log p_\theta(x_i)$（通用形式） |

## 第五部分：MLE 在 RL 中的位置

在 RL 的不同阶段，MLE 扮演不同角色：

| 阶段 | 用法 | 对应 loss |
|------|------|----------|
| 预训练（行为克隆） | 最大化专家动作的概率 | MSE / NLL |
| 世界模型训练 | 最大化观测到的 $(s, a, s')$ 转移的概率 | 转移分布的 NLL |
| RL 微调 | **不用 MLE**——改用策略梯度（最大化期望回报，不是数据概率） | PPO clip loss |
| 扩散策略训练 | 最大化去噪步骤的条件概率 | 噪声预测 MSE |

**关键区别**：
- MLE 说的是"让模型拟合**已有数据**"
- RL 说的是"让策略获得**最大奖励**"

行为克隆（MLE）只是起点；RL 微调才能让策略超越专家。但理解 MLE 是理解"为什么行为克隆的 loss 长这样"以及"为什么扩散模型训练用 MSE"的前提。

## 总结

| 概念 | 一句话 |
|------|--------|
| 似然 $\mathcal{L}(\theta)$ | "数据固定，看哪个参数能让数据最可能出现" |
| MLE | 选择似然最大的 $\theta$ |
| 对数似然 | 取 log 让乘法变加法，数值稳定 |
| 高斯 + MLE = MSE | 假设误差服从高斯 → 最优 loss 就是均方误差 |
| 分类 + MLE = 交叉熵 | 假设标签是离散 → 最优 loss 就是交叉熵 |
| MLE vs RL | MLE 拟合数据，RL 最大化奖励——两个不同的目标 |
| L2 正则 = MAP | 加入高斯先验后的 MLE 扩展 |
