# 前置知识：Muon —— 基于矩阵正交化的动量优化器

> **一句话**：Muon（MomentUm Orthogonalized by Newton-Schulz）不把权重矩阵看成一堆互相独立的标量，而是把动量累积后的整个梯度矩阵拉成"最接近它的正交矩阵"再去更新参数——用一种叫 Newton-Schulz 迭代的方法快速近似完成这件事，避免了精确计算奇异值分解（SVD）的高昂开销。

## 贯穿全文的例子

> 一个 Transformer 语言模型里的某个线性层，权重矩阵 $W$ 形状是 $[4096, 4096]$（输入维度到输出维度）。训练过程中，这个矩阵每一步都会收到一个同样形状的梯度矩阵 $G$。本文用"这一个权重矩阵在某一步收到的梯度矩阵长什么样、Muon 会怎么处理它"来贯穿讲解。

---

## 1. Adam 处理矩阵参数时忽略了什么

[Adam](./005e_前置知识_Adam与AdamW自适应学习率优化器) 给矩阵参数 $W \in \mathbb{R}^{n\times m}$ 的每一个元素 $W_{ij}$ 单独维护一阶矩 $m_{ij}$ 和二阶矩 $v_{ij}$——这个矩阵在 Adam 眼里其实是 $n\times m$ 个互相独立的标量，每个标量各自记录自己的历史均值和历史波动幅度，彼此之间没有任何信息交换。

但一个权重矩阵远不止是"一堆数字的集合"。它对输入向量做的是一个**线性变换**：$y = Wx$。这个变换的性质（放大哪些方向、压缩哪些方向）由 $W$ 的**奇异值分解**（Singular Value Decomposition, SVD——把任意矩阵 $W$ 分解成 $W=U\Sigma V^T$，$U,V$ 是正交矩阵，$\Sigma$ 是对角矩阵，对角线上是奇异值）决定：奇异值大的方向被显著放大，奇异值小的方向几乎被压没。

问题在于：Adam/SGD-Momentum 算出来的梯度更新矩阵，凭经验观察，往往是**近似低秩**的——也就是说，更新矩阵的能量高度集中在少数几个奇异值上，其余方向的更新量非常微弱。逐元素处理完全看不到这个"整体结构"，结果是：模型的学习方向被这几个"主导方向"长期主宰，其余方向（哪怕它们对某些任务很关键）几乎学不到东西。回到贯穿的例子：如果这个 $4096\times4096$ 权重矩阵的梯度更新矩阵能量 90% 集中在前 10 个奇异值方向上，那么 Adam 逐元素更新的结果，本质上也会继承这种"厚此薄彼"的倾向，模型收敛后权重矩阵的"表达能力"没有被充分利用。

## 2. Muon 的核心思路：把更新矩阵"拉平"成正交矩阵

Muon 的解决方案是：在动量累积之后，**不直接用这个矩阵去更新参数**，而是先找到"离它最近的正交矩阵（或半正交矩阵）"，再用这个正交化之后的矩阵去更新参数。正交矩阵有一个关键性质——它的所有奇异值都恰好是 1，也就是说，一个正交矩阵在所有方向上的"拉伸倍数"是完全均匀的，不存在某些方向被过度放大、其余方向被忽略的情况。

用数学语言描述这次"拉平"操作（正交化，Orthogonalization）：

$$
\text{Ortho}(G) = \arg\min_{O} \left\{ \|O - G\|_F : O^TO = I \text{ 或 } OO^T = I \right\}
$$

**这个公式在做什么**：在"所有正交矩阵"这个集合里，找到跟原始矩阵 $G$ 距离最近的那一个 $O$，用 $O$ 代替 $G$ 去更新参数。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $G$ | **原始的动量累积梯度矩阵** | 贯穿例子里那个 $4096\times4096$ 矩阵，可能奇异值分布很不均匀（近似低秩） |
| $O^TO=I$ 或 $OO^T=I$ | **正交（或半正交）矩阵的定义** | 矩阵的列（或行）两两正交且长度为 1——几何上表示"一个不带拉伸的旋转/反射变换"，所有方向被同等对待 |
| $\|O-G\|_F$ | **两个矩阵的差距**（Frobenius 范数，把矩阵摊平成向量后算欧几里得距离） | 衡量"拉平后的矩阵"跟"原始矩阵"改变了多少 |
| $\arg\min$ | **在改动最小的前提下完成拉平** | 不是随便找一个正交矩阵，而是找"最保留原始方向信息、只是把奇异值都拉成 1"的那一个——数学上可以证明这就是 $G$ 的 SVD 中的 $UV^T$（丢弃奇异值 $\Sigma$，只保留左右奇异向量） |

**用人话读**："把梯度矩阵里被过度放大的方向压回正常水平、被忽略的方向适当拉高，让所有方向获得同等的更新力度，同时尽量不改变原始梯度指向的大方向。"

**为什么是这个形式**：如果 $G=U\Sigma V^T$ 是 SVD 分解，可以证明 $\text{Ortho}(G)=UV^T$——也就是丢掉对角矩阵 $\Sigma$（各方向不均匀的拉伸倍数），只保留两侧的旋转信息 $U, V$。这样"哪个方向该更新"这个信息（由 $U,V$ 编码）被完整保留，"更新多少"这个曾经不均匀的信息被强制拉平为处处相等。
:::

Muon 的完整更新规则是先做标准的 SGD 动量累积，再对累积后的动量矩阵做正交化：

$$
M_t = \mu M_{t-1} + G_t, \qquad O_t = \text{Ortho}(M_t), \qquad W_t = W_{t-1} - \eta_t O_t
$$

**这个公式在做什么**：先像 SGD-Momentum 一样把历史梯度矩阵平滑累积起来（减少单步噪声），再对累积后的结果做一次"拉平所有方向"的后处理，最后用拉平后的矩阵更新权重。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $M_t = \mu M_{t-1} + G_t$ | **动量累积**（与普通 Momentum 相同的角色，见 [Adam 前置知识](./005e_前置知识_Adam与AdamW自适应学习率优化器) 第 2 节） | 把当前梯度矩阵 $G_t$ 和历史动量 $M_{t-1}$ 融合，得到平滑后的方向 |
| $\text{Ortho}(M_t)$ | **正交化后处理** | Muon 与普通 Momentum 优化器唯一的本质区别——在应用更新之前，先把动量矩阵拉平成半正交矩阵 |
| $\eta_t$ | **学习率** | 和其他优化器一样，控制这一步走多远 |
| $W_t = W_{t-1} - \eta_t O_t$ | **参数更新** | 用拉平后的矩阵，而不是原始动量矩阵，去更新权重 |

**用人话读**："先把这一步的梯度和历史梯度融合成一个平滑的方向（这一步和 Momentum 一样），再把这个方向矩阵的'各方向力度'强行拉平成处处相等，最后拿这个拉平后的方向去更新权重矩阵。"

**为什么把正交化放在动量累积之后而不是之前**：Keller Jordan 在原始博客里报告了一个经验发现——先累积动量、再正交化，效果优于先正交化梯度、再对正交化结果做动量累积（后者是更早的 Orthogonal-SGDM 方法的做法）。直觉上，动量本身已经在做"跨时间步的降噪"，用平滑后的信号做正交化能得到更稳定的方向估计。
:::

## 3. Newton-Schulz 迭代：不用 SVD 也能做正交化

计算 $\text{Ortho}(G)=UV^T$ 最直接的办法是先做精确的 SVD 分解，再丢弃 $\Sigma$。但 SVD 对一个 $4096\times4096$ 的矩阵来说计算成本很高，而且难以在 GPU 上高效并行、难以稳定地用低精度（如 bfloat16）计算——这在每一步训练都要对成千上万个矩阵重复执行的场景下是不可接受的开销。

Muon 改用**Newton-Schulz 迭代**（一种只用矩阵乘法、不需要矩阵分解就能逼近某些矩阵函数的迭代算法）来近似正交化。核心思路是：构造一个多项式 $\varphi(x)$，反复把它应用在矩阵的奇异值上，让每个奇异值都被推向 1，同时全程只用矩阵乘法（矩阵乘法在 GPU 上极快，且可以稳定地用 bfloat16 计算）。

Newton-Schulz 单步迭代的公式：

$$
X_{k+1} = a X_k + b (X_k X_k^T) X_k + c (X_k X_k^T)^2 X_k
$$

**这个公式在做什么**：只用矩阵乘法和加法（没有矩阵求逆、没有分解），把当前矩阵 $X_k$ 变换成一个奇异值分布更接近"全 1"的新矩阵 $X_{k+1}$，反复迭代几次后就能逼近真正的正交化结果。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $X_k$ | **第 $k$ 次迭代后的近似结果**（初始 $X_0 = M_t/\|M_t\|_F$，先归一化保证奇异值都在 $[0,1]$ 范围内） | 每一轮迭代的输入 |
| $X_kX_k^T$、$(X_kX_k^T)^2$ | **只依赖矩阵乘法的中间量** | 如果 $X_k=U\Sigma V^T$，那么 $X_kX_k^T=U\Sigma^2U^T$——这一步在不知道、也不需要显式算出 $U,\Sigma,V$ 的情况下，隐式地对奇异值做平方操作 |
| $a, b, c$ | **精心调好的系数**（Muon 用 $(3.4445,-4.7750,2.0315)$） | 决定多项式 $\varphi(x)=ax+bx^3+cx^5$ 的具体形状——这组系数被设计成"让 $[0,1]$ 区间里的奇异值经过几次迭代后都收敛到 1 附近" |
| $X_{k+1}$ | **本轮迭代后更接近正交的矩阵** | 如果输入的某个方向奇异值是 $\sigma$，经过一次迭代后奇异值变为 $\varphi(\sigma)=a\sigma+b\sigma^3+c\sigma^5$ |

**用人话读**："反复对整个矩阵做几次矩阵乘法组合，每次都让矩阵里各个方向的'力度'更接近彼此、逐渐都逼近 1，全程不需要拆解矩阵内部结构，只需要乘法。"

**为什么是这个形式**：如果 $M_t=U\Sigma V^T$，可以证明一次 Newton-Schulz 迭代等价于 $X_{k+1}=U\varphi(\Sigma)V^T$——也就是说，虽然整个运算是在矩阵层面进行的（左乘右乘一堆矩阵），其效果恰好等价于"只对奇异值这个对角矩阵应用了函数 $\varphi$，方向 $U,V$ 完全不受影响"。这是精心选择系数 $(a,b,c)$ 换来的性质：只要 $\varphi(x)$ 在 $[0,1]$ 上收敛到 1，反复迭代 $N$ 次后奇异值就会被推向 $\varphi^{(N)}(x)\to1$，而不需要真的去算 SVD。
:::

![Newton-Schulz迭代将奇异值推向1的过程](/newton_schulz_convergence.png)

> 横轴是矩阵某个方向的初始奇异值（归一化到 $[0,1]$），纵轴是经过 $N$ 次 Newton-Schulz 迭代后的值。可以看到：即便是初始值很小（接近 0）的奇异值，只需 5 步迭代也已经被大幅推高到接近 1 附近——这正是 Muon 只需要 5 步迭代（而不是几十步）就能得到足够好的正交化近似的原因。注意曲线在 x=0 附近的斜率特别陡，这是刻意调整系数 $a$（让 $\varphi'(0)=a$ 尽可能大）换来的效果，专门针对"初始奇异值很小、需要被快速拉起来"的情况做了优化。

**为什么这样做比 SVD 快**：SVD 分解一个 $n\times n$ 矩阵的计算复杂度通常是 $O(n^3)$，且这个过程本质上是串行的、难以充分利用 GPU 的并行矩阵乘法能力，实践中即使有优化实现也远慢于纯矩阵乘法。而 Newton-Schulz 每步迭代只是几次矩阵乘法（复杂度也是 $O(n^3)$ 量级，但矩阵乘法是 GPU 上吞吐量最高的运算），5 步迭代的总开销远小于一次精确 SVD，且可以稳定地用 bfloat16（16 位浮点数，比标准 32 位浮点数节省一半内存和带宽）计算，这对于每一步训练都要处理网络里成百上千个权重矩阵的场景至关重要。Muon 作者在原始博客中给出的估算：对 NanoGPT 规模的训练，Muon 引入的额外计算开销低于总训练算力的 1%。

## 4. Muon 只适用于矩阵参数：哪些层用 Muon，哪些不用

Muon 的正交化操作只对**二维矩阵参数**有意义——一个向量（如 bias）或标量没有"奇异值分布不均匀"这个问题，谈不上正交化。因此实践中 Muon 只用于神经网络的**隐藏层的二维权重矩阵**（如 Transformer 中的注意力投影矩阵、MLP 权重矩阵），而以下几类参数仍然交给 AdamW 处理：

- **输入嵌入层（embedding）**：每一行对应一个 token 的向量，行与行之间没有"整体旋转对称性"的结构，不适合正交化
- **输出分类头（如 LM head）**：同理，输出层的角色和隐藏层不同
- **标量/向量参数**（如 LayerNorm 的 gain、bias）：本身就是一维的，没有奇异值分布的概念

回到贯穿的例子：那个 $4096\times4096$ 的隐藏层权重矩阵是 Muon 的典型应用对象；但如果模型里还有一个 embedding 矩阵，即便它同样是二维的（词表大小 × 隐藏维度），也应该用 AdamW 而不是 Muon——这不是复杂度问题，而是"embedding 矩阵的每一行代表一个独立的、语义上不相关的 token，不存在一个统一的旋转结构值得被正交化保留"的结构性差异。

## 5. Muon 与 Adam 的对比总结

| 特性 | Adam / AdamW | Muon |
|------|-------------|------|
| 处理对象 | 逐元素（标量） | 整个矩阵的整体结构 |
| 核心操作 | 一阶矩 + 二阶矩滑动平均 | 动量累积 + 正交化（Newton-Schulz 近似） |
| 额外存储 | 两份统计量（$m,v$），与参数同形状 | 一份动量矩阵，与参数同形状（比 Adam 省一半） |
| 需要矩阵分解？ | 不需要 | 不需要精确 SVD，用 Newton-Schulz 近似 |
| 适用参数类型 | 所有类型（标量/向量/矩阵） | 仅二维矩阵（embedding、输出头、标量仍需 AdamW） |
| 解决的核心问题 | 不同参数梯度尺度差异大 | 矩阵更新的方向近似低秩、部分方向被忽略 |
