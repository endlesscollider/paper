# 前置知识：方差与标准差

> **为什么要读这篇**：期望告诉你"平均能得多少分"，但没告诉你"每次的结果离平均有多远"。方差衡量的就是这个"波动幅度"。在 RL 中，策略梯度估计的方差决定了训练是否稳定——方差大 → 梯度乱跳 → 训练崩溃。PPO 的 GAE、baseline 减去、mini-batch 增大——全是为了降低方差。

## 贯穿全文的例子

> **场景**：两个不同的机器人策略，目标都是移到 5.0 cm 处。
>
> - **策略 A**：$\pi_A(a) = \mathcal{N}(a;\, 5.0, 0.01)$ — 均值正好在目标上，标准差很小（0.1 cm）
> - **策略 B**：$\pi_B(a) = \mathcal{N}(a;\, 5.0, 4.0)$ — 均值也在目标上，但标准差很大（2.0 cm）
>
> 两个策略的**期望动作相同**（都是 5.0），但表现天差地别：A 每次都精准命中，B 经常偏离很远。方差描述的就是这个差异。

## 第一部分：方差的定义与直觉

### 1.1 想衡量什么

期望 $\mathbb{E}[X] = \mu$ 告诉你"重心在哪"。但我们还想知道：**结果围绕重心的"散布程度"有多大？**

最自然的想法：看每次结果和均值的**偏差** $X - \mu$，然后取平均。

问题是：$\mathbb{E}[X - \mu] = \mathbb{E}[X] - \mu = 0$（正偏差和负偏差互相抵消，恒为 0）。

解决方案：**平方**偏差后再取平均，这样正负都变成正的了：

$$
\text{Var}(X) = \mathbb{E}\left[(X - \mu)^2\right]
$$

> **一句话**："每次结果偏离均值的距离的平方"的平均。

### 1.2 展开为可计算的形式

$$
\text{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2
$$

推导（展开平方）：

$$
\mathbb{E}[(X-\mu)^2] = \mathbb{E}[X^2 - 2\mu X + \mu^2] = \mathbb{E}[X^2] - 2\mu\mathbb{E}[X] + \mu^2 = \mathbb{E}[X^2] - \mu^2
$$

这个形式在实际计算中更方便——先算 $\mathbb{E}[X^2]$ 和 $\mathbb{E}[X]$，然后相减。

### 1.3 标准差

$$
\sigma = \sqrt{\text{Var}(X)}
$$

标准差的优势：和 $X$ 有**相同的单位**。如果 $X$ 的单位是 cm，方差的单位是 cm²，标准差的单位是 cm——更直觉。

### 1.4 完整数值例子

**策略 A**：$a \sim \mathcal{N}(5.0, 0.01)$，标准差 $\sigma = 0.1$ cm

模拟 5 次执行：$a = 5.08, 4.93, 5.02, 4.97, 5.11$

- 偏差：$0.08, -0.07, 0.02, -0.03, 0.11$
- 偏差平方：$0.0064, 0.0049, 0.0004, 0.0009, 0.0121$
- 平均偏差平方（方差的采样估计）：$(0.0064+0.0049+0.0004+0.0009+0.0121)/5 = 0.0049$
- 标准差估计：$\sqrt{0.0049} = 0.07$ cm

**策略 B**：$a \sim \mathcal{N}(5.0, 4.0)$，标准差 $\sigma = 2.0$ cm

模拟 5 次执行：$a = 3.2, 6.8, 4.1, 7.5, 2.9$

- 偏差：$-1.8, 1.8, -0.9, 2.5, -2.1$
- 偏差平方：$3.24, 3.24, 0.81, 6.25, 4.41$
- 平均偏差平方：$(3.24+3.24+0.81+6.25+4.41)/5 = 3.59$
- 标准差估计：$\sqrt{3.59} = 1.90$ cm

**对比**：策略 A 的方差 ≈ 0.005，策略 B 的方差 ≈ 3.6——B 的"波动"是 A 的 700 倍！虽然两者的期望相同（都是 5.0），但 B 根本不可靠。

## 第二部分：方差在 RL 中的含义

### 2.1 策略梯度估计的方差

策略梯度的理论值：

$$
g = \mathbb{E}[\nabla\log\pi \cdot A]
$$

实际用蒙特卡洛估计：

$$
\hat{g} = \frac{1}{N}\sum_{i=1}^N \nabla\log\pi(a_i|s_i) \cdot A_i
$$

这个估计 $\hat{g}$ 本身也是一个随机变量（因为每次采的样本不同）。它的方差：

$$
\text{Var}(\hat{g}) = \frac{\text{Var}(\nabla\log\pi \cdot A)}{N}
$$

**后果**：
- 方差大 → 每次估计出的梯度方向可能差别很大 → 参数更新时而往左时而往右 → 训练震荡不收敛
- 方差小 → 梯度估计稳定 → 训练平稳收敛

### 2.2 为什么 Advantage 比 Return 的方差小

用 $R(\tau)$（整条轨迹的总回报）做梯度估计，方差很大——因为 $R$ 既包含"这个动作的贡献"又包含"后续所有步骤的随机性"。

减去 baseline $V(s)$，得到 $A(s,a) = Q(s,a) - V(s)$：
- $A$ 只反映"这个动作**相对平均**好多少"
- $V(s)$ 把"状态本身的价值"（和当前动作无关的部分）减掉了
- 剩下的波动更小 → 方差更小

## 第三部分：方差的运算规则

| 规则 | 公式 | 使用场景 |
|------|------|---------|
| 常数缩放 | $\text{Var}(cX) = c^2 \text{Var}(X)$ | learning rate 放大会放大梯度方差 |
| 平移不变 | $\text{Var}(X + c) = \text{Var}(X)$ | 加 baseline 不改变方差（但选好的 baseline 可以减小被乘对象的方差） |
| 独立变量相加 | $\text{Var}(X+Y) = \text{Var}(X) + \text{Var}(Y)$ | 多步回报的方差 = 各步方差之和 |
| 均值的方差 | $\text{Var}(\bar{X}_N) = \frac{\text{Var}(X)}{N}$ | **batch size $N$ 越大，梯度估计方差越小** |

最后一条是核心：$N$ 个独立样本的均值，方差是单个样本方差的 $1/N$。

**数值例子**：单个样本的策略梯度方差是 100。
- batch size $N = 1$：$\text{Var}(\hat{g}) = 100$（极不稳定）
- batch size $N = 64$：$\text{Var}(\hat{g}) = 100/64 = 1.56$（稳定多了）
- batch size $N = 4096$：$\text{Var}(\hat{g}) = 100/4096 = 0.024$（非常稳定）

这就是为什么 PPO 通常用 2048~8192 的 batch size。

## 总结

| 概念 | 含义 | 在 RL 中的角色 |
|------|------|--------------|
| 方差 $\text{Var}(X)$ | 结果围绕均值的波动程度 | 策略梯度估计的"可信度" |
| 标准差 $\sigma$ | 方差的平方根（和 $X$ 同单位） | 策略的探索幅度 |
| $\text{Var}(\bar{X}) = \text{Var}(X)/N$ | 样本均值方差随 $N$ 下降 | batch size 越大训练越稳定 |
| 方差减小技巧 | baseline、GAE、大 batch | PPO 训练的核心工程手段 |
