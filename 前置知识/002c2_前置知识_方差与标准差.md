# 前置知识：方差与标准差

> **为什么要读这篇**：期望告诉你"平均能得多少分"，但没告诉你"每次的结果离平均有多远"。方差衡量的就是这个"波动幅度"。在 RL 中，策略梯度估计的方差决定了训练是否稳定——方差大 → 梯度乱跳 → 训练崩溃。PPO 的 GAE、baseline 减去、mini-batch 增大——全是为了降低方差。

## 贯穿全文的例子

> **场景**：两个不同的机器人策略，目标都是移到 5.0 cm 处。
>
> - **策略 A**：$\pi_A(a) = \mathcal{N}(a;\, 5.0, 0.01)$ — 均值正好在目标上，标准差很小（0.1 cm）
> - **策略 B**：$\pi_B(a) = \mathcal{N}(a;\, 5.0, 4.0)$ — 均值也在目标上，但标准差很大（2.0 cm）
>
> 两个策略的**期望动作相同**（都是 5.0），但表现天差地别：A 每次都精准命中，B 经常偏离很远。方差描述的就是这个差异。

## 第一部分：方差的定义与直觉

### 1.1 想衡量什么

期望 $\mathbb{E}[X] = \mu$ 告诉你"重心在哪"。但我们还想知道：**结果围绕重心的"散布程度"有多大？**

最自然的想法：看每次结果和均值的**偏差** $X - \mu$，然后取平均。

问题是：$\mathbb{E}[X - \mu] = \mathbb{E}[X] - \mu = 0$（正偏差和负偏差互相抵消，恒为 0）。

解决方案：**平方**偏差后再取平均，这样正负都变成正的了：

$$
\text{Var}(X) = \mathbb{E}\left[(X - \mu)^2\right]
$$

**这个公式在做什么**：把"每次结果偏离均值多远"这件事变成一个正数再求平均，量化随机变量的波动幅度。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $X - \mu$ | **原始偏差** | 单次结果和均值的距离，可能是正也可能是负 |
| $(X-\mu)^2$ | **偏差的平方** | 把正负偏差统一变成正数，且偏得越远惩罚越重（平方放大） |
| $\mathbb{E}[\cdot]$ | **长期平均** | 对所有可能结果按概率加权平均，得到"平均偏离程度" |
| $\text{Var}(X)$ | **波动打分** | 最终得到的一个数，越大说明结果越不稳定 |

**用人话读**："把每次结果离平均值的距离先平方再求平均，得到的数就是这个随机变量的波动大小。"

**为什么要平方而不是取绝对值**：平方处处可导，方便后续求梯度和做代数推导（如下面的展开公式）；绝对值在 0 点不可导，数学上更难处理。代价是平方对离群值更敏感，但这在大多数场景下是可接受的。
:::

### 1.2 展开为可计算的形式

$$
\text{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2
$$

**这个公式在做什么**：给出方差的等价计算公式——不用先算偏差再平方，只需要"平方的期望"减去"期望的平方"就能算出方差。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\mathbb{E}[X^2]$ | **平方后的均值** | 先把每个结果平方，再求期望 |
| $(\mathbb{E}[X])^2$ | **均值的平方** | 先求期望，再把这个均值平方 |
| 两者之差 | **等价方差** | 和 1.1 节定义的 $\mathbb{E}[(X-\mu)^2]$ 数值完全相等，只是计算路径不同 |

**用人话读**："方差也可以用'先平方再平均'减去'先平均再平方'算出来，两种算法结果一样。"

**为什么需要这个等价形式**：实际计算中，这个形式往往更方便——只需要维护两个累加量（$\sum X$ 和 $\sum X^2$），一次遍历数据就能同时算出均值和方差，不需要先求出 $\mu$ 再重新遍历一次算偏差。
:::

推导（展开平方）：

$$
\mathbb{E}[(X-\mu)^2] = \mathbb{E}[X^2 - 2\mu X + \mu^2] = \mathbb{E}[X^2] - 2\mu\mathbb{E}[X] + \mu^2 = \mathbb{E}[X^2] - \mu^2
$$

**这个公式在做什么**：具体展示上面等价公式的代数证明过程——把平方展开成三项，逐项求期望，化简后正好得到 $\mathbb{E}[X^2]-\mu^2$。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $X^2 - 2\mu X + \mu^2$ | **展开后的三项** | $(X-\mu)^2$ 用平方公式 $(a-b)^2=a^2-2ab+b^2$ 展开 |
| $\mathbb{E}[X^2]-2\mu\mathbb{E}[X]+\mu^2$ | **逐项求期望** | 期望是线性运算，可以拆开分别对每一项求期望 |
| $-2\mu\mathbb{E}[X]+\mu^2 = -\mu^2$ | **代入 $\mathbb{E}[X]=\mu$ 化简** | $\mathbb{E}[X]$ 本身就是 $\mu$，代入后 $-2\mu^2+\mu^2=-\mu^2$ |

**用人话读**："把平方展开、逐项求期望、再代入 $\mathbb{E}[X]=\mu$ 化简，三步就能从原始定义推出等价公式。"

**为什么这一步是纯代数推导**：这里没有引入任何新假设，只是用期望的线性性质（$\mathbb{E}[aX+b]=a\mathbb{E}[X]+b$）把定义式改写成另一种等价形式，目的是得到计算更方便的版本。
:::

这个形式在实际计算中更方便——先算 $\mathbb{E}[X^2]$ 和 $\mathbb{E}[X]$，然后相减。

### 1.3 标准差

$$
\sigma = \sqrt{\text{Var}(X)}
$$

**这个公式在做什么**：把方差开根号还原回和原变量相同的单位，得到更直觉的"波动幅度"指标——标准差。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\text{Var}(X)$ | **平方单位的波动** | 方差的单位是原变量单位的平方（如 cm²），数值不直观 |
| $\sqrt{\cdot}$ | **单位还原器** | 开根号把单位从"平方"还原回"原单位" |
| $\sigma$ | **标准差** | 和 $X$ 同单位的波动幅度，更容易和实际数值对比 |

**用人话读**："标准差就是方差开根号，单位和原变量一样，比方差更好理解波动有多大。"

**为什么是这个形式**：方差在推导和求梯度时数学性质更好（如满足 $\text{Var}(cX)=c^2\text{Var}(X)$），但数值上单位是平方，不适合直觉判断"波动有多大"；开根号后单位和 $X$ 一致，才能直接和均值放在一起比较（如"均值 5cm，标准差 0.1cm"）。
:::

标准差的优势：和 $X$ 有**相同的单位**。如果 $X$ 的单位是 cm，方差的单位是 cm²，标准差的单位是 cm——更直觉。

### 1.4 完整数值例子

**策略 A**：$a \sim \mathcal{N}(5.0, 0.01)$，标准差 $\sigma = 0.1$ cm

模拟 5 次执行：$a = 5.08, 4.93, 5.02, 4.97, 5.11$

- 偏差：$0.08, -0.07, 0.02, -0.03, 0.11$
- 偏差平方：$0.0064, 0.0049, 0.0004, 0.0009, 0.0121$
- 平均偏差平方（方差的采样估计）：$(0.0064+0.0049+0.0004+0.0009+0.0121)/5 = 0.0049$
- 标准差估计：$\sqrt{0.0049} = 0.07$ cm

**策略 B**：$a \sim \mathcal{N}(5.0, 4.0)$，标准差 $\sigma = 2.0$ cm

模拟 5 次执行：$a = 3.2, 6.8, 4.1, 7.5, 2.9$

- 偏差：$-1.8, 1.8, -0.9, 2.5, -2.1$
- 偏差平方：$3.24, 3.24, 0.81, 6.25, 4.41$
- 平均偏差平方：$(3.24+3.24+0.81+6.25+4.41)/5 = 3.59$
- 标准差估计：$\sqrt{3.59} = 1.90$ cm

**对比**：策略 A 的方差 ≈ 0.005，策略 B 的方差 ≈ 3.6——B 的"波动"是 A 的 700 倍！虽然两者的期望相同（都是 5.0），但 B 根本不可靠。

## 第二部分：方差在 RL 中的含义

### 2.1 策略梯度估计的方差

策略梯度的理论值：

$$
g = \mathbb{E}[\nabla\log\pi \cdot A]
$$

**这个公式在做什么**：给出策略梯度的真实定义——对"log 概率梯度乘优势"这个量，在无穷多次采样下取平均得到的理论值。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\nabla\log\pi$ | **调整方向指南** | [策略梯度](/前置知识/000a_前置知识_策略梯度与PPO) 里"怎么调参数能让这个动作概率变大"的方向 |
| $A$ | **动作打分** | Advantage，这个动作比平均水平好多少 |
| $\nabla\log\pi\cdot A$ | **单次梯度贡献** | 一次采样得到的、还没求平均的梯度估计值 |
| $\mathbb{E}[\cdot]$ | **理论上的无穷平均** | 对所有可能的采样结果求期望，得到真实但不可直接计算的梯度 $g$ |

**用人话读**："策略梯度的真实值，是把'调整方向乘打分'这个量在所有可能的采样结果上求平均。"

**为什么是这个形式**：这正是 [策略梯度定理](/前置知识/000a_前置知识_策略梯度与PPO) 推导出的结果——但期望没法真正算出来（可能的轨迹无穷多），实际训练只能用有限样本近似，这就引出下面的蒙特卡洛估计。
:::

实际用蒙特卡洛估计：

$$
\hat{g} = \frac{1}{N}\sum_{i=1}^N \nabla\log\pi(a_i|s_i) \cdot A_i
$$

**这个公式在做什么**：用有限的 $N$ 个采样样本的平均值，近似上面那个算不出来的理论期望 $g$。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\nabla\log\pi(a_i\|s_i)\cdot A_i$ | **第 $i$ 个样本的梯度贡献** | 用第 $i$ 条采样数据算出的单次梯度估计 |
| $\sum_{i=1}^N$ | **累加所有样本** | 把 $N$ 个样本各自的梯度贡献加起来 |
| $\frac{1}{N}$ | **求平均** | 用样本均值近似理论上的期望值 |
| $\hat g$ | **实际用来更新参数的梯度** | 训练代码里真正拿去做梯度上升的那个量 |

**用人话读**："采集 $N$ 条数据，各自算一份梯度贡献，加起来除以 $N$，这就是实际训练时用的梯度估计。"

**为什么是这个形式（蒙特卡洛近似）**：这是[蒙特卡洛采样](/前置知识/002c3_前置知识_蒙特卡洛采样)的标准做法——用有限样本的平均值近似无法直接计算的期望，样本数 $N$ 越大，$\hat g$ 越接近真实的 $g$。
:::

这个估计 $\hat{g}$ 本身也是一个随机变量（因为每次采的样本不同）。它的方差：

$$
\text{Var}(\hat{g}) = \frac{\text{Var}(\nabla\log\pi \cdot A)}{N}
$$

**这个公式在做什么**：说明"用 $N$ 个样本求平均"这个操作本身会把单样本的方差缩小到 $1/N$——这是后面 batch size 越大训练越稳定的数学根源。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\text{Var}(\nabla\log\pi\cdot A)$ | **单样本的波动** | 一次采样得到的梯度贡献本身的方差有多大 |
| $N$ | **样本数量** | 一次更新用了多少条采样数据（batch size） |
| $\text{Var}(\hat g)$ | **平均后的波动** | 样本均值 $\hat g$ 的方差，随 $N$ 增大而线性缩小 |

**用人话读**："梯度估计的抖动程度，等于单个样本的抖动程度除以样本数——样本越多，估计越稳。"

**为什么是这个形式**：这是第三部分"均值的方差"运算规则（$\text{Var}(\bar X_N)=\text{Var}(X)/N$）的直接应用，前提是各个样本相互独立采样。它精确解释了为什么增大 batch size 能让策略梯度训练更稳定。
:::

**后果**：
- 方差大 → 每次估计出的梯度方向可能差别很大 → 参数更新时而往左时而往右 → 训练震荡不收敛
- 方差小 → 梯度估计稳定 → 训练平稳收敛

### 2.2 为什么 Advantage 比 Return 的方差小

用 $R(\tau)$（整条轨迹的总回报）做梯度估计，方差很大——因为 $R$ 既包含"这个动作的贡献"又包含"后续所有步骤的随机性"。

减去 baseline $V(s)$，得到 $A(s,a) = Q(s,a) - V(s)$：
- $A$ 只反映"这个动作**相对平均**好多少"
- $V(s)$ 把"状态本身的价值"（和当前动作无关的部分）减掉了
- 剩下的波动更小 → 方差更小

## 第三部分：方差的运算规则

| 规则 | 公式 | 使用场景 |
|------|------|---------|
| 常数缩放 | $\text{Var}(cX) = c^2 \text{Var}(X)$ | learning rate 放大会放大梯度方差 |
| 平移不变 | $\text{Var}(X + c) = \text{Var}(X)$ | 加 baseline 不改变方差（但选好的 baseline 可以减小被乘对象的方差） |
| 独立变量相加 | $\text{Var}(X+Y) = \text{Var}(X) + \text{Var}(Y)$ | 多步回报的方差 = 各步方差之和 |
| 均值的方差 | $\text{Var}(\bar{X}_N) = \frac{\text{Var}(X)}{N}$ | **batch size $N$ 越大，梯度估计方差越小** |

最后一条是核心：$N$ 个独立样本的均值，方差是单个样本方差的 $1/N$。

**数值例子**：单个样本的策略梯度方差是 100。
- batch size $N = 1$：$\text{Var}(\hat{g}) = 100$（极不稳定）
- batch size $N = 64$：$\text{Var}(\hat{g}) = 100/64 = 1.56$（稳定多了）
- batch size $N = 4096$：$\text{Var}(\hat{g}) = 100/4096 = 0.024$（非常稳定）

这就是为什么 PPO 通常用 2048~8192 的 batch size。

## 总结

| 概念 | 含义 | 在 RL 中的角色 |
|------|------|--------------|
| 方差 $\text{Var}(X)$ | 结果围绕均值的波动程度 | 策略梯度估计的"可信度" |
| 标准差 $\sigma$ | 方差的平方根（和 $X$ 同单位） | 策略的探索幅度 |
| $\text{Var}(\bar{X}) = \text{Var}(X)/N$ | 样本均值方差随 $N$ 下降 | batch size 越大训练越稳定 |
| 方差减小技巧 | baseline、GAE、大 batch | PPO 训练的核心工程手段 |
