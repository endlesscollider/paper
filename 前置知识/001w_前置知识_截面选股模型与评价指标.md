# 前置知识：截面选股模型与评价指标（IC/ICIR/RankIC）

> **一句话**：截面选股模型在同一个交易日把所有股票"排排坐"，预测谁涨得多谁涨得少，然后用 IC、ICIR、RankIC 来衡量"排得准不准"。

## 贯穿全文的例子

> 假设市场上只有 5 只股票 {A, B, C, D, E}。
> - 某交易日，你的模型给出预测分值：A=0.8, B=0.3, C=0.6, D=0.1, E=0.5
> - 次日实际涨幅：A=+3%, B=-1%, C=+2%, D=-2%, E=+0.5%
>
> 截面选股就是利用这些分值来排序、选出表现最好的股票组合。

## 一、什么是"截面"模型（Cross-Sectional Model）

### 1.1 时间序列 vs 截面：两种看股票的方式

股票预测有两种视角：

| 视角 | 输入 | 输出 | 典型方法 |
|------|------|------|----------|
| 时间序列（纵向） | 一只股票过去 T 天的价格序列 | 这只股票明天涨多少 | LSTM、Transformer |
| **截面（横向）** | 同一天所有 N 只股票的特征 | N 只股票的相对排名/相对收益 | 截面回归、排序学习 |

**为什么截面视角更实用？**

1. **绝对收益极难预测**：股票明天涨 1.5% 还是 1.6%，受宏观、情绪、突发事件影响极大。但"A 比 B 涨得多"这种相对关系更稳定。
2. **对冲可以消除市场风险**：买入预测排名靠前的股票、做空排名靠后的股票（多空对冲），即使大盘暴跌，只要排序正确就能盈利。
3. **实际交易策略直接可用**：选出 Top-K 只股票等权买入，就是最简单的截面选股策略。

### 1.2 截面模型的数学定义

截面模型在每个交易日 $t$ 做以下事情：

$$
\hat{y}_{i,t} = f_\theta(\mathbf{x}_{i,t}, \; \{\mathbf{x}_{j,t}\}_{j=1}^N)
$$

**这个公式在做什么**：把股票 $i$ 在第 $t$ 天的特征（以及可选的同一天所有股票特征）丢进模型，吐出一个预测分值，用来给股票排序。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\mathbf{x}_{i,t} \in \mathbb{R}^d$ | **个股档案** | 股票 $i$ 在第 $t$ 天的特征向量，通常包含价量因子（过去 5/10/20/60 日收益率、波动率、换手率等）和基本面因子（PE、PB、ROE 等） |
| $\{\mathbf{x}_{j,t}\}_{j=1}^N$ | **全场对比资料（可选）** | 同一天所有 $N$ 只股票的特征集合。简单模型（如 LightGBM）不用这一项，只看个股特征；复杂模型（如 MASTER、StockMixer）会利用股票之间的关系 |
| $f_\theta$ | **打分器** | 参数化的预测模型，把特征映射成一个分值 |
| $\hat{y}_{i,t}$ | **排位分数** | 模型对股票 $i$ 在第 $t$ 天给出的预测值（可以是预测收益率，也可以只是一个排序分数） |

**用人话读**："把一只股票自己的特征、外加（可选的）同一天所有股票的特征喂给模型，模型吐出一个分数，分数高的排前面。"

**为什么是这个形式**：公式里保留"同一天所有 $N$ 只股票的特征集合 $\{\mathbf{x}_{j,t}\}_{j=1}^N$"作为可选输入，而不是像时间序列模型那样只用单只股票自己的历史——因为截面选股关心的是股票之间的相对排序，一只股票涨跌与否往往要参照同一天其他股票的表现才有意义（比如大盘普涨 5% 时，个股只涨 2% 其实是跑输）。简单模型可以先忽略这一项、只用个股特征近似求解；复杂模型则显式利用这一项来建模股票间的关系，这也是这两类模型的根本区别所在。
:::

**关键区别**：截面模型的 batch 是"同一天的所有股票"，而不是"同一只股票的多天"。

### 1.3 具体数值例子

假设 $d=3$，特征是（5日收益率、20日波动率、换手率）：

| 股票 | 5日收益率 | 20日波动率 | 换手率 | 模型预测 $\hat{y}$ | 次日实际收益 $y$ |
|------|-----------|------------|--------|---------------------|------------------|
| A | +2.1% | 15% | 3.2% | 0.8 | +3.0% |
| B | -0.5% | 22% | 1.1% | 0.3 | -1.0% |
| C | +1.5% | 12% | 2.8% | 0.6 | +2.0% |
| D | -1.2% | 30% | 0.8% | 0.1 | -2.0% |
| E | +0.3% | 18% | 2.0% | 0.5 | +0.5% |

模型排序：A > C > E > B > D  
实际排序：A > C > E > B > D  

这个例子中模型的排序**完全正确**——这就是 RankIC = 1 的情况。

**为什么是这个形式**：公式里保留了"同一天所有 $N$ 只股票的特征集合 $\{\mathbf{x}_{j,t}\}_{j=1}^N$"作为可选输入，而不是像时间序列模型那样只用单只股票自己的历史——这是因为截面选股关心的是"股票之间的相对排序"，一只股票涨跌与否往往要参照同一天其他股票的表现才有意义（比如大盘普涨 5% 时，个股只涨 2% 其实是跑输）。简单模型（LightGBM）可以先忽略这一项、只用个股特征近似求解；复杂模型（MASTER、StockMixer）则显式利用这一项来建模股票间的关系，这也是这两类模型的根本区别所在。

## 二、IC（Information Coefficient）：预测与实际的相关性

### 2.1 定义

模型训练完之后，我们需要一个具体的数字来回答"这个模型的排序到底准不准"，不能只凭肉眼看几个例子就下结论——这个数字必须能对着几千只股票的完整截面客观计算出来，且可以逐日跟踪、和其他模型比较。IC 就是这样一个数字。

IC 是模型预测值 $\hat{y}$ 和实际未来收益 $y$ 之间的 **Pearson 相关系数**，在每个截面（交易日）上计算：

$$
\text{IC}_t = \text{Corr}(\hat{\mathbf{y}}_t, \mathbf{y}_t) = \frac{\sum_{i=1}^N (\hat{y}_{i,t} - \bar{\hat{y}}_t)(y_{i,t} - \bar{y}_t)}{\sqrt{\sum_{i=1}^N (\hat{y}_{i,t} - \bar{\hat{y}}_t)^2} \cdot \sqrt{\sum_{i=1}^N (y_{i,t} - \bar{y}_t)^2}}
$$

**这个公式在做什么**：算出"模型预测的谁高谁低"和"实际收益的谁高谁低"这两组排序有多一致——就是普通的 Pearson 相关系数。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\hat{\mathbf{y}}_t = (\hat{y}_{1,t}, \ldots, \hat{y}_{N,t})$ | **模型的排位表** | 第 $t$ 天所有 $N$ 只股票的预测值向量 |
| $\mathbf{y}_t = (y_{1,t}, \ldots, y_{N,t})$ | **真实的成绩单** | 对应的实际收益率向量 |
| $\bar{\hat{y}}_t,\ \bar{y}_t$ | **两个及格线** | 分别是预测值和实际收益的截面均值，用来判断每只股票是"超出平均"还是"低于平均" |
| 分子 $\sum_i (\hat{y}_{i,t}-\bar{\hat{y}}_t)(y_{i,t}-\bar{y}_t)$ | **同向奖励器** | 协方差：如果一只股票预测和实际都同时高于（或都低于）均值，这一项就为正，贡献越大说明两者步调越一致 |
| 分母的两个平方根 | **量纲校正尺** | 分别是预测值和实际收益的标准差，相乘后把协方差压缩到 $[-1,1]$ 区间，消除数值尺度的影响 |

**用人话读**："看预测值和实际收益是不是'同涨同跌'，同涨同跌得越一致，这个相关系数就越接近 1。"

**为什么是这个形式**：用 Pearson 相关系数而不是直接用误差（如 MSE）来评价截面模型，是因为截面选股真正关心的是"预测值的相对高低排序"而不是"预测值本身准不准"——哪怕预测值整体偏移或缩放（比如全部乘以 0.1），只要排序不变，选股策略的效果就不变。Pearson 相关系数天然对"整体线性缩放/平移"不敏感（分子分母的缩放会相互抵消），这正好匹配截面选股的需求；分母上的两个标准差归一化，则保证了 IC 的取值范围永远在 $[-1,1]$，不同天、不同模型之间可以直接比较大小。
:::

**数值例子**（用贯穿例子的数据）：

预测值 $\hat{y} = (0.8, 0.3, 0.6, 0.1, 0.5)$，均值 $\bar{\hat{y}} = 0.46$  
实际收益 $y = (3.0, -1.0, 2.0, -2.0, 0.5)$，均值 $\bar{y} = 0.5$

分子 = $(0.8-0.46)(3.0-0.5) + (0.3-0.46)(-1.0-0.5) + (0.6-0.46)(2.0-0.5) + (0.1-0.46)(-2.0-0.5) + (0.5-0.46)(0.5-0.5)$  
= $0.34 \times 2.5 + (-0.16) \times (-1.5) + 0.14 \times 1.5 + (-0.36) \times (-2.5) + 0.04 \times 0$  
= $0.85 + 0.24 + 0.21 + 0.90 + 0 = 2.20$

分母 = $\sqrt{0.34^2 + 0.16^2 + 0.14^2 + 0.36^2 + 0.04^2} \times \sqrt{2.5^2 + 1.5^2 + 1.5^2 + 2.5^2 + 0^2}$  
= $\sqrt{0.1156 + 0.0256 + 0.0196 + 0.1296 + 0.0016} \times \sqrt{6.25 + 2.25 + 2.25 + 6.25 + 0}$  
= $\sqrt{0.292} \times \sqrt{17.0}$  
= $0.540 \times 4.123 = 2.226$

$\text{IC}_t = 2.20 / 2.226 = 0.988$

这是一个非常高的 IC，因为我们的例子中预测排序几乎完美。

### 2.2 IC 的解读

| IC 范围 | 解读 | 实际意义 |
|---------|------|----------|
| > 0.1 | 很强 | 在 A 股已经是顶级因子 |
| 0.05 ~ 0.1 | 中等偏强 | 可以稳定赚钱 |
| 0.03 ~ 0.05 | 中等 | 大部分发表论文的水平 |
| 0 ~ 0.03 | 弱 | 需要大量股票分散才能体现 |
| < 0 | 反向信号 | 可能有问题，但反过来用也行 |

**为什么 IC=0.05 就能赚钱？** 因为截面有几千只股票。即使每天的预测只比随机好一点点，通过每天选 Top-50 并分散持仓，日积月累就能产生显著超额收益。这是大数定律在空间维度（股票数量）上的体现。

## 三、RankIC：更稳健的排序相关性

### 3.1 为什么需要 RankIC

Pearson IC 对异常值非常敏感。如果某只股票当天涨停（+10%），它会极大拉动整个相关系数。RankIC 解决这个问题：先把预测值和实际值都转换为**排名**，再计算相关系数。

### 3.2 定义

$$
\text{RankIC}_t = \text{Corr}\big(\text{rank}(\hat{\mathbf{y}}_t), \; \text{rank}(\mathbf{y}_t)\big)
$$

**这个公式在做什么**：不看预测值和实际收益的具体数字，只看"排第几"，再对这两组排名算相关系数——这就是 Spearman 秩相关系数。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\text{rank}(\cdot)$ | **排名转换器** | 把一个向量转换成排名向量，比如 $(0.8, 0.3, 0.6, 0.1, 0.5)$ 排名后变成 $(1, 4, 2, 5, 3)$（数值越大排名越靠前，排名为 1 表示最大） |
| $\text{rank}(\hat{\mathbf{y}}_t)$ | **模型的名次表** | 把预测值换成名次后的向量 |
| $\text{rank}(\mathbf{y}_t)$ | **真实的名次表** | 把实际收益换成名次后的向量 |
| $\text{Corr}(\cdot,\cdot)$ | **名次一致性打分器** | 对两个排名向量计算 Pearson 相关系数——因为输入已经变成排名（1,2,3,...这种均匀分布的整数），对排名做 Pearson 相关在数学上就等价于 Spearman 秩相关 |

**用人话读**："先把预测值和实际收益都换成名次，再看两组名次排得有多像。"

**为什么是这个形式**：先把数值转成排名再算相关系数，是为了让指标只依赖"顺序"而不依赖"数值大小"。涨停股 +10% 和普通股 +2% 在排名上都只是"第 1 名""第 2 名"，不会像 Pearson IC 那样因为一个极端数值就把相关系数拉得很高或很低。这正好匹配截面选股"只关心 Top-K 排序"的实际需求，所以业界更看重 RankIC。
:::

**数值例子**：

| 股票 | 预测排名 | 实际排名 |
|------|----------|----------|
| A | 1 | 1 |
| C | 2 | 2 |
| E | 3 | 3 |
| B | 4 | 4 |
| D | 5 | 5 |

排名完全一致 → RankIC = 1.0。

再看一个不完美的例子：如果预测排名是 A=1, C=2, E=3, B=4, D=5，但实际排名是 A=1, C=3, E=2, B=4, D=5（C 和 E 排反了）：

rank($\hat{y}$) = (1, 4, 2, 5, 3)，rank($y$) = (1, 4, 3, 5, 2)

$\text{RankIC} = \text{Corr}((1,4,2,5,3), (1,4,3,5,2)) = 0.9$

### 3.3 RankIC vs IC 的选择

| 特性 | IC (Pearson) | RankIC (Spearman) |
|------|-------------|-------------------|
| 对异常值敏感 | 是（一个涨停股可以主导结果） | 否（排名抹平了极端值） |
| 要求预测值的线性关系 | 是 | 否（只要单调关系即可） |
| 实际选股时更相关 | 不一定（交易时选 Top-K，关心的是排序） | **是**（直接衡量排序质量） |
| 业界使用 | 仍然广泛报告 | **更受重视** |

**结论**：RankIC 在截面选股中更重要。因为实际策略是"选排名前 50 的买入"，不关心预测值的绝对大小。MASTER 论文报告的 RankIC 0.076 在 CSI300 中已经是非常好的成绩。

## 四、ICIR（IC Information Ratio）：稳定性衡量

### 4.1 动机

IC 是单天的指标。如果模型在牛市 IC=0.1，但在熊市 IC=-0.05，平均 IC 看起来还不错，但实际表现很不稳定。ICIR 衡量的是 IC 的**稳定性**。

### 4.2 定义

$$
\text{ICIR} = \frac{\overline{\text{IC}}}{\sigma(\text{IC})}
$$

**这个公式在做什么**：把"平均预测能力"除以"预测能力的波动"，衡量模型的排序能力是不是稳定，而不是偶尔运气好。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\overline{\text{IC}} = \frac{1}{T}\sum_{t=1}^T \text{IC}_t$ | **平均战绩** | T 个交易日的 IC 均值，衡量模型整体预测能力有多强 |
| $\sigma(\text{IC}) = \sqrt{\frac{1}{T-1}\sum_{t=1}^T (\text{IC}_t - \overline{\text{IC}})^2}$ | **发挥稳定度量尺** | IC 的标准差，越小说明模型每天的表现越稳定，不会时好时坏 |
| $\text{ICIR}$ | **稳定性打分** | 平均战绩 / 发挥波动，类似 Sharpe Ratio 的结构 |

**用人话读**："模型每天预测能力的平均水平，除以这个能力的波动大小，波动越小、均值越高，这个分数就越高。"

**为什么是这个形式**：均值除以标准差这个结构和 Sharpe Ratio（收益均值/收益标准差）完全一致，都是"信号强度/信号波动"的比值——分母的标准差惩罚了"时好时坏"的不稳定表现，只有 IC 均值高**且**波动小才能拿到高 ICIR。这比只看 IC 均值更能反映模型能不能在实盘里持续稳定盈利。
:::

**数值例子**：

假设 5 天的 IC 序列为：0.08, 0.06, 0.05, 0.07, 0.04

- $\overline{\text{IC}} = 0.06$
- $\sigma(\text{IC}) = \sqrt{\frac{(0.02^2 + 0^2 + 0.01^2 + 0.01^2 + 0.02^2)}{4}} = \sqrt{\frac{0.001}{4}} = \sqrt{0.00025} = 0.0158$
- $\text{ICIR} = 0.06 / 0.0158 = 3.79$

这是一个很高的 ICIR。通常年化后（乘 $\sqrt{252}$），ICIR > 2 就算优秀。

### 4.3 ICIR 的解读

| 年化 ICIR | 解读 |
|-----------|------|
| > 3.0 | 极强且极稳定（很少见） |
| 2.0 ~ 3.0 | 优秀 |
| 1.0 ~ 2.0 | 良好 |
| 0.5 ~ 1.0 | 一般 |
| < 0.5 | 不稳定，实盘风险大 |

**为什么 ICIR 比 IC 均值更重要？**  
因为交易有成本。如果 IC 波动大，意味着有些天模型预测完全错误，那天的交易就会亏损。ICIR 高意味着"每天都稳定地选对"，这在扣除交易成本后更容易盈利。

## 五、从 IC 到实际策略：Top-K 选股

### 5.1 策略构建

截面模型的输出是"每只股票的排序分"。最简单的交易策略：

1. 每天收盘后，用模型对所有股票打分
2. 选出分数最高的 K 只股票（通常 K=30~100）
3. 等权或市值加权买入
4. 次日（或持有 N 天后）重新排序、换仓

### 5.2 评价策略表现的指标

| 指标 | 计算 | 意义 |
|------|------|------|
| **超额年化收益** | 策略收益 - 基准收益（如 CSI300） | 模型带来了多少额外回报 |
| **Sharpe Ratio** | 超额收益均值 / 标准差 × $\sqrt{252}$ | 风险调整后的收益 |
| **MDD（最大回撤）** | 从峰值到谷值的最大跌幅 | 最坏情况损失 |
| **换手率** | 每天更换的持仓比例 | 越低越好（交易成本） |
| **IR（信息比率）** | 类似 Sharpe，但用超额收益 | 和 ICIR 对应，衡量策略层面的稳定性 |

### 5.3 交易成本的重要性

一个常见错误：不考虑交易成本就宣称策略有效。

- A 股单边手续费约 0.1%~0.15%（含印花税）
- 如果每天换手 30%，年化交易成本 = 30% × 2（买+卖）× 0.15% × 252天 = **22.68%**
- 如果超额年化只有 15%，扣完成本后实际亏损

**所以正确的评估必须在扣除 30~100bps 成本后看净收益。** 这也是为什么低换手策略（如 5~10 天调仓一次）通常比日频策略更实用。

## 六、截面模型的训练：Ranking Loss vs MSE

### 6.1 为什么不能只用 MSE

直觉：我们最终关心的是排序（Top-K 选股），不是预测值的精确性。如果模型把所有股票的预测值都偏移了一个常数（如都加了 0.5），排序不变，MSE 变大了但策略完全不受影响。

### 6.2 常用损失函数

**MSE Loss**：

$$
L_{\text{MSE}} = \frac{1}{N}\sum_{i=1}^N (\hat{y}_i - y_i)^2
$$

**这个公式在做什么**：衡量模型预测值和实际收益率在数值上差了多远，误差越大惩罚越重（平方放大大误差）。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $N$ | **考生总数** | 截面股票数，当天参与预测的股票总数 |
| $\hat{y}_i,\ y_i$ | **一份答卷、一份标准答案** | 第 $i$ 只股票的预测值和实际收益率 |
| $(\hat{y}_i - y_i)^2$ | **单科扣分** | 预测和实际差得越远，这一项越大 |
| $\frac{1}{N}\sum_i$ | **全班平均分** | 对所有股票取平均，得到当天所有预测的整体误差水平 |

**用人话读**："每只股票预测值和实际收益的差，平方后再对全部股票取平均。"

**为什么是这个形式**：用平方而不是绝对值，是因为平方误差处处可导（绝对值在 0 点不可导），且对大误差惩罚更重，符合"极端错误更不能接受"的直觉；这也是假设误差服从高斯分布时的最大似然估计形式。
:::

**数值代入**：取三只股票 A、B、C，预测值 $\hat{y}=(0.8, 0.3, 0.1)$，实际收益 $y=(3.0, -1.0, -2.0)$：

- A：$(0.8-3.0)^2 = (-2.2)^2 = 4.84$
- B：$(0.3-(-1.0))^2 = 1.3^2 = 1.69$
- C：$(0.1-(-2.0))^2 = 2.1^2 = 4.41$
- 求和：$4.84+1.69+4.41=10.94$，除以 $N=3$：$L_{\text{MSE}} = 3.65$

注意：这三只股票的**排序**其实是完全正确的（A>B>C，实际也是 A>B>C），但 MSE 依然很大——因为预测值的绝对数值尺度（0.1~0.8）和实际收益率的尺度（-2%~3%）不一样。这正是 6.1 节说的问题：MSE 会惩罚"排对了但数值不匹配"的情况，而截面选股真正关心的只是排序。

**Ranking Loss**（Pairwise）：

$$
L_{\text{rank}} = \frac{1}{|P|}\sum_{(i,j) \in P} \max(0, -(y_i - y_j)(\hat{y}_i - \hat{y}_j))
$$

**这个公式在做什么**：不看数值大小，只检查"每一对股票的相对顺序有没有排反"，排反了才罚——对于所有实际收益 $y_i > y_j$ 的股票对，要求模型预测也满足 $\hat{y}_i > \hat{y}_j$。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $P$ | **待比较配对名单** | 所有需要比较的股票对集合，通常取实际收益 $y_i \neq y_j$ 的全部两两组合 |
| $(y_i - y_j)$ | **真实顺序裁判** | 实际收益的顺序信号，大于 0 说明 $i$ 该排在 $j$ 前面 |
| $(\hat{y}_i - \hat{y}_j)$ | **模型顺序裁判** | 预测值的顺序信号，大于 0 说明模型也认为 $i$ 排在 $j$ 前面 |
| $-(y_i-y_j)(\hat{y}_i-\hat{y}_j)$ | **一致性检测器** | 两个裁判同号（顺序一致）时这一项为负；异号（排反）时为正 |
| $\max(0, \cdot)$ | **只罚错不罚对的门卫** | 排对了直接归零，不产生梯度；排反了才放行惩罚 |
| $\frac{1}{|P|}\sum$ | **配对平均** | 对所有配对取平均，让 loss 不随股票数变化而膨胀 |

**用人话读**："把所有股票两两配对，凡是模型排序和实际排序不一致的配对，都要挨罚；排对了的配对不产生任何惩罚。"

**为什么是这个形式**：用 $\max(0,\cdot)$ 是一个 hinge 形式，只在排错的时候产生梯度、排对了梯度为零，这样模型不会为了追求"排序余量越大越好"而无限拉大预测值差距，训练更稳定。
:::

**数值代入**：仍用 A、B、C 三只股票，$\hat{y}=(0.8, 0.3, 0.1)$，$y=(3.0, -1.0, -2.0)$，$|P|=3$（三对组合）：

- $(A,B)$：$y_A-y_B = 3.0-(-1.0)=4.0$，$\hat{y}_A-\hat{y}_B=0.8-0.3=0.5$，乘积 $=2.0$，取负 $=-2.0$，$\max(0,-2.0)=0$
- $(A,C)$：$y_A-y_C=5.0$，$\hat{y}_A-\hat{y}_C=0.7$，乘积 $=3.5$，取负 $=-3.5$，$\max(0,-3.5)=0$
- $(B,C)$：$y_B-y_C=1.0$，$\hat{y}_B-\hat{y}_C=0.2$，乘积 $=0.2$，取负 $=-0.2$，$\max(0,-0.2)=0$
- $L_{\text{rank}} = (0+0+0)/3 = 0$——因为三对的顺序全部排对了，loss 为 0

现在换一个模型把 B、C 排反的情况：$\hat{y}_B=0.05 < \hat{y}_C=0.1$（模型认为 C 该排在 B 前面，但实际 B 该排在 C 前面）：

- $(B,C)$：$y_B-y_C=1.0>0$（B 该在前），$\hat{y}_B-\hat{y}_C=0.05-0.1=-0.05<0$（模型排反了），乘积 $=-0.05$，取负 $=0.05$，$\max(0,0.05)=0.05$
- 这一对产生了 $0.05$ 的惩罚——梯度会推动 $\hat{y}_B$ 增大、$\hat{y}_C$ 减小，把顺序纠正回来

**ListMLE / ListNet**：直接优化整个列表的排列概率。

### 6.3 实践中的选择

大多数 SOTA 模型使用 **MSE + IC 正则** 或 **MSE + Ranking Loss** 的混合损失：

$$
L = \underbrace{L_{\text{MSE}}}_{\text{拉数值往接近真实收益}} + \lambda \cdot \underbrace{L_{\text{rank}}}_{\text{拉排序往和实际一致}}
$$

**这个公式在做什么**：把"数值要准"和"排序要对"两个目标加权相加，用一个 loss 同时优化两件事。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $L_{\text{MSE}}$ | **数值教练** | 把预测值往实际收益率的绝对数值上拉，不管排序 |
| $L_{\text{rank}}$ | **排序教练** | 只在排序反了时产生梯度，把排反的股票对的预测值往正确顺序拉，不管绝对数值 |
| $\lambda$ | **两位教练话语权分配旋钮** | 控制"排序要对"相对于"数值要准"的重要程度，典型取值 0.1~1.0 |

**用人话读**："数值误差和排序误差各算一份，排序误差乘一个权重后加到数值误差上，作为总的训练目标。"

**为什么是这个形式**：直接相加是最简单的多目标优化方式，$\lambda$ 提供了一个可调的旋钮——如果策略只关心 Top-K 排序，可以调大 $\lambda$；如果还想让预测值本身有意义（比如用于仓位加权），可以调小 $\lambda$ 保留更多 MSE 的约束。
:::

**两项之间的博弈**：单用 $L_{\text{MSE}}$ 会让模型纠结于数值尺度（比如强行把预测值也拉到 -2%~3% 这个区间），但截面选股只关心排序；单用 $L_{\text{rank}}$ 又会丢掉数值信息（比如预测值可能被拉到不合理的范围，影响 IC 这类依赖数值相关性的评估指标）。加权求和让两者互相牵制：$L_{\text{MSE}}$ 保证预测值大体上"靠谱"，$L_{\text{rank}}$ 保证排序不出大错。

**数值代入**：取 6.2 节"B、C 排反"的例子，$\lambda=0.1$：

- $L_{\text{MSE}}$（用排反后的预测值 $\hat{y}=(0.8,0.05,0.1)$ 重新计算）：$(0.8-3.0)^2=4.84$，$(0.05-(-1.0))^2=1.1025$，$(0.1-(-2.0))^2=4.41$，求和 $=10.3525$，除以 3 得 $3.4508$
- $L_{\text{rank}} = 0.05/3 = 0.0167$（只有 $(B,C)$ 这一对贡献了惩罚）
- $L = 3.4508 + 0.1 \times 0.0167 = 3.4508 + 0.00167 = 3.4525$

可以看到数值上 $L_{\text{MSE}}$ 的量级远大于 $L_{\text{rank}}$，这也是为什么 $\lambda$ 通常需要根据两项 loss 的实际数值量级来调（比如先分别打印两项 loss 的均值，再选一个能让两者贡献相当的 $\lambda$），否则排序信号会被数值误差项"淹没"。

IC 正则化可以表示为：

$$
L_{\text{IC-reg}} = -\text{Corr}(\hat{\mathbf{y}}, \mathbf{y})
$$

**这个公式在做什么**：把"最大化 IC"这个目标转换成一个可以用梯度下降**最小化**的 loss。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\text{Corr}(\hat{\mathbf{y}}, \mathbf{y})$ | **本文第二节的 $\text{IC}_t$** | 预测值和实际收益的 Pearson 相关系数，定义和拆解已在第二节给出，这里直接复用 |
| $-(\cdot)$ | **方向反转开关** | 把"越大越好"的指标翻转成"越小越好"的 loss |

**用人话读**："IC 越高说明预测越准，取负号后就变成了越准 loss 越低，可以直接喂给梯度下降。"

**为什么是这个形式**：优化器的标准设定是最小化 loss，而 IC 是"越大越好"的指标，取负号就把"最大化一个量"变成了标准的"最小化 loss"问题，不需要额外实现一个反向的优化器。
:::

**数值代入**：复用第二节数值例子中算出的 $\text{IC}_t = 0.988$，则 $L_{\text{IC-reg}} = -0.988$。这是一个很小（很负）的 loss 值，说明当前预测和实际收益高度相关——梯度下降会倾向于维持这种高相关性，不会有大的更新方向。如果某天 IC 掉到 0.02，$L_{\text{IC-reg}}=-0.02$，loss 明显"不够负"，梯度会推动模型调整参数以提高相关性。

## 七、截面模型的 DataLoader 设计（工程关键）

### 7.1 错误做法：随机打散单股票窗口

很多初学者会这样组织数据：

```python
# 错误！截面模型不能这样
dataset = [(stock_i_features_day_t, stock_i_return_day_t) for all i, t]
dataloader = DataLoader(dataset, shuffle=True, batch_size=64)
```

这样一个 batch 里混了不同天的不同股票——没法计算截面 IC，也没法做 stock mixing。

### 7.2 正确做法：同一天的所有股票组成一个 batch

```python
# 正确：每个样本是"一整天的截面"
class CrossSectionalDataset:
    def __getitem__(self, idx):
        date = self.dates[idx]
        # 返回该天所有股票的特征和标签
        features = self.data[date]  # shape: (N_stocks, d_features)
        returns = self.labels[date]  # shape: (N_stocks,)
        return features, returns

dataloader = DataLoader(dataset, batch_size=1)  # 每个 batch 是一个截面
```

**为什么这很重要？**
1. 截面模型（如 StockMixer、MASTER）需要看到同一天所有股票来建模股票间关系
2. Ranking Loss 需要在同一截面内比较
3. 评估 IC/RankIC 必须在同一截面内计算

## 八、总结

| 概念 | 核心含义 | 记忆口诀 |
|------|----------|----------|
| 截面模型 | 同一天排所有股票 | "同一天，排排坐" |
| IC | 预测值和实际收益的 Pearson 相关 | "线性相关有多强" |
| RankIC | 预测排名和实际排名的 Spearman 相关 | "排序排得准不准" |
| ICIR | IC 均值 / IC 标准差 | "又准又稳" |
| Top-K | 选分最高的 K 只买入 | 截面模型的直接应用 |
