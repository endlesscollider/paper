# 前置知识：标量条件编码——位置编码、时间步嵌入与随机傅里叶特征

> **一句话**：神经网络看到一个孤零零的标量（比如"这是第 5 个词""现在是第 250 步去噪""当前时刻 $t=0.37$"）时，很难直接利用它——把这个标量先映射成一组不同频率的正弦/余弦波，再喂给网络，几乎所有需要"告诉网络当前处于哪个位置/哪个时刻"的场景（Transformer、扩散模型、Flow Matching、NeRF）都在用这同一个底层技巧，只是具体配方不同。

## 贯穿全文的例子

> **场景**：一个扩散/flow 生成网络，每次前向都需要知道"现在处于生成过程的第几步"——这个信息用一个标量 $t$ 表示（可能是离散的整数步数 $k\in\{0,1,\ldots,K\}$，也可能是连续的归一化时刻 $t\in[0,1]$）。网络需要把这个标量转换成一个能被神经网络有效利用的向量，才能在不同时刻表现出不同的行为（早期去噪时大刀阔斧，后期去噪时精细微调）。本文所有编码方式都会用这个场景反复演算。

## 一、基础原理阶段：为什么不能直接把标量塞给网络

### 1.1 最直接的做法，以及它为什么不好用

假设网络需要知道当前时刻 $t=0.37$，最直接的做法是把这个数字原样拼进输入向量：

$$
\text{输入} = [\text{观测特征}, \; 0.37]
$$

**这样做会出什么问题**：网络的第一层通常是一个线性层 $y = Wx+b$，如果 $t$ 只占输入向量里的一个维度，这个维度对输出的影响就只能是**线性**的——$t$ 变化一点，$y$ 只能跟着做简单的比例变化。但真实场景里,"时间"对结果的影响几乎从来不是线性的：扩散模型里,$t$ 接近 1（几乎是纯噪声）时网络该做的事和 $t$ 接近 0（几乎是干净数据）时该做的事有本质区别,这种区别不是"数值大一点、输出就跟着大一点"能表达的。

**一个具体的失败例子**：假设网络需要学会"当 $t<0.3$ 时输出接近 0，当 $t>0.7$ 时输出接近 1，中间平滑过渡"——这是一个非线性的阶梯状函数。如果 $t$ 只是原始标量输入，网络的第一层只能给它乘一个固定权重再加偏置，后续层需要用大量非线性激活函数的组合才能勉强拼出这种阶梯形状,而且不同的 $t$ 区间之间会互相"纠缠"——调整网络去更好拟合 $t$ 接近 0 那一段,很容易连带影响 $t$ 接近 1 那一段的行为，因为它们共享的是同一个标量输入通道。

### 1.2 解决思路：把一个标量"展开"成多个不同频率的通道

所有本文要讲的方法,核心思路都是同一件事:**不要让网络直接面对一个孤零零的数字,而是先把这个数字变换成一个高维向量,向量里的每一维分别负责捕捉这个数字在"不同粒度/不同频率"下的信息**。

打一个类比:想象你要向别人描述"现在几点"。如果只说"现在是第 37 分钟"(一个数字),对方很难直接感知这意味着什么。但如果你同时提供多种粒度的信息——"现在是这一天的第 37 分钟"、"现在是这一小时的第 37 分钟"（也就是差 23 分钟到下一小时）、"现在是这一秒的进度"——组合起来的信息量远超单个数字,不同的下游任务可以各自挑选自己需要的那个粒度来用。这正是下面几种编码方法在做的事——用不同"频率"的正弦波,从粗粒度到细粒度,把一个标量的信息展开铺陈开。

## 二、概念阶段之一：正弦位置编码（Transformer 的原始方案）

### 2.1 要解决的问题

Transformer 处理一个词序列时，Attention 机制本身对"词的顺序"是不敏感的（打乱输入顺序，Attention 算出来的结果只是被同样打乱，内部计算逻辑不变）。但语言显然是有顺序的("狗咬人"和"人咬狗"意思完全不同)，所以需要一种方式，把"这是序列里第几个位置"这个信息也编码进每个词的向量表示里。

### 2.2 公式

$$
PE(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d}}\right), \qquad PE(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d}}\right)
$$

**为什么需要这个公式**：我们需要给序列里第 $pos$ 个位置生成一个 $d$ 维的向量，这个向量要满足两个条件——不同位置的编码要能被区分开（不能"撞车"），而且相近的位置编码应该也比较接近（位置 5 和位置 6 的编码不应该天差地别）。这个公式用一组不同频率的正弦/余弦波组合出这样的向量。

> **一句话直觉**：把"第几个位置"这件事,用一排快慢不同的时钟的指针角度来表示——走得快的时钟（高频）能分辨相邻位置的细微差别,走得慢的时钟（低频）能标记大范围的位置区间,组合起来就能唯一确定任意一个位置。

**逐项拆解**：

| 符号 | 数学含义 | 直觉 | 在例子中对应什么 |
|------|---------|------|-----------------|
| $pos$ | 序列中的位置编号（0, 1, 2, ...） | "这是第几个词" | 一句话里某个词的位置 |
| $i$ | 维度对的编号，$i=0,1,\ldots,d/2-1$ | "第几组时钟" | 决定这一组正弦波的频率 |
| $d$ | 编码向量的总维度 | "总共有多少组时钟" | 比如 512 维，就有 256 组正弦/余弦对 |
| $10000^{2i/d}$ | 分母，随 $i$ 增大而指数增长 | "第 $i$ 组时钟走得多慢" | $i=0$ 时分母是 1（最快的钟），$i$ 越大分母越大（越慢的钟） |
| $\sin(\cdot), \cos(\cdot)$ | 正弦、余弦函数 | 用一对相位相差 90° 的波，联合起来能唯一确定"指针角度"（不会因为角度周期性而混淆） | 同一组"时钟"的两根指针 |

**具体数值例子**：取 $d=4$（只有 2 组时钟），计算位置 $pos=1$ 和 $pos=2$ 的编码：

- $i=0$：分母 $10000^{0/4}=1$。$PE(1,0)=\sin(1/1)=\sin(1)=0.841$，$PE(1,1)=\cos(1)=0.540$；$PE(2,0)=\sin(2)=0.909$，$PE(2,1)=\cos(2)=-0.416$
- $i=1$：分母 $10000^{2/4}=100$。$PE(1,2)=\sin(1/100)=0.010$，$PE(1,3)=\cos(0.01)=0.99995$；$PE(2,2)=\sin(0.02)=0.020$，$PE(2,3)=\cos(0.02)=0.9998$

得到 $PE(1)=[0.841, 0.540, 0.010, 0.99995]$，$PE(2)=[0.909, -0.416, 0.020, 0.9998]$。**观察这两个向量**：低频那一组（第 3、4 维，$i=1$）几乎没变化（$0.010\to0.020$），因为"慢时钟"走一步的角度变化很小；高频那一组（第 1、2 维，$i=0$）变化明显（$0.841\to0.909$），因为"快时钟"对相邻位置很敏感。这正是"不同频率捕捉不同粒度信息"这句话的具体体现。

**为什么是这个形式（为什么用 $10000$ 这个底数，为什么正余弦成对出现）**：$10000$ 只是一个足够大的经验数值，保证最慢的那组"时钟"的周期远超实际序列长度（不会出现"转了一圈回到起点、和另一个位置撞车"的情况）；正余弦成对出现是为了让"任意两个位置编码之间的关系"可以用一个固定的线性变换表示（这是三角函数加法公式的性质：$PE(pos+k)$ 可以写成 $PE(pos)$ 的一个线性函数,和 $k$ 有关但不显式依赖 $pos$ 本身），这让模型更容易学到"相对位置"的概念,而不只是"绝对位置"。

## 三、概念阶段之二：时间步嵌入（扩散模型的具体用法）

### 3.1 和位置编码的关系：同一个公式，换了一个应用场景

扩散模型（[DDPM 前置知识第 6.1 节](/前置知识/000b_前置知识_扩散模型DDPM#6.1-时间步嵌入-timestep-embedding)）需要让去噪网络知道"现在是第几步去噪"——这个需求在数学结构上和 Transformer 的"这是第几个词"完全一样,都是"给一个离散整数生成一个向量表示"，所以扩散模型直接**借用**了上面那套正弦位置编码公式,只是把 $pos$ 换成了扩散步数 $k$：

$$
k \;\to\; \text{sinusoidal embedding}(k) \;\to\; \text{MLP} \;\to\; \text{时间步特征向量}
$$

**为什么多了一层 MLP**：位置编码在 Transformer 里通常是直接加到词向量上；但扩散模型的时间步信息，需要参与调制网络中间层的行为（比如后面 [AdaLayerNorm](/前置知识/001f_前置知识_AdaLayerNorm条件化归一化) 里讲的"用时间步向量去缩放/平移某一层的输出"），这需要一个更灵活的、非固定的映射——正弦编码出来的向量先过一个小 MLP（通常是两层带激活函数的全连接），让网络自己学会怎么把"原始的多频率信息"进一步加工成最适合调制任务的形式。这一步 MLP 是可训练的，正弦编码那一步不是（下一节会讲这个"是否可训练"的区分）。

### 3.2 一个容易忽略的问题：$k$ 是整数还是连续值

上面公式里的 $pos$/$k$ 在 Transformer 和 DDPM 里都是**离散整数**（第几个词、第几步去噪）。但很多现代生成模型（比如 Flow Matching）里的时间是一个**连续值** $t\in[0,1]$（不是"第几步"，而是"走到了整个路径的百分之多少"）。正弦位置编码公式本身对这一点是无所谓的——$\sin(t/10000^{2i/d})$ 这个式子里 $t$ 可以取任意实数,不需要是整数。但当"编码一个连续标量"变成主要需求时，另一种更专门为此设计的方法——随机傅里叶特征——用得更广泛,下一节详细讲。

## 四、概念阶段之三：随机傅里叶特征（更通用的连续标量编码）

### 4.1 要解决的问题

正弦位置编码里,每一组"时钟"的频率是**手工设计、固定不变**的（由 $10000^{2i/d}$ 这个公式直接决定，训练前就定好了）。这在"位置是整数、范围可预期"的场景（比如序列长度不超过几千）里够用，但在一些场景里（比如 [Flow Matching 前置知识](/前置知识/000g_前置知识_Flow_Matching与连续归一化流) 里网络要处理连续时刻 $t\in[0,1]$，或者 NeRF 里网络要处理连续的三维坐标），手工设计的固定频率不一定是最优的——不同任务、不同数据分布，可能需要不同的频率组合才能让网络学得又快又好。

### 4.2 公式

$$
\gamma(t) = \big[\cos(2\pi \mathbf{w}_1 t), \sin(2\pi \mathbf{w}_1 t), \ldots, \cos(2\pi \mathbf{w}_m t), \sin(2\pi \mathbf{w}_m t)\big], \qquad \mathbf{w}_j \sim \mathcal{N}(0, \sigma^2)\ \text{或按对数尺度均匀采样}
$$

**为什么需要这个公式**：和正弦位置编码解决的是同一类问题（给标量 $t$ 一个能被网络有效利用的高维表示），但这里不再手工规定频率的具体数值，而是把频率 $\mathbf{w}_j$ 当成**随机采样出来**（或者在某些实现里设成可学习参数）的一组数,不再局限于 $10000^{2i/d}$ 这一种固定的指数衰减规律。这让编码方式能更灵活地适配"标量的取值范围不是整数、不一定有一个自然的最大长度"这种场景。

> **一句话直觉**：不再用一组"事先商量好节奏"的时钟，而是随手扔一把频率各不相同的音叉,让标量 $t$ 去敲响每一个音叉,记录下每个音叉振动的相位——足够多、足够杂乱的音叉组合起来,就能唯一、平滑地刻画任意一个 $t$ 的取值。

**逐项拆解**：

| 符号 | 数学含义 | 直觉 | 在例子中对应什么 |
|------|---------|------|-----------------|
| $t$ | 要编码的连续标量 | "当前时刻" | Flow Matching 里的归一化时间 $t\in[0,1]$ |
| $\mathbf{w}_j$ | 第 $j$ 个随机频率 | "第 $j$ 个音叉的振动频率" | 通常从某个分布里采样一次，之后固定下来（不随训练变化，除非显式设为可学习） |
| $m$ | 频率的总数量 | "有多少个音叉" | 决定编码向量的维度（$2m$ 维，因为每个频率贡献 cos 和 sin 两维） |
| $\cos(2\pi\mathbf{w}_j t), \sin(2\pi\mathbf{w}_j t)$ | 标量 $t$ 在第 $j$ 个频率下的相位 | "音叉振动到了哪个角度" | 具体的编码数值 |

**具体数值例子**：取 $m=2$ 个频率，$\mathbf{w}=(1, 8)$（一慢一快），编码 $t=0.1$ 和 $t=0.15$：

- 频率 $1$：$\cos(2\pi\times1\times0.1)=\cos(0.628)=0.809$，$\sin(0.628)=0.588$；$t=0.15$ 时 $\cos(2\pi\times0.15)=\cos(0.942)=0.588$，$\sin(0.942)=0.809$
- 频率 $8$：$\cos(2\pi\times8\times0.1)=\cos(5.027)=0.309$，$\sin(5.027)=-0.951$；$t=0.15$ 时 $\cos(2\pi\times8\times0.15)=\cos(7.540)=0.309$（注意这里已经过了大半个周期）

**观察**：低频（$\mathbf{w}=1$）那一对，$t$ 从 0.1 变到 0.15（变化 0.05）时，编码值变化比较平缓（$0.809\to0.588$）；高频（$\mathbf{w}=8$）那一对，同样 0.05 的变化，因为频率更高，相位转过的角度更大，捕捉到了更精细的差异。这和正弦位置编码里"快时钟/慢时钟"的直觉完全一致——随机傅里叶特征只是把"频率具体是多少"这件事从"手工公式决定"换成了"随机采样决定"。

**为什么是这个形式（为什么要随机采样频率，而不是继续手工设计）**：这背后有一个理论支撑——[Tancik et al., 2020](https://arxiv.org/abs/2006.10739) 的工作证明,用随机傅里叶特征编码低维坐标输入,能显著缓解神经网络"天生偏好学习低频函数"的问题（这个现象称为"频谱偏差"，spectral bias）。直接学习输入到输出的映射，网络会自动倾向于学出一个过于平滑、丢失细节的函数；先把输入过一层随机傅里叶特征展开，相当于人为地把各种频率的信息"喂"给网络，让网络更容易学到本来学不到的高频细节（比如图像里锐利的边缘、Flow Matching 里时间维度上突变的行为）。随机（而不是固定公式）采样频率的好处是频率分布更"均匀地覆盖"整个感兴趣的频率范围，不会像固定指数公式那样只密集覆盖某几个特定的尺度。

### 4.3 一个决定编码效果好坏的关键超参数：频率的尺度 $\sigma$

$\mathbf{w}_j$ 采样自 $\mathcal{N}(0,\sigma^2)$ 时，$\sigma$ 决定了这组随机频率总体偏"快"还是偏"慢"。$\sigma$ 太小，所有频率都很低，编码出来的向量对 $t$ 的微小变化几乎没有区分度（相当于所有音叉都是慢悠悠的大摆钟，捕捉不到细节）；$\sigma$ 太大，频率太高，编码值对 $t$ 的微小扰动过于敏感（相位转得太快，反而让相近的 $t$ 编码出差异巨大的结果，训练变得不稳定）。这是使用随机傅里叶特征时需要根据具体任务调试的一个实践细节。

## 五、另外两条不同的路：可学习位置嵌入与 RoPE（简要对比）

上面讲的都是"用固定公式或随机采样、不需要训练"的编码方式。这里简要提两条不同思路，帮助建立更完整的认知地图（不是本文重点，只做区分说明）：

**可学习位置嵌入（Learned Positional Embedding）**：不用任何三角函数公式，直接给每个位置/每个整数时间步维护一个可训练的向量（本质上是一个查表操作，类似词嵌入）。优点是完全交给训练数据去决定"什么样的编码最有用"；缺点是**不能泛化到训练时没见过的位置**（比如训练时序列最长 512，推理时遇到第 600 个位置，查表会直接失败或者需要额外处理），而正弦编码/随机傅里叶特征因为是一个连续函数，天然能处理任意范围的输入。

**RoPE（Rotary Position Embedding，旋转位置编码）**：现代大语言模型（LLaMA、Qwen 等）广泛使用的方案，思路和前面几种都不一样——不是把位置信息编码成一个独立的向量再和内容向量相加/拼接，而是直接把位置信息"旋转"进 Attention 计算里的 Query/Key 向量本身（对向量的每一对维度做一个和位置相关的旋转变换）。它的核心优势是天然编码了"相对位置"关系（两个 token 的 Attention 分数只依赖它们之间的距离，不依赖绝对位置），这对长序列泛化更友好。RoPE 的具体机制值得单独成文，这里先记住它是和"先编码成向量再拼接"完全不同的第三条路线。

---

## 六、怎么选：一张对照表

| 方法 | 输入类型 | 是否需要训练 | 典型应用场景 | 能否泛化到训练时没见过的范围 |
|------|---------|-------------|-------------|------------------------------|
| 正弦位置编码 | 离散整数（也可以是连续值） | 不需要（固定公式） | Transformer 原始论文、DDPM 时间步嵌入 | 能（公式对任意输入都成立） |
| 随机傅里叶特征 | 连续标量/低维坐标 | 频率通常固定不训练，只有后续 MLP 训练 | Flow Matching 时间编码、NeRF 坐标编码 | 能，且对高频细节的表达力更强 |
| 可学习位置嵌入 | 离散整数 | 需要（直接训练嵌入表） | 早期 Transformer 变体、一些固定长度序列任务 | 不能（超出训练范围直接失效） |
| RoPE | 离散整数（token 位置） | 不需要额外参数，直接嵌入 Attention 计算 | 现代 LLM（LLaMA/Qwen 等） | 能，且天然编码相对位置 |

**一个实用的判断标准**：如果编码对象是"离散、有限、训练时能覆盖到的范围"（比如固定长度的动作 token 序列），可学习位置嵌入或正弦编码都可以；如果编码对象是"连续标量，取值范围在训练/推理时可能不完全一致"（比如 Flow Matching 里的 $t\in[0,1]$，或者不同分辨率图像的像素坐标），随机傅里叶特征通常表现更好，这也是为什么 [Q-Chunking 官方代码完全解析第 2 章](/系列/qc_training_deep_dive/02_网络架构大盘点_四个网络长什么样) 里 `ActorVectorField` 编码 flow matching 的连续时间 $t$ 时用的是 `FourierFeatures` 而不是查表式的位置嵌入。

## 七、工程实操阶段：代码里怎么写

### 7.1 正弦位置编码 / 时间步嵌入的标准实现

下面这段代码的核心思路是：先按公式算出一组随频率指数衰减的分母，标量乘上这组分母的倒数得到一组"相位"，再对这组相位分别取 cos 和 sin 拼接起来——这是 Transformer 原始论文和大多数扩散模型代码里时间步嵌入的标准写法：

```python
class FourierFeatures(nn.Module):
    output_size: int = 64
    learnable: bool = False

    def __call__(self, x):
        if self.learnable:
            # 可学习频率：随机傅里叶特征的可训练版本
            w = self.param('kernel', nn.initializers.normal(0.2), (self.output_size // 2, x.shape[-1]))
            f = 2 * jnp.pi * x @ w.T
        else:
            # 固定频率：标准正弦位置编码公式
            half_dim = self.output_size // 2
            f = jnp.log(10000) / (half_dim - 1)
            f = jnp.exp(jnp.arange(half_dim) * -f)   # 对应公式里的 1/10000^(2i/d) 这组分母
            f = x * f
        return jnp.concatenate([jnp.cos(f), jnp.sin(f)], axis=-1)
```

**代码里值得注意的一行**：`learnable=False` 分支和第二节讲的正弦位置编码公式是同一件事——`jnp.exp(jnp.arange(half_dim) * -f)` 算出的就是那一组指数衰减的分母（等价于 $10000^{-2i/d}$）；`learnable=True` 分支则是第四节随机傅里叶特征的一个**可训练**变体——不是训练前随机采样一次固定下来，而是把频率 `w` 做成一个可学习参数，让梯度下降自己去调整最适合当前任务的频率组合。

### 7.2 后接 MLP：把编码向量加工成任务需要的形式

```python
class TimestepEmbedding(nn.Module):
    hidden_dim: int
    def __call__(self, t):
        emb = FourierFeatures(output_size=self.hidden_dim)(t)
        emb = nn.Dense(self.hidden_dim)(emb)
        emb = nn.silu(emb)
        emb = nn.Dense(self.hidden_dim)(emb)
        return emb
```

这对应第三节讲的"正弦编码 → MLP"两步流程——先用固定或半固定的三角函数展开捕捉多频率信息，再用一个小 MLP 把这个原始展开加工、压缩成后续网络（比如 [AdaLayerNorm](/前置知识/001f_前置知识_AdaLayerNorm条件化归一化) 的调制模块）真正需要的向量形式。
