# Focal Loss：让损失函数自动"少管"容易样本，"多管"难样本

> **一句话总结**：给标准交叉熵乘上一个随预测置信度动态变化的调制因子 $(1-p_t)^\gamma$——模型已经很有把握的样本，损失被压得几乎归零；模型还没搞懂的样本，损失基本不受影响。这样，海量"一眼就能分对"的样本不会再把训练过程淹没。
>
> **为什么要学这个**：任何存在"少数类样本极度稀少、多数类样本极度泛滥"的分类任务——目标检测里的背景框 vs 目标框、风控里的正常交易 vs 欺诈交易、医学影像里的正常区域 vs 病灶区域——都会遇到标准交叉熵"被多数类拖着走"的问题。Focal Loss 是解决这类问题最简洁有效的手段之一，理解它能让你看懂后续几乎所有"密集预测"类模型（检测、分割）的训练目标设计。

## 贯穿全文的例子

> **场景**：你在训练一个二分类器，判断"一张候选图像区域里是否包含目标物体"。训练集里有 10000 个候选区域，其中 9900 个是背景（没有目标，标签 0），只有 100 个真正包含目标（标签 1）——背景和目标的比例接近 **99:1**。
>
> 这不是一个刻意构造的极端例子。任何"先大量生成候选、再逐一判断"的系统（目标检测的候选框、风控系统的候选交易、推荐系统的候选物料）天然都是这种比例——多数候选一眼就能排除，只有极少数值得认真判断。本文接下来会反复用这个"9900 背景 : 100 目标"的场景，代入具体数字看交叉熵和 Focal Loss 的表现差异。

---

## 1. 问题的根源：标准交叉熵被"多数票"淹没

### 1.1 二分类交叉熵回顾

[交叉熵损失与 Softmax](/前置知识/003f_前置知识_交叉熵损失与Softmax) 已经完整讲过多分类场景下 softmax + 交叉熵的推导。这里只需要它的二分类特例：模型对某个样本输出一个概率 $p\in[0,1]$（表示"这个样本属于标签为 1 的那一类"的置信度），真实标签 $y\in\{1,-1\}$，交叉熵（Cross Entropy, CE，衡量预测概率分布和真实标签之间差距的标准损失函数）定义为：

$$
\text{CE}(p, y) = \begin{cases} -\log(p) & y=1 \\ -\log(1-p) & y=-1 \end{cases}
$$

**这个公式在做什么**：不管真实标签是 1 还是 -1，都只看"模型给正确答案打的置信度"，置信度越低惩罚越重——这和 [交叉熵前置知识](/前置知识/003f_前置知识_交叉熵损失与Softmax) 里 $-\log p_y$ 的逻辑完全一致，只是这里只有两个类别，需要按标签选择对应的分支。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $p$ | **模型对"正类"的置信度** | 神经网络最后一层过 sigmoid 输出的值，落在 $(0,1)$ 之间 |
| $y=1$ 分支：$-\log(p)$ | **正类的扣分规则** | 如果真实标签是"有目标"，直接用 $p$（模型对"有目标"的信心）算惩罚 |
| $y=-1$ 分支：$-\log(1-p)$ | **负类的扣分规则** | 如果真实标签是"背景"，用 $1-p$（模型对"是背景"的信心）算惩罚——因为 $p$ 是"有目标"的置信度，$1-p$ 才是"背景"的置信度 |

**用人话读**："不管这个样本真实是背景还是目标，只看模型对'正确答案'那一类给出的置信度有多高，置信度越低扣分越重。"

**为什么要分两个分支写**：这是二分类特有的写法技巧——用一个统一的符号 $p_t$（下面马上定义）把两个分支合并成一行公式，方便后续统一讨论调制因子怎么加进去。
:::

### 1.2 统一记号：$p_t$

为了不用每次都写"if-else"两个分支，定义一个统一变量：

$$
p_t = \begin{cases} p & y=1 \\ 1-p & y=-1 \end{cases}
$$

**这个公式在做什么**：把"正类用 $p$、负类用 $1-p$"这两条规则合并成一个统一变量 $p_t$——不管真实标签是正是负，$p_t$ 永远表示"模型对真实类别的置信度"。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $y=1$ 时取 $p$ | **正类的信心值** | 真实标签是正类时，模型对"正类"的置信度 $p$ 本身就是"对真实类别的置信度" |
| $y=-1$ 时取 $1-p$ | **负类的信心值** | 真实标签是负类时，$p$ 衡量的是"正类"的置信度，所以要用 $1-p$ 才能表示"对负类（即真实类别）的置信度" |
| $p_t$ | **统一视角下的"答题信心"** | 不管标签正负，都指向同一件事：模型这次答对真实类别的信心有多高 |

**用人话读**："不管这道题真实答案是正类还是负类，$p_t$ 都表示模型对那个真实答案给出的置信度。"

**为什么要引入这个记号**：定义 $p_t$ 后，交叉熵可以统一写成一行 $\text{CE}(p_t)=-\log(p_t)$，不用再分两个分支讨论——这是纯粹的记号简化，方便后面统一讨论调制因子怎么加进去。
:::

### 1.3 用贯穿全文的例子看问题出在哪

回到"9900 背景 : 100 目标"的场景。假设模型已经训练得还不错——对大多数背景样本，$p_t$ 能达到 0.9 以上（模型很确信这是背景）；但对目标样本，因为数量太少、特征更难学，$p_t$ 只能达到 0.3 左右（模型没什么把握）。

分别算一下单个样本的交叉熵损失：

- 背景样本（容易，$p_t=0.9$）：$\text{CE} = -\log(0.9) \approx 0.105$
- 目标样本（困难，$p_t=0.3$）：$\text{CE} = -\log(0.3) \approx 1.204$

单看这两个数字，困难样本的损失（1.204）确实比容易样本（0.105）大得多，看起来交叉熵已经在"偏重"困难样本了。**但问题出在数量上**：9900 个容易样本，每个贡献 0.105，总贡献是 $9900\times 0.105\approx 1040$；100 个困难样本，每个贡献 1.204，总贡献只有 $100\times 1.204\approx 120$。**容易样本以数量优势碾压了困难样本对总损失（以及梯度）的贡献**——模型的梯度更新方向，绝大部分是在"进一步巩固已经学得很好的背景判断"上，而不是"想办法把还没学会的目标样本学好"。这正是类别不平衡（class imbalance，训练数据中不同类别样本数量差异悬殊的现象）问题的数学本质：不是交叉熵对每个样本的惩罚不合理，而是**大量样本的小额惩罚，加起来超过了少量样本的大额惩罚**。

## 2. Focal Loss 的解法：给损失加一个随置信度衰减的调制因子

### 2.1 核心思路：不是"数量补偿"，是"难度补偿"

解决类别不平衡的传统思路是**数量补偿**——比如给少数类样本的损失乘上一个更大的权重（这在 [Focal Loss 论文精读](/论文综述/110_Focal_Loss_密集目标检测的焦点损失) 里对应 $\alpha$-balanced 交叉熵，会详细讲）。但这种补偿只看"你属于哪一类"，不看"你这道题到底难不难"——同样是背景类，一个"一看就知道是背景"的样本和一个"长得很像目标、容易被误判的背景"的样本，会被分配一样的权重,这不够精细。

Focal Loss（焦点损失，Lin 等人 2017 年提出，最初用于解决密集目标检测中背景样本远多于目标样本导致的训练失衡问题）换了一个角度：**不看你属于哪一类，只看你这道题模型答得有多自信**。如果模型已经很自信地答对了（$p_t$ 很大），这道题不管是正类还是负类，都该"少算它的账"；如果模型还没答对（$p_t$ 很小），不管是正类还是负类，都该"正常算账甚至加重算账"。这是一种**难度补偿**而非**数量补偿**的思路,后面会看到这套思路完全不需要知道"背景有多少个、目标有多少个"这类统计信息，只需要看每个样本自己的 $p_t$。

### 2.2 Focal Loss 公式

$$
\text{FL}(p_t) = -(1-p_t)^\gamma \log(p_t)
$$

**这个公式在做什么**：在标准交叉熵前面乘一个"自动折扣因子" $(1-p_t)^\gamma$——模型越有把握（$p_t$ 越接近 1），折扣力度越大，这道题的损失被压得越接近 0；模型没把握（$p_t$ 小），折扣接近 1，损失基本不受影响，和标准交叉熵一样重。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $-\log(p_t)$ | **原始交叉熵账单** | 和第一节完全一样的标准惩罚，只是还没打折 |
| $1-p_t$ | **模型的"心虚程度"** | $p_t$ 是模型的信心，$1-p_t$ 就是信心的补数——模型越自信，这个值越小 |
| $(1-p_t)^\gamma$ | **自动折扣因子（调制因子）** | 把"心虚程度"取 $\gamma$ 次方，作为交叉熵的乘法系数。心虚程度小（自信）→折扣因子趋近 0→几乎不计这道题的账；心虚程度大（没把握）→折扣因子趋近 1→正常计账 |
| $\gamma\geq0$ | **聚焦参数（focusing parameter）** | 一个手动设置的超参数，控制"折扣力度对信心变化有多敏感"，下一节详细展开 |
| $-(1-p_t)^\gamma\log(p_t)$ | **打折后的最终账单** | 折扣因子和原始交叉熵账单相乘的结果，就是这个样本最终贡献给总损失的值 |

**用人话读**："每道题先按标准交叉熵算一遍原始扣分，再看模型对这道题有多自信——越自信，这道题的扣分就被打的折扣越狠，几乎归零；越不自信，几乎不打折，正常扣分。"

**为什么用 $(1-p_t)^\gamma$ 这个形式而不是别的衰减函数**：$(1-p_t)$ 天然落在 $[0,1]$ 区间、且在 $p_t\to1$ 时精确趋于 0——不需要额外归一化就能直接当乘法系数用；取幂 $\gamma$ 则提供了一个连续可调的"衰减速度"旋钮，$\gamma$ 越大，同样的置信度下折扣压得越狠（下一节会用具体数字展示这个效果）。这是一个刻意选得很简单的函数形式，作者在论文里也提到"具体用什么函数形式并不关键，只要有类似的性质（自信样本损失被压低）就能起作用"——重要的是"随置信度动态衰减"这个设计思想,不是这个函数本身有什么特殊的数学性质。
:::

### 2.3 用贯穿全文的例子验证效果

回到"背景 $p_t=0.9$、目标 $p_t=0.3$"的场景，取 $\gamma=2$（论文实验中效果最好的默认值）算一下：

- 背景样本：$\text{FL} = -(1-0.9)^2\log(0.9) = -(0.1)^2\times(-0.105) \approx 0.00105$
- 目标样本：$\text{FL} = -(1-0.3)^2\log(0.3) = -(0.7)^2\times(-1.204) \approx 0.590$

对比一下打折前后的比例：背景样本的损失从 0.105 压到 0.00105，缩小到约 **1%**（打了 100 倍的折扣）；目标样本的损失从 1.204 降到 0.590，只缩小到约 **49%**（打了不到 2 倍的折扣）。再看总账：9900 个背景样本总贡献从约 1040 骤降到 $9900\times0.00105\approx 10.4$；100 个目标样本总贡献从 120 略降到 $100\times0.590=59$。**现在困难样本对总损失的贡献（59）已经超过了容易样本的贡献（10.4）**——梯度更新的重心被成功地从"巩固已经学好的背景判断"转移到了"想办法学好还没搞懂的目标样本"，而这一切**完全没有用到"背景有 9900 个、目标有 100 个"这个统计信息**，只是让每个样本根据自己的 $p_t$ 自动决定该占多大权重。

## 3. 聚焦参数 $\gamma$：控制"折扣力度对信心有多敏感"

### 3.1 $\gamma=0$：退化为标准交叉熵

当 $\gamma=0$ 时，$(1-p_t)^0=1$（任何数的 0 次方都是 1），调制因子恒等于 1，Focal Loss 退化成 $\text{FL}(p_t)=-\log(p_t)=\text{CE}(p_t)$——**Focal Loss 是标准交叉熵的严格推广**，标准交叉熵只是它在 $\gamma=0$ 处的一个特例，不是两个互相独立的损失函数。这也说明 Focal Loss 引入的额外风险很低——哪怕 $\gamma$ 调得不合适，最坏情况也不比标准交叉熵差多少（继续增大或调小 $\gamma$ 是连续变化，不会突然跳变到一个完全不同的行为）。

### 3.2 $\gamma$ 越大，折扣衰减越快

$\gamma$ 决定了"随着 $p_t$ 增大，折扣因子衰减的速度"。用之前算过的背景样本（$p_t=0.9$）代入几个不同的 $\gamma$：

| $\gamma$ | 调制因子 $(1-0.9)^\gamma = 0.1^\gamma$ | 相对标准交叉熵的折扣倍数 |
|---|---|---|
| 0 | 1 | 1×（无折扣） |
| 0.5 | $0.1^{0.5}\approx0.316$ | 约 3.2× |
| 1 | 0.1 | 10× |
| 2 | 0.01 | 100× |
| 5 | 0.00001 | 100000× |

可以看到，$\gamma$ 每增大一点，"容易样本"被压低的力度就急剧上升——这是指数关系,不是线性关系。原论文的实验发现 $\gamma=2$ 是效果最好的默认值，且模型对 $\gamma\in[0.5,5]$ 这个范围内的取值都相对稳健（不会因为 $\gamma$ 稍微偏离最优值就性能骤降)。$\gamma$ 太小（比如 0 或 0.5），折扣力度不够,容易样本依然能通过数量优势主导训练;$\gamma$ 太大（比如远超过 5),折扣过猛,可能导致模型在困难样本上也过度压低了正常应该有的梯度信号,收敛变慢。

### 3.3 关键性质：只影响容易样本，几乎不影响困难样本

注意 3.2 节的例子里,调制因子的变化全部发生在 $p_t=0.9$（容易样本）这一侧。如果换成困难样本 $p_t=0.3$，$(1-0.3)^\gamma=0.7^\gamma$ 的变化就温和得多：$\gamma=0$ 时是 1，$\gamma=2$ 时是 0.49，$\gamma=5$ 时是 0.168——衰减速度远不如容易样本那么剧烈。这正是 Focal Loss 设计上最重要的一个性质：**$\gamma$ 这个旋钮，调的主要是"容易样本被压低多少",几乎不动"困难样本原本该有多少损失"**。这也是为什么论文称之为"聚焦"（focusing）——训练的注意力被自动聚焦到了少数困难样本上,而不是靠人工指定权重去强调某个类别。

## 5. $\alpha$-balanced 变体：留个引子

Focal Loss 论文实际实验中用的是一个加了额外权重 $\alpha_t$ 的版本：$\text{FL}(p_t)=-\alpha_t(1-p_t)^\gamma\log(p_t)$——在难度补偿（$(1-p_t)^\gamma$）之外，再叠加一层传统的类别数量补偿（$\alpha_t$）。这个变体、以及论文里 $\alpha$ 和 $\gamma$ 该如何配合调参的实验细节，本文不展开——完整推导和实验数据见 [Focal Loss 论文精读](/论文综述/110_Focal_Loss_密集目标检测的焦点损失) 第三节。这里只需要知道：**难度补偿（本文的核心内容）和数量补偿（$\alpha$）是两件可以叠加、但概念上独立的事**，前者看"这道题答得有多自信"，后者看"这道题属于哪个类别"。

## 6. 代码实现

理解了公式之后,看看它在代码里怎么落地。核心思路是：先照常用 sigmoid 把 logit 转成概率 $p$，算出对应真实标签的 $p_t$，再按公式套上调制因子。下面的实现直接对应本文推导的公式,没有做额外的数值稳定性处理（工程实现通常会用 `binary_cross_entropy_with_logits` 结合 log-sum-exp 技巧来避免数值溢出，但核心逻辑和这里完全一致）：

```python
import torch
import torch.nn.functional as F

def focal_loss(logits: torch.Tensor, targets: torch.Tensor, gamma: float = 2.0) -> torch.Tensor:
    """
    logits: 模型输出的原始分数（未经过 sigmoid），形状 [N]
    targets: 真实标签，取值 0 或 1，形状 [N]
    gamma: 聚焦参数
    """
    p = torch.sigmoid(logits)                     # 转成概率
    p_t = torch.where(targets == 1, p, 1 - p)      # 统一记号：模型对"真实类别"的置信度
    ce_loss = -torch.log(p_t.clamp(min=1e-8))      # 标准交叉熵（clamp 防止 log(0)）
    modulating_factor = (1 - p_t) ** gamma          # 调制因子
    return (modulating_factor * ce_loss).mean()     # 打折后再取平均

# 对应贯穿全文的数值例子
p_t_easy = torch.tensor([0.9])   # 背景样本
p_t_hard = torch.tensor([0.3])   # 目标样本
for gamma in [0, 0.5, 1, 2, 5]:
    factor_easy = (1 - p_t_easy) ** gamma
    factor_hard = (1 - p_t_hard) ** gamma
    print(f"gamma={gamma}: 背景折扣={factor_easy.item():.5f}, 目标折扣={factor_hard.item():.5f}")
```

代码里最关键的一行是 `p_t = torch.where(targets == 1, p, 1 - p)`——它就是第 1.2 节定义的统一记号 $p_t$ 在代码里的直接体现：真实标签是 1 就用 $p$，是 0（对应公式里的 $-1$）就用 $1-p$。之后的 `modulating_factor` 和 `ce_loss` 相乘,就是公式 $-(1-p_t)^\gamma\log(p_t)$ 的逐行翻译，不需要任何额外技巧。

## 7. 常见误区

### ❌ 误区 1："Focal Loss 是给少数类加权重"

不完全对。给类别加权重是 $\alpha$-balanced 交叉熵（数量补偿）做的事。Focal Loss 的核心贡献 $(1-p_t)^\gamma$ 看的是"这道题答得自信不自信"，和这个样本属于哪个类别无关——一个"难分的背景"和一个"难分的目标"，只要 $p_t$ 差不多小，受到的折扣力度就差不多小。

### ❌ 误区 2："$\gamma$ 越大越好"

不对。$\gamma$ 太大会导致模型在训练早期（此时几乎所有样本 $p_t$ 都不高）损失被普遍压得太低，梯度信号整体变弱,收敛速度反而下降。原论文验证了 $\gamma=2$ 附近是效果最好的甜点区间，过大或过小都会掉点。

### ❌ 误区 3："Focal Loss 只能用于目标检测"

Focal Loss 是一个通用的分类损失函数改造思路，只要任务存在"少数困难样本被大量容易样本淹没"的现象（不平衡分类、异常检测、极端多标签分类等），都可以套用这个思路,不局限于目标检测场景。

## 8. 小结

| 概念 | 一句话 |
|------|--------|
| 问题根源 | 大量"容易样本"的小额损失累加起来，超过少量"困难样本"的大额损失，梯度被容易样本主导 |
| $p_t$ | 模型对真实类别的置信度，统一正负类记号的简化写法 |
| 调制因子 $(1-p_t)^\gamma$ | 自动折扣系数，置信度越高折扣越狠，是"难度补偿"而非"数量补偿" |
| 聚焦参数 $\gamma$ | 控制折扣衰减速度的旋钮，$\gamma=0$ 退化为标准交叉熵，常用默认值 2 |
| 和 $\alpha$-balanced 的关系 | 难度补偿（本文）和数量补偿（$\alpha$）可以叠加，是两件独立的事，详见精读 |
