# AWR：优势加权回归

> **一句话概括**：好动作多学、差动作少学——用 advantage 加权的模仿学习。

## 一、动机：为什么需要 AWR

### 1.1 问题背景

假设我们有一批数据（如人类示教），想用来训练一个比数据"平均水平"更好的策略。

**行为克隆（BC）的问题**：对所有数据一视同仁地模仿。如果数据中有好有坏：

| 数据 | BC 的做法 | 期望做法 |
|------|----------|---------|
| 好轨迹（成功） | 等权学习 | 重点学习 |
| 坏轨迹（失败） | 等权学习 | 忽略或少学 |

**PPO 的问题**：需要在线环境交互（可能不可行）。

**AWR 的定位**：结合两者优点——**用已有数据做策略提升，不需要新的环境交互**。

### 1.2 直觉

AWR 的直觉极其简单：

> **给好动作加大学习权重，给差动作降低学习权重。**

"好不好"用 advantage 来衡量：$A(s,a) > 0$ 表示比平均好。

---

## 二、核心公式

### 2.1 AWR 的 Loss Function

普通行为克隆（BC）的 loss 是 $-\mathbb{E}_{(s,a)\sim\mathcal{D}}[\log\pi_\theta(a|s)]$——对所有数据一视同仁。要让"好动作学得更用力、差动作学得更少"，最直接的办法是给每个样本的 log-likelihood 项乘上一个权重，权重由这个动作有多好（advantage）决定：

$$
\mathcal{L}_{\text{AWR}}(\theta) = -\mathbb{E}_{(s,a) \sim \mathcal{D}} \left[ w(s,a) \cdot \log \pi_\theta(a|s) \right]
$$

**这个公式在做什么**：这就是普通的模仿学习 loss，只是给每条数据乘了一个"这个动作有多好"的权重——好动作乘的数大，梯度贡献就大；差动作乘的数接近 0，几乎不参与更新。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $(s,a)\sim\mathcal{D}$ | **训练素材来源** | 从离线数据集里抽一条历史记录（如示教轨迹里的一步），不产生新动作 |
| $\log\pi_\theta(a|s)$ | **模仿信号** | 标准行为克隆项，衡量策略网络当前有多"认可"这个动作 |
| $w(s,a)$ | **学习力度旋钮** | 由下面的权重公式算出的标量，好动作这里的值大，差动作这里的值接近 0 |
| $-\mathbb{E}_{(s,a)\sim\mathcal{D}}[\cdot]$ | **公平考试** | 对数据集里所有样本取平均，再取负号变成待最小化的 loss |

**用人话读**："对每条历史数据算一个'这个动作有多好'的权重，权重大的数据要求策略更用力地模仿，权重小的数据几乎不参与更新。"

**为什么是这个形式**：这本质上就是普通行为克隆 loss 加一个逐样本的权重系数，改动最小、实现最简单——不需要额外训练 Q 网络或修改策略网络结构，只要在 loss 里多乘一项。
:::

权重具体怎么算：

$$
w(s,a) = \frac{1}{Z} \exp\left(\frac{A(s,a)}{\beta}\right)
$$

**这个公式在做什么**：把"这个动作比平均水平好多少"（advantage，可能是负数）翻译成一个永远为正、且可以调节陡峭程度的学习权重。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $A(s,a)=Q(s,a)-V(s)$ | **好坏打分器** | [优势函数](/前置知识/000o_前置知识_Q函数与Value函数)，衡量这个动作比该状态平均水平好多少，可正可负 |
| $\beta>0$ | **挑食程度旋钮** | 温度参数，典型取值 0.05～1.0，控制权重分布的"锐度" |
| $\exp(A/\beta)$ | **正数翻译器** | 把可正可负的 advantage 映射成永远为正的数，advantage 越大权重越高 |
| $Z=\mathbb{E}_{(s,a)\sim\mathcal{D}}[\exp(A(s,a)/\beta)]$ | **归一化器** | 让权重的平均力度保持在正常水平，不整体放大或缩小 loss |

**用人话读**："先把 advantage 除以温度再取指数，得到一个正数当权重；再除以所有样本权重的平均值，让权重整体不偏大偏小。"

**为什么用 $\exp$ 而不是直接用 $A$**：直接用 $A$ 当权重时，$A<0$ 会导致权重为负，含义不明确，还需要额外 clip 处理；$\exp(A/\beta)$ 天然保证权重恒为正、advantage 越大权重越大，且处处连续可微，方便梯度下降。

**代入数字**：假设数据集里有 3 条样本，advantage 分别是 $A = [+2.0, 0, -1.5]$，取 $\beta = 1.0$：
- 未归一化权重：$\exp(2.0) = 7.39$，$\exp(0) = 1.0$，$\exp(-1.5) = 0.22$
- 归一化常数 $Z = (7.39+1.0+0.22)/3 = 2.87$
- 归一化后权重：$w = [7.39/2.87,\ 1.0/2.87,\ 0.22/2.87] = [2.57,\ 0.35,\ 0.08]$

好动作拿到的权重是差动作的约 32 倍。
:::

假设三条样本的 $\log\pi_\theta(a|s) = [-0.5, -0.5, -0.5]$（初始策略对三个动作给的概率一样），代入上面的 loss 公式：

$$
\mathcal{L}_{\text{AWR}} = -\frac{1}{3}\big[2.57\times(-0.5) + 0.35\times(-0.5) + 0.08\times(-0.5)\big] = -\frac{1}{3}\times(-1.5) = 0.5
$$

**这个公式在做什么**：把上面算出的三个权重代入 loss 公式，具体算出这一批数据的 AWR loss 数值，验证"好动作权重大"确实会让梯度更偏向好动作。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $2.57,\ 0.35,\ 0.08$ | **三条样本的权重** | 分别对应好动作、中性动作、差动作，来自上面的归一化结果 |
| $(-0.5)$ | **策略当前的模仿信号** | 三条样本的 $\log\pi_\theta(a|s)$，假设初始策略对三者一视同仁 |
| $-\frac{1}{3}[\cdot]$ | **求平均再翻负号** | 三条样本的加权信号求平均，取负变成待最小化的 loss |

**用人话读**："三条数据的权重乘各自的模仿信号，求平均再翻负号，算出这批数据当前的 loss 是 0.5。"

**为什么这样算有效**：对 loss 求梯度时，权重大的样本（好动作，2.57）贡献的梯度也大，会被优先拉高概率；权重小的样本（差动作，0.08）贡献的梯度几乎可以忽略——这正是"好动作多学、差动作少学"在数学上的体现。
:::

梯度下降会优先增大第一条样本（好动作，权重 2.57）的概率，对第三条样本（差动作，权重仅 0.08）几乎不施加压力——这正是"好动作多学、差动作少学"的效果。

### 2.2 温度 $\beta$ 的作用

$\beta$ 控制"挑食程度"：

| $\beta$ 值 | 效果 | 极端情况 |
|-----------|------|---------|
| $\beta \to \infty$ | 所有权重趋近相等 | 退化为普通 BC |
| $\beta$ 中等 | 好动作权重大，差动作权重小 | **最常用** |
| $\beta \to 0$ | 只学最好的一个动作 | 退化为最优动作选择 |

**代入数字**：三个 $(s,a)$ 对，advantage 分别为 $[+2.0, 0, -1.5]$

$\beta = 1.0$ 时：
- 权重：$[e^2, e^0, e^{-1.5}] = [7.39, 1.0, 0.22]$
- 归一化后：$[0.86, 0.12, 0.02]$ → 好动作占 86% 权重

$\beta = 0.5$ 时：
- 权重：$[e^4, e^0, e^{-3}] = [54.6, 1.0, 0.05]$
- 归一化后：$[0.98, 0.02, 0.00]$ → 好动作占 98% 权重

$\beta$ 越小，越"挑食"。

### 2.3 为什么用 $\exp$ 而不是直接用 $A$

直接用 $A$ 作为权重有问题：
- $A < 0$ 时权重为负 → 含义不明确
- 需要额外处理负值（如 clip 到 0）

$\exp(A/\beta)$ 保证：
- 永远为正数
- advantage 越大权重越大
- 连续且可微

### 2.4 理论基础：KL 约束优化

2.3 节解释了为什么权重要用 $\exp(A/\beta)$ 这个形式，但没说明它从何而来。事实上它不是拍脑袋设计的，而是一个约束优化问题的精确解——如果把"提升策略"表述为"在不偏离原始数据分布太远的前提下最大化 advantage"，数学上唯一的最优解就正好是 AWR 的权重形式：

$$
\max_\pi \mathbb{E}_{(s,a) \sim \mathcal{D}} \left[ \pi(a|s) \cdot A(s,a) \right] \quad \text{s.t.} \quad D_{\text{KL}}(\pi \| \pi_{\text{data}}) \leq \epsilon
$$

**这个公式在做什么**：把"提升策略"表述成一个带约束的优化问题——在不偏离数据分布太远的前提下，最大化期望 advantage。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\max_\pi$ | **求解目标** | 在所有可能的策略 $\pi$ 中找一个最好的 |
| $\mathbb{E}_{(s,a)\sim\mathcal{D}}[\pi(a|s)\cdot A(s,a)]$ | **收益目标** | 数据集里的状态下，新策略给"好动作"分配的概率越高，这个期望值越大 |
| $D_{\text{KL}}(\pi \| \pi_{\text{data}})$ | **安全绳** | 新策略 $\pi$ 与[数据行为策略](/前置知识/000j_前置知识_KL散度与策略约束) $\pi_{\text{data}}$ 之间的 KL 散度，衡量新策略偏离原始数据分布的程度 |
| $\epsilon$ | **安全绳长度** | 允许偏离数据分布的最大幅度（超参数） |
| s.t. $\cdots\leq\epsilon$ | **硬性约束** | subject to，优化时必须满足这条不等式，不能违反 |

**用人话读**："在不允许离数据分布太远的前提下，尽量把概率往 advantage 大的动作上堆。"

**为什么需要 KL 约束**：如果没有这条约束，直接最大化 $\mathbb{E}[\pi(a|s)A(s,a)]$ 会让策略把所有概率质量都堆到 advantage 最大的那个动作上（退化成贪心策略），这在离线数据有限、Q/V 估计本身有误差的情况下非常危险——策略可能"自信地"选择一个实际上被高估的动作。KL 约束强制新策略不能离数据行为太远，起到正则化作用。
:::

用 Lagrange 乘子法求解这个带约束的优化问题，可以证明最优解具有如下形式：

$$
\pi^*(a|s) \propto \pi_{\text{data}}(a|s) \cdot \exp(A(s,a) / \beta)
$$

**这个公式在做什么**：给出上面约束优化问题的解析解——最优策略就是"原始数据分布乘以一个由 advantage 决定的指数权重"，这正好解释了 2.1 节的权重公式从何而来。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\pi^*(a|s)$ | **最优策略** | 上面约束优化问题的解 |
| $\pi_{\text{data}}(a|s)$ | **出发点** | 产生离线数据集 $\mathcal{D}$ 的原始行为策略（人类示教或历史策略），实践中直接用数据本身近似 |
| $\exp(A(s,a)/\beta)$ | **调整力度** | 和 2.1 节权重公式里的指数项完全一致，把 advantage 转成正的放大/缩小系数 |
| $\propto$ | **待归一化标记** | 两边相差一个归一化常数（正是 2.1 节的 $Z$），保证 $\pi^*$ 加起来等于 1 |

**用人话读**："最优策略 = 原始数据分布，乘以一个'这个动作有多好'决定的放大系数，再归一化。"

**为什么是这个形式**：$\epsilon$ 越大表示允许新策略偏离数据分布越远，对应的 Lagrange 乘子 $\beta$ 就越小（约束越松，惩罚力度越低），这与 2.2 节"$\beta$ 越小越挑食"的结论完全吻合——$\beta\to 0$ 时几乎不受 KL 约束，策略可以自由地把概率集中到最优动作上；$\beta\to\infty$ 时约束极严，策略几乎不能偏离 $\pi_{\text{data}}$，退化为普通 BC。
:::

**代入数字**：延续 2.1 节的例子，$\pi_{\text{data}}$ 对三个动作给出的概率（比如均匀）都是 $1/3$，advantage 是 $[+2.0, 0, -1.5]$，$\beta=1$：

$$
\pi^* \propto [1/3 \times e^{2.0},\ 1/3 \times e^{0},\ 1/3 \times e^{-1.5}] = [0.333\times 7.39,\ 0.333,\ 0.333\times0.22] = [2.46,\ 0.33,\ 0.07]
$$

**这个公式在做什么**：把 $\pi_{\text{data}}$ 和 advantage 的具体数值代入最优策略公式，算出这三个动作在最优策略下（归一化前）各自分到的相对权重。

::: details 📐 公式详解（点击展开）

| 数值 | 代表什么 | 算出来说明什么 |
|------|---------|---------------|
| $1/3$ | 三个动作各自的原始行为策略概率 $\pi_{\text{data}}$（均匀分布） | 数据里三个动作被采到的概率一样 |
| $e^{2.0},\ e^{0},\ e^{-1.5}$ | 三个动作各自的 $\exp(A/\beta)$ | 好动作（$A=2.0$）放大约 7.4 倍，中性动作不变，差动作压缩到 0.22 倍 |
| $2.46,\ 0.33,\ 0.07$ | 三个动作各自未归一化的 $\pi^*$ | 好动作明显在数值上遥遥领先 |

**用人话读**："均匀的原始分布乘以各自的放大系数后，好动作的数值遥遥领先，差动作几乎可以忽略。"

**为什么这个结果重要**：归一化后 $\pi^* \approx [0.86, 0.12, 0.02]$——最优策略把 86% 的概率放在最好的那个动作上，这和 2.2 节 $\beta=1.0$ 算出的权重分布是一致的，说明"用 advantage 加权模仿"确实就是在逼近这个约束优化问题的解。
:::

## 三、实现细节

### 3.1 如何计算 Advantage

离线数据中没有在线 Value 估计，有两种做法：

**做法一：Monte Carlo 回报**

离线数据里没有一个在线环境让我们随时查询 $Q(s,a)$，但轨迹是完整记录下来的，所以可以直接把这条轨迹后续实际拿到的奖励加总，作为 $Q(s_t,a_t)$ 的估计，再减去一个 baseline 得到 advantage：

$$
A(s_t, a_t) = \sum_{k=0}^{T-t} \gamma^k r_{t+k} - V(s_t)
$$

**这个公式在做什么**：把这条轨迹从当前时刻往后实际拿到的所有奖励折扣累加，减去"这个状态平均能拿多少"，剩下的就是这个动作的"超额贡献"（advantage）。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\sum_{k=0}^{T-t}\gamma^k r_{t+k}$ | **实际战绩单** | 从 $t$ 时刻到轨迹结束，真实拿到的所有奖励按折扣累加，是对 $Q(s_t,a_t)$ 的 Monte Carlo（蒙特卡洛，直接用完整轨迹的真实回报）估计 |
| $\gamma\in(0,1)$ | **远见折扣** | 折扣因子，典型值 0.99，让远期奖励的权重逐步衰减 |
| $r_{t+k}$ | **每一步的真实奖励** | 记录在离线数据里的标量奖励，$k$ 从 0 累加到轨迹结束 $T-t$ |
| $V(s_t)$ | **及格线** | 状态 $s_t$ 的价值估计（baseline），由一个单独训练的 Value 网络给出 |
| $A(s_t,a_t)$ | **超额贡献** | 实际战绩减去及格线，正数说明这条轨迹表现比该状态平均水平好 |

**用人话读**："把这条轨迹从现在往后实际拿到的所有奖励打折加起来，减去这个状态本来该拿多少分，剩下的正负就是这个动作的超额贡献。"

**为什么是这个形式**：用完整轨迹的真实回报（而不是单步奖励）作为 $Q$ 的估计，是因为离线数据没有额外的环境可以查询，Monte Carlo 回报是唯一不需要 bootstrap、只依赖已记录数据就能算出的无偏估计；代价是方差较大（一条轨迹的随机性会直接反映在估计里），这也是下面"做法二"用 TD 估计来降低方差的动机。
:::

**代入数字**：假设轨迹从 $t$ 时刻开始一共还剩 3 步（$T-t=2$），奖励依次是 $r_t=1, r_{t+1}=0, r_{t+2}=5$（比如最后一步任务成功给了大奖励），$\gamma=0.9$，$V(s_t)=2.0$：

$$
\sum_{k=0}^{2}\gamma^k r_{t+k} = 1\times1 + 0.9\times0 + 0.81\times5 = 1 + 0 + 4.05 = 5.05
$$

**这个公式在做什么**：把三步真实奖励代入折扣累加公式，具体算出这条轨迹从 $t$ 时刻往后的折扣累计回报（也就是 $Q(s_t,a_t)$ 的 Monte Carlo 估计）。

::: details 📐 公式详解（点击展开）

| 数值 | 代表什么 | 算出来说明什么 |
|------|---------|---------------|
| $1\times1,\ 0.9\times0,\ 0.81\times5$ | 三步奖励各自打折后的值 | 越往后的奖励折扣越重（$0.9^0, 0.9^1, 0.9^2$），但最后一步奖励绝对值够大（5），打折后仍贡献 4.05 |
| $5.05$ | 折扣累计回报，即 $Q(s_t,a_t)$ 的估计 | 这条轨迹从 $t$ 时刻往后实际拿到的"总战绩" |

**用人话读**："三步奖励打折加起来，越靠后的折扣越重，但最后一步奖励足够大，加总后这条轨迹的总战绩是 5.05。"

**为什么这个结果重要**：这个 5.05 会在下一步减去 baseline，看看这条轨迹到底比"平均水平"好多少。
:::

$$
A(s_t,a_t) = 5.05 - 2.0 = 3.05
$$

**这个公式在做什么**：把上面算出的折扣累计回报减去 baseline，具体算出这个动作的 advantage 数值。

::: details 📐 公式详解（点击展开）

| 数值 | 代表什么 | 算出来说明什么 |
|------|---------|---------------|
| $5.05$ | 折扣累计回报，即 $Q(s_t,a_t)$ 的估计 | 这条轨迹从 $t$ 时刻往后实际拿到的"总战绩" |
| $2.0$ | baseline $V(s_t)$ | 这个状态"平均水平"该拿多少分 |
| $3.05$ | 最终 advantage | 明显是正的、较大的值，说明这条轨迹表现远好于该状态的平均水平 |

**用人话读**："这条轨迹实际拿了 5.05 分，而这个状态本来平均只该拿 2 分，所以这个动作的超额贡献是 3.05——一个很好的动作。"

**为什么这个结果重要**：这是一个正的、较大的 advantage，说明这个动作所在的轨迹表现远好于该状态的平均水平，在 2.1 节的权重公式里会拿到很高的权重。
:::

**做法二：TD(λ) 估计**

Monte Carlo 回报方差大，且必须等到轨迹结束才能算。另一种做法是训练一个 Value 网络，用自举（bootstrap）的方式只看一步转移就更新价值估计：

$$
V(s_t) \leftarrow r_t + \gamma V(s_{t+1})
$$

**这个公式在做什么**：不用等轨迹跑完，只用"这一步的奖励 + 下一状态的价值估计"就能更新对当前状态价值的判断——这是时序差分（Temporal Difference, TD）估计的核心操作。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $r_t$ | **这一步的真实反馈** | 数据中记录的即时奖励 |
| $\gamma V(s_{t+1})$ | **对未来的估计（而非真实回报）** | 用 Value 网络当前对下一状态 $s_{t+1}$ 的打分，打折后当作"未来大概能拿多少" |
| $r_t+\gamma V(s_{t+1})$ | **TD target** | 拿去当作训练标签，让 $V(s_t)$ 去逼近它 |
| $\leftarrow$ | **更新操作** | 训练时用右边的 TD target 去拟合左边的 Value 网络输出，通常用均方误差实现 |

**用人话读**："不用等轨迹跑完，用'这一步拿到的奖励 + 对下一状态价值的当前估计'就能更新这一状态的价值判断。"

**为什么是这个形式**：TD 估计只依赖"一步真实奖励 + 下一状态的价值估计"而不是整条轨迹，因此方差远小于 Monte Carlo（不受轨迹后续随机性的影响），但代价是引入了偏差（$V(s_{t+1})$ 本身是估计值，可能不准）。这是强化学习中经典的偏差-方差权衡，TD(λ) 的 $\lambda$ 参数就是用来在两种估计之间插值调节的。
:::

**代入数字**：延续上例，$r_t=1$，$\gamma=0.9$，假设 Value 网络当前对 $s_{t+1}$ 的估计是 $V(s_{t+1})=4.0$：

$$
\text{TD target} = 1 + 0.9\times4.0 = 1+3.6 = 4.6
$$

**这个公式在做什么**：把真实奖励和下一状态的价值估计代入，具体算出这一步的 TD target 数值。

::: details 📐 公式详解（点击展开）

| 数值 | 代表什么 | 算出来说明什么 |
|------|---------|---------------|
| $1$ | 即时奖励 $r_t$ | 这一步真实拿到的奖励 |
| $0.9\times4.0=3.6$ | 折扣后的下一状态价值 $\gamma V(s_{t+1})$ | 下一状态"看起来"能拿到的分打了 0.9 折 |
| $4.6$ | TD target | 两者相加，就是 $V(s_t)$ 要去逼近的训练标签 |

**用人话读**："这一步拿到 1 分奖励，下一状态打折后估计还能拿 3.6 分，加起来这一步的目标价值就是 4.6。"

**为什么这个结果重要**：如果 Value 网络当前输出 $V(s_t)=2.0$，那么 TD 误差是 $4.6-2.0=2.6$，训练时会用这个误差（通常是其平方）作为 loss 去更新 Value 网络参数，让 $V(s_t)$ 逐渐逼近 4.6。
:::

然后 $A = r_t + \gamma V(s_{t+1}) - V(s_t)$，也就是把上面算出的 TD target 减去 baseline $V(s_t)$：$A = 4.6 - 2.0 = 2.6$。

### 3.2 训练流程

```python
# AWR 训练伪代码
for epoch in range(num_epochs):
    # 1. 从离线数据采样
    batch = sample(replay_buffer)
    
    # 2. 计算 advantage
    values = value_net(batch.states)
    advantages = batch.returns - values
    
    # 3. 计算权重
    weights = torch.exp(advantages / beta)
    weights = weights / weights.mean()  # 归一化
    
    # 4. 加权 BC loss
    log_probs = policy.log_prob(batch.actions, batch.states)
    loss = -(weights * log_probs).mean()
    
    # 5. 更新策略
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

### 3.3 实际训练技巧

| 技巧 | 作用 |
|------|------|
| 权重 clip（最大值限制） | 防止单个样本主导梯度 |
| 温度退火（$\beta$ 逐渐减小） | 从保守到激进 |
| 多次遍历数据 | 充分利用离线数据 |
| Value 网络预训练 | 更准确的 advantage 估计 |

## 四、AWR vs 其他方法

| 维度 | AWR | PPO | CQL |
|------|-----|-----|-----|
| 在线/离线 | 离线 | 在线 | 离线 |
| 需要环境？ | ❌ | ✅ | ❌ |
| 实现复杂度 | ⭐ | ⭐⭐ | ⭐⭐⭐ |
| 能超越数据？ | ❌ 不能 | ✅ 能 | 有限 |
| 训练稳定性 | ✅ 最稳定 | ⚠️ 可能崩溃 | ✅ 稳定 |
| 核心思想 | 加权模仿 | 约束优化 | Q 值惩罚 |

**AWR 适合的场景**：
- 有一批混合质量的数据（有好有坏）
- 不能做在线交互
- 要求训练稳定
- 不需要超越数据中最好的表现
