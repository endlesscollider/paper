## 🔥 今日亮点

### **The Embodiment Gap in Robot Foundation Models（arXiv:2608.18433）**

这是今天最值得关注的理论性进展。它提出"embodiment gap"概念，指出 RFM 的泛化能力与在具体机器人上实际部署之间存在系统性脱节。当前 VLA 研究普遍遵循 scaling 范式——更多数据、更大模型、更高 benchmark 分数，但很少量化"模型能跑"和"模型能装上机器人跑"之间的额外工作量。这篇工作把这个被忽视的环节显式化为一个可讨论、可比较的研究课题，并指出不同方法在适配不同机器人本体时需要的工作量差异巨大。对领域的推动在于：为 RFM 的评估、选型、投入产出分析提供统一概念框架。若后续能配套给出量化该 gap 的度量工具，其影响力可能堪比当年的 "sim-to-real gap"，成为机器人基础模型领域的标准术语。

### **Revisiting the "Push-T" Robot Manipulation Task with Agentic Robotics（arXiv:2608.18227）**

这是今天最具"反直觉"冲击力的工作。Push-T 是模仿学习领域最具代表性的 benchmark 之一，几乎所有主流解法都依赖人类演示数据。而这篇 short paper 让 Claude Code 以 coding agent 的身份直接被 prompt 编写算法，在整个流程中完全无需演示数据。其核心价值在于重新定义操作策略的获取成本：从"采集大量人类数据"转向"用 LLM 的推理和代码生成能力直接编程"。如果这个方案在 Push-T 上达到接近数据驱动方法的性能，将直接挑战"操作策略必须从数据中学习"的底层假设，也会让 Agentic Robotics 从概念讨论走向可验证的 benchmark 实践。当然，short paper 的篇幅决定了验证还不充分，未来需要更多任务、更多基线的完整对比来支撑这一范式转向。

### **GigaBrain-WBC-0.5: A Behavior World Model for Robust Whole-Body Control with Environment Interaction（arXiv:2608.18234）**

这是人形机器人控制方向最值得跟踪的实质进展。现有全身运动跟踪策略大多在空场景、平地环境中训练，一旦面对地形起伏、障碍物或物体接触就失去鲁棒性，这恰恰是人形机器人走入真实世界最核心的障碍。GigaBrain-WBC-0.5 提出用行为世界模型显式建模环境交互下的动力学变化，让底层控制策略在训练阶段就学会"接触如何改变机器人状态"，而不是在部署时被动应对。这个"预测-补偿"闭环在建模思路上解决了 WBC 长期依赖精确动力学假设的问题。虽然 0.5 版本尚属早期、量化结果未披露，但把世界模型引入 humanoid WBC 的方向具有明确的扩展空间，后续版本如果能给出真机对比实验，将有望成为该方向的重要参考。
