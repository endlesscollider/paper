## 🔥 今日亮点

**1. GaussVLA——VLA 空间推理的一次结构级补强**

今天的论文中，GaussVLA 在问题定位上最精准：VLA 模型的视觉表征长期停留在"扁平 patch token + 标量深度"层面，模型对物体的朝向、空间关系、几何置信度缺乏显式结构。GaussVLA 用 Gaussian 原语替代像素级深度，让策略在动作预测时天然具备表面朝向和空间分布的先验；配合 Mamba 骨干缓解高分辨率视觉 token 的计算问题，这套设计直击 VLA 空间泛化能力弱的本质。如果后续实验能在真实机器人任务上证明几何高斯表征带来的量化提升，它很可能成为 VLA 视觉编码的新范式。

**2. CRESSim-Neo——手术机器人学习的基础设施补位**

机器人学习在过去两年快速发展的一个重要原因，是有 Isaac Lab 这样的 GPU 并行仿真引擎支撑大规模数据生成。而手术机器人领域长期没有对等的基础设施：软组织、流体、缝合线的多物理耦合让仿真极难规模化。CRESSim-Neo 把 position-based simulation 扩展到了刚体 + 可变形组织 + 流体 + 绳索，同时提供批处理渲染、手术传感和 GPU 数据管线，等于把手术机器人训练所需的数据基础设施一次性补齐。从组织牵拉到超声图像合成，这套引擎有望成为未来手术 foundation policy 研究的事实标准平台。

**3. Viability Kernel MPC——让安全不再只是约束，而是状态空间的边界**

工业无人机在复杂环境里的最大问题不是"能不能飞好"，而是"怎样保证绝对安全"。传统 MPC 把安全当作局部硬约束，无法回答"当前状态是否存在可行的安全路径"这一全局问题。这篇工作把 viability theory 引入 MPC，为核心安全状态集合提供理论边界保障，同时保持轴对齐包围盒的低计算开销，在安全性和实时性之间找到了务实平衡。对于做全驱动多旋翼、工业巡检和城市空中交通的研究者而言，这是一个值得持续追踪的控制架构方向。
