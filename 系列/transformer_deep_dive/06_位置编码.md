## 1. 问题：Self-Attention 是"无序"的

[第 4 章](./04_TransformerBlock全拆解)提到了这个问题：Self-Attention 的点积运算 $QK^T$ 与 token 的顺序无关。把输入序列打乱，只要 token 集合不变，Attention 的输出也不变（只是行的顺序跟着变了）。

用一个例子直观感受：

> 输入 A："**猫** 吃 鱼"
> 输入 B："**鱼** 吃 猫"

如果不加位置编码，"猫"在两个句子中产生的 Q、K、V 完全相同（因为 Embedding 只取决于 token 本身）。Attention 无法区分"猫"在句首还是句尾——但这两个句子的含义天差地别。

**位置编码的任务就是：在 Attention 计算之前把"每个 token 在序列中的位置"这个信息注入进去。**

---

## 2. 方案一：正弦位置编码——原版 Transformer 的选择

### 做法

原版"Attention Is All You Need"论文用的是一组固定的（不可训练的）正弦/余弦函数来编码位置：

$$
\text{PE}(pos, 2i) = \sin\!\left(\frac{pos}{10000^{2i/d_{model}}}\right), \quad \text{PE}(pos, 2i+1) = \cos\!\left(\frac{pos}{10000^{2i/d_{model}}}\right)
$$

**这个公式在做什么**：给序列中第 $pos$ 个位置生成一个 $d_{model}$ 维的向量，每两个相邻维度用一对 sin/cos 函数，频率从低到高递增。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $pos$ | 位置索引 | "我是序列中的第几个 token" |
| $i$ | 维度索引 | "这是嵌入向量的第几组维度" |
| $10000^{2i/d_{model}}$ | 频率的分母 | 控制这一维的"振荡频率"——低维变化快（捕捉近距离），高维变化慢（捕捉远距离） |
| $\sin / \cos$ 配对 | 相位正交 | 让模型可以通过线性组合恢复任意相对位置信息 |

**用人话读**："每个位置用一组不同频率的正弦波来编码——低频维度区分远距离位置，高频维度区分近距离位置。"

**为什么用 sin/cos 配对**：$\sin(pos + k)$ 可以写成 $\sin(pos)$ 和 $\cos(pos)$ 的线性组合。这意味着从位置 $pos$ 到位置 $pos + k$ 的偏移可以用一个固定的线性变换表示——模型可以通过线性运算"算出"两个 token 之间的相对距离。
:::

### 优缺点

| 优点 | 缺点 |
|------|------|
| 不需要训练，确定性生成 | 在长序列上效果不如可学习编码 |
| 理论上可外推到任意长度 | 实际外推效果有限 |
| 编码了相对位置信息（通过 sin/cos 线性性质） | 相对位置信息是隐式的，模型需要自己学会利用 |

## 3. 方案二：可学习位置编码——BERT 和 GPT-2 的选择

### 做法

最直接的方案：为每个位置分配一个可学习的向量，和 token Embedding 一样通过训练来优化。

```python
position_embedding = nn.Embedding(max_length, d_model)
# 位置 0 → 一个 d_model 维向量
# 位置 1 → 另一个 d_model 维向量
# ...
```

### 优缺点

| 优点 | 缺点 |
|------|------|
| 简单直接 | 有最大长度限制（max_length 必须预先确定） |
| 对训练长度内的位置表示能力强 | 完全无法外推——超过 max_length 的位置没有对应的 Embedding |
| BERT（512）和 GPT-2（1024）实测效果好 | 对长序列不友好 |

BERT 用 max_length = 512，GPT-2 用 1024。在这些长度范围内，可学习编码的效果不比正弦编码差，甚至略好。但它无法处理训练时没见过的位置。

## 4. 方案三：RoPE 旋转位置编码——现代 LLM 的主流

### 核心思想

RoPE（Rotary Position Embedding，旋转位置编码）不是在 Embedding 上加一个向量，而是**在 Q 和 K 上施加一个依赖位置的旋转**。

关键洞察：**Attention 关心的不是"token 在第几个位置"，而是"两个 token 之间距离多远"。** RoPE 让 $Q_m$ 和 $K_n$ 的点积只取决于它们之间的相对距离 $m - n$，而不是绝对位置 $m$ 和 $n$。

### 做法

把 Q 和 K 向量的每两个相邻维度看成一个 2D 平面上的点，按照位置 $pos$ 旋转一个角度 $\theta_{pos}$：

$$
\text{RoPE}(x, pos) = x \cdot e^{i \cdot pos \cdot \theta}
$$

**这个公式在做什么**：在复数平面上，把向量 $x$ 旋转 $pos \cdot \theta$ 角度。不同维度对使用不同的基础频率 $\theta$（类似正弦编码的多频率设计）。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $x$ | Q 或 K 向量的一对相邻维度 | 被编码前的"裸"特征 |
| $pos \cdot \theta$ | 旋转角度 | 位置越远，旋转越多 |
| $e^{i \cdot \alpha}$ | 旋转算子 | 在 2D 平面上做旋转（$\cos\alpha + i\sin\alpha$） |

**用人话读**："把 Q/K 的每对维度当成 2D 平面上的一个点，按位置旋转——位置不同，旋转角度不同。两个 token 做点积时，旋转角度的差等于它们的相对距离。"

**为什么旋转能编码相对位置**：$Q_m$ 旋转了 $m\theta$，$K_n$ 旋转了 $n\theta$。它们的点积中旋转角只出现 $(m-n)\theta$——绝对位置被消去了，只剩下相对距离。
:::

RoPE 的完整数学推导参见 [RoPE 旋转位置编码](/前置知识/002k_前置知识_RoPE旋转位置编码)。

### 为什么 RoPE 成了主流

| 优势 | 说明 |
|------|------|
| 天然的相对位置编码 | 点积只依赖 $m - n$，不依赖绝对位置 |
| 可外推 | 虽然外推需要额外技巧（如 NTK-aware scaling），但比可学习编码好得多 |
| 无额外参数 | 旋转矩阵是确定性的，不增加模型参数 |
| 高效实现 | 只需要逐元素乘法，不需要额外的矩阵运算 |

Llama、Qwen、Mistral、GPT-NeoX 等主流开源 LLM 全部使用 RoPE。

## 5. 方案四：ALiBi 线性偏置——不需要位置 Embedding

### 核心思想

ALiBi（Attention with Linear Biases）的思路更激进：**完全不修改 Q/K/V 或 Embedding，而是在 Attention 分数上直接加一个线性惩罚——距离越远，惩罚越大。**

$$
\text{score}(i, j) = Q_i K_j^T - m \cdot \lvert i - j \rvert
$$

**这个公式在做什么**：在原始的注意力分数上减去一个和距离成正比的偏置——距离越远的 token，被关注的"成本"越高。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $Q_i K_j^T$ | 语义匹配分数 | "这两个 token 在内容上有多相关" |
| $m \cdot \lvert i - j \rvert$ | 距离惩罚 | "但它们距离太远了，打个折扣" |
| $m$ | 每个 head 的斜率（固定值，不可学习） | 不同 head 使用不同的斜率，有的 head 衰减快（关注局部），有的慢（关注远处） |

**用人话读**："Attention 分数 = 内容相关度 - 距离成本。距离越远，成本越高，需要内容非常相关才能'值回票价'。"

**为什么不同 head 用不同的 m**：让不同 head 有不同的"视野范围"——$m$ 大的 head 只关注近处（局部语法），$m$ 小的 head 可以看远处（长距离依赖）。
:::

### ALiBi vs RoPE

| 维度 | RoPE | ALiBi |
|------|------|-------|
| 作用位置 | Q 和 K 的向量 | Attention 分数 |
| 是否修改嵌入 | 是（旋转 Q/K） | 否（加偏置） |
| 长度外推 | 需要 scaling 技巧 | 天然外推较好 |
| 实现复杂度 | 稍复杂 | 非常简单 |
| 主流使用 | Llama/Qwen/Mistral | BLOOM、部分 MPT |

## 6. 四种方案的对比总结

| 方案 | 编码方式 | 绝对/相对 | 可学习 | 长度外推 | 代表模型 |
|------|---------|----------|--------|---------|---------|
| 正弦编码 | 加到 Embedding 上 | 绝对（隐式相对） | 否 | 理论可以，实际有限 | 原版 Transformer |
| 可学习编码 | 加到 Embedding 上 | 绝对 | 是 | 不行 | BERT, GPT-2 |
| RoPE | 旋转 Q 和 K | 相对 | 否 | 配合 scaling 可以 | Llama, Qwen, Mistral |
| ALiBi | 加到 Attention 分数上 | 相对 | 否 | 天然较好 | BLOOM, MPT |

### 现代趋势

2023 年之后的主流选择是 **RoPE**，配合长度外推技巧（如 YaRN、NTK-aware scaling）可以支持很长的上下文。ALiBi 在某些场景下仍有使用，但 RoPE 在整体性能上更优。

可学习编码因为无法外推，在需要长上下文的现代模型中已经不太使用。正弦编码作为开创性方案仍有历史意义，但在实际应用中已被 RoPE 取代。

---

## 7. 本章小结

| 核心问题 | 答案 |
|---------|------|
| 为什么需要位置编码 | Self-Attention 是置换不变的，不加位置编码无法区分 token 的顺序 |
| 绝对 vs 相对位置 | 相对位置更符合语言特性——"两个词隔了多远"比"这个词在第几位"更有用 |
| 现代主流方案 | RoPE：通过旋转 Q/K 实现相对位置编码，高效、无额外参数、可外推 |
| 外推是什么 | 模型在推理时遇到比训练时更长的序列，位置编码是否仍然有效 |
