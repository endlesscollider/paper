# 机器人系统辨识深度解析：从真机实验到仿真对齐

> 系统辨识不是“把几个参数调到看起来像”，而是用可重复的真机实验估计一组参数，再用独立实验验证这些参数能否预测机器人行为。本系列把这件事拆成一条可执行的工程流水线。

## 读完后你能完成什么

- 列出一台机械臂或人形机器人需要辨识的运动学、动力学、执行器、传感器和接触参数。
- 设计覆盖充分、不会撞机的激励轨迹，采集并清洗位置、速度、电流、力矩和视觉数据。
- 用最小二乘、带约束优化和分阶段辨识估计参数，并知道哪些参数在当前实验中不可辨识。
- 把真机参数写回 URDF、MuJoCo XML 或 Isaac Lab 配置，完成坐标系、关节零位、质量和 PD 的对齐。
- 用轨迹误差、速度误差、接触事件和任务成功率做闭环验证，定位误差来自几何、时延、执行器还是接触模型。

## 贯穿案例

全文使用一台 7 自由度双臂桌面机器人作为例子：每个手臂 7 个旋转关节，腕部有六维力传感器，头部相机和腕部相机通过外参连接到基座坐标系。目标是在仿真中复现“从桌面拿起方块”的真实轨迹。

```mermaid
flowchart LR
    A[真机规格与坐标系] --> B[安全激励实验]
    B --> C[时间同步与数据清洗]
    C --> D[运动学辨识]
    D --> E[执行器与动力学辨识]
    E --> F[接触和传感器参数]
    F --> G[写入 URDF / MuJoCo / Isaac]
    G --> H[独立轨迹验证]
    H -->|残差超阈值| B
    H -->|通过| I[窄范围域随机化与部署]
```

> 图中的回边很重要：辨识不是一次性拟合。验证阶段必须使用未参与拟合的轨迹，残差出现结构性偏差时回到实验设计，而不是直接扩大随机化范围。
