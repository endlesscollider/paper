# 第二章：解析法 IK——几何法与代数法

> 前情提要：[第 1 章](./01_IK问题定义与分类)定义了 IK 问题并给出了四大类方法的全景。本章深入第一类方法——解析法：利用机器人的几何特殊性，直接推导出封闭形式的 IK 解。

## 1. 什么是解析解，为什么它最快

解析法的目标：把 IK 方程 $f(\mathbf{q}) = T_{\text{target}}$ 通过代数变换，
直接写出 $q_i = g_i(\mathbf{x}_{\text{target}})$ 的显式表达式（只包含 $\arctan$、$\arccos$、$\sqrt{}$ 等基本运算，没有迭代）。

**优势**：
- **极快**：微秒级，只需几十次浮点运算
- **精确**：不存在迭代收敛问题，给出精确解（在浮点精度范围内）
- **完整**：可以枚举所有解（如 8 解），由上层逻辑选最优

**限制**：
- 只适用于**特殊构型**的机器人。通用的 6-DOF 机器人不一定有封闭解
- **Pieper 充分条件**：如果 6-DOF 机器人的后三个关节轴交于一点（球形手腕），则一定存在解析解。大多数工业机器人（UR5、KUKA、ABB、Franka 部分模式）满足或接近满足这个条件

## 2. 案例一：2-DOF 平面臂的几何解法

这是最经典的入门案例。两根连杆长度 $l_1$、$l_2$，关节 1 在原点、关节 2 在连杆 1 末端。给定目标 $(x_d, y_d)$，求 $(q_1, q_2)$。

### 2.1 推导过程

**Step 1：用余弦定理求 $q_2$**

目标距原点的距离为 $r = \sqrt{x_d^2 + y_d^2}$。由余弦定理：

$$
r^2 = l_1^2 + l_2^2 + 2l_1 l_2 \cos(q_2)
$$

**这个公式在做什么**：利用"原点→肘→末端"三角形的余弦定理，建立 $q_2$ 和目标距离的关系。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 |
|------|------|
| $r^2 = x_d^2 + y_d^2$ | 目标点到原点的距离平方 |
| $l_1, l_2$ | 两根连杆长度 |
| $q_2$ | 肘关节角度（$q_2=0$ 时两连杆共线伸直） |
| $\cos(q_2)$ | 三角形中"肘角"对边的余弦 |

解出：

$$
\cos(q_2) = \frac{x_d^2 + y_d^2 - l_1^2 - l_2^2}{2 l_1 l_2}
$$

**数值代入**：$l_1 = 1$，$l_2 = 0.5$，目标 $(x_d, y_d) = (1.2, 0.5)$：

$$
\cos(q_2) = \frac{1.2^2 + 0.5^2 - 1^2 - 0.5^2}{2 \cdot 1 \cdot 0.5} = \frac{1.44 + 0.25 - 1 - 0.25}{1} = \frac{0.44}{1} = 0.44
$$

$$
q_2 = \pm\arccos(0.44) = \pm 63.9° \approx \pm 1.115 \text{ rad}
$$

两个解对应"肘上"（$q_2 > 0$）和"肘下"（$q_2 < 0$）。

**为什么是这个形式**：余弦定理直接给出三角形内角与边长的关系。$\pm$ 代表两种几何构型（关于原点→末端连线的镜像）。
:::

**Step 2：用 $\text{atan2}$ 求 $q_1$**

$$
q_1 = \text{atan2}(y_d, x_d) - \text{atan2}(l_2\sin(q_2), \; l_1 + l_2\cos(q_2))
$$

**这个公式在做什么**：先算目标方向角，再减去由 $q_2$ 引起的偏转，得到肩关节角。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 |
|------|------|
| $\text{atan2}(y_d, x_d)$ | 目标点相对原点的方位角 |
| $\text{atan2}(l_2 s_2, l_1 + l_2 c_2)$ | 连杆 2 的存在导致的方向偏移 |

**数值代入**（取 $q_2 = +63.9°$，即 $\sin(q_2) = 0.898$，$\cos(q_2) = 0.44$）：

$$
q_1 = \text{atan2}(0.5, 1.2) - \text{atan2}(0.5 \times 0.898, \; 1 + 0.5 \times 0.44)
$$

$$
= \text{atan2}(0.5, 1.2) - \text{atan2}(0.449, 1.22) = 22.6° - 20.2° = 2.4° \approx 0.042 \text{ rad}
$$

验证：$x = 1\cos(2.4°) + 0.5\cos(2.4° + 63.9°) = 0.999 + 0.5\cos(66.3°) = 0.999 + 0.200 = 1.199 \approx 1.2$ ✓

**为什么是这个形式**：$\text{atan2}$ 比 $\arctan$ 好用——它能正确处理四个象限，不会丢失符号信息。
:::

### 2.2 可达性判断

如果 $\cos(q_2) > 1$ 或 $< -1$，说明目标不可达：

$$
|x_d^2 + y_d^2 - l_1^2 - l_2^2| > 2l_1 l_2 \implies \text{不可达}
$$

**这个公式在做什么**：检查 $\cos(q_2)$ 是否落在 $[-1, 1]$ 范围内——超出即意味着目标点不在工作空间内。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 |
|------|------|
| $x_d^2 + y_d^2$ | 目标点到原点的距离平方 $r^2$ |
| $l_1^2 + l_2^2$ | 两连杆长度平方和（基准项） |
| $2l_1 l_2$ | 余弦定理中的系数，决定 $\cos(q_2)$ 的分母 |
| 不等式成立 | 说明 $|\cos(q_2)| > 1$，无实数解 |

两种不可达情况：
- 太远：$r > l_1 + l_2$（完全伸直也够不着）
- 太近：$r < |l_1 - l_2|$（完全折叠也到不了）

**数值代入**：$l_1 = 1$，$l_2 = 0.5$，目标 $(x_d, y_d) = (2.0, 0)$：

$$
|2.0^2 + 0 - 1 - 0.25| = |4 - 1.25| = 2.75 > 2 \times 1 \times 0.5 = 1 \implies \text{不可达}
$$

验证：$r = 2.0 > l_1 + l_2 = 1.5$，确实够不着。

**为什么是这个形式**：本质上就是要求 $\cos(q_2) \in [-1, 1]$，等价于要求目标距离 $r \in [|l_1 - l_2|, \; l_1 + l_2]$。
:::

### 2.3 Python 实现

核心思路：先判断可达性，再用余弦定理和 atan2 分别计算 $q_2$ 和 $q_1$，返回"肘上"和"肘下"两组解。

```python
import numpy as np

def ik_2dof_planar(x_d, y_d, l1, l2):
    """
    2-DOF 平面臂解析 IK。
    返回两组解 [(q1_elbow_up, q2_elbow_up), (q1_elbow_down, q2_elbow_down)]，
    如果不可达返回空列表。
    """
    r_sq = x_d**2 + y_d**2
    cos_q2 = (r_sq - l1**2 - l2**2) / (2 * l1 * l2)
    
    # 可达性检查
    if abs(cos_q2) > 1.0:
        return []  # 不可达
    
    # q2 的两个解
    q2_up = np.arccos(cos_q2)     # 肘上
    q2_down = -np.arccos(cos_q2)  # 肘下
    
    solutions = []
    for q2 in [q2_up, q2_down]:
        # 对应的 q1
        q1 = np.arctan2(y_d, x_d) - np.arctan2(
            l2 * np.sin(q2), l1 + l2 * np.cos(q2)
        )
        solutions.append((q1, q2))
    
    return solutions

# 测试
sols = ik_2dof_planar(1.2, 0.5, 1.0, 0.5)
for i, (q1, q2) in enumerate(sols):
    print(f"解 {i+1}: q1={np.degrees(q1):.1f}°, q2={np.degrees(q2):.1f}°")
```

输出：`解 1: q1=2.4°, q2=63.9°` 和 `解 2: q1=42.8°, q2=-63.9°`。

## 3. 案例二：6-DOF 球形手腕臂的解析解


大多数工业 6-DOF 机器人（UR5、KUKA IIWA 的等效模式、ABB 系列）满足 **Pieper 条件**：后三个关节的轴线交于一点（球形手腕中心）。这使得位置和姿态的 IK 可以**解耦**。

![6-DOF 球形手腕臂结构示意图：前 3 关节决定位置，后 3 轴交于手腕中心决定姿态](/ik_6dof_spherical_wrist_structure.png)

> 上图展示了一个典型 6-DOF 球形手腕臂的侧视示意图。蓝色框内的前 3 关节（$q_1, q_2, q_3$）控制手腕中心 $\mathbf{p}_w$ 的位置；橙色框内的后 3 关节（$q_4, q_5, q_6$）的轴线**交汇于手腕中心这一点**（图中橙色大圆），它们只改变末端姿态不改变手腕位置。$d_6$ 是手腕中心到末端执行器的固定偏移。

### 3.1 解耦原理

```mermaid
flowchart LR
    A["目标位姿 T_target"] --> B["提取手腕中心位置 p_wrist"]
    B --> C["用前 3 关节解位置 IK → q1, q2, q3"]
    C --> D["用后 3 关节解姿态 IK → q4, q5, q6"]
    D --> E["完整解 (q1,...,q6)"]
```

**关键洞察**：如果后三轴交于一点 $\mathbf{p}_w$（手腕中心），那么 $\mathbf{p}_w$ 的位置**只由前 3 个关节决定**——后 3 个关节只改变姿态不改变手腕位置。因此：

1. 从目标位姿 $T_{\text{target}}$ 反推手腕中心位置：$\mathbf{p}_w = \mathbf{p}_{\text{target}} - d_6 \cdot \mathbf{z}_{\text{target}}$
2. 用前 3 个关节的几何解出 $(q_1, q_2, q_3)$（类似 2-DOF 但在 3D 空间）
3. 前 3 关节确定后，计算 $R_0^3$，然后 $R_3^6 = (R_0^3)^T R_{\text{target}}$
4. 从 $R_3^6$ 中用 ZYZ 欧拉角分解解出 $(q_4, q_5, q_6)$

### 3.2 Step 1：计算手腕中心

![从末端目标位姿反推手腕中心的几何关系](/ik_wrist_center_decoupling.png)

> 上图展示了反推手腕中心的几何关系：已知末端目标位置 $\mathbf{p}_{\text{target}}$ 和末端 $z$ 轴朝向（红色箭头），沿着 $z$ 轴方向往回退 $d_6$ 的距离（紫色虚线箭头），就得到手腕中心 $\mathbf{p}_w$。核心公式：$\mathbf{p}_w = \mathbf{p}_{\text{target}} - d_6 \cdot R\hat{z}$。

$$
\mathbf{p}_w = \mathbf{p}_{\text{target}} - d_6 \cdot R_{\text{target}} \hat{\mathbf{z}}
$$

**这个公式在做什么**：从末端目标位置"往回推"一个手腕到末端的偏移量，得到手腕球心位置。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 |
|------|------|
| $\mathbf{p}_{\text{target}}$ | 末端执行器的目标位置 |
| $d_6$ | 手腕中心到末端的固定偏移距离（由连杆 6 长度决定） |
| $R_{\text{target}} \hat{\mathbf{z}}$ | 目标姿态下末端 $z$ 轴的方向（世界坐标系中） |

**数值代入**：目标 $\mathbf{p}_{\text{target}} = (0.5, 0.2, 0.10)^T$，$d_6 = 0.107$ m（Franka 的末端偏移），目标姿态竖直向下所以 $R_{\text{target}}\hat{\mathbf{z}} = (0, 0, -1)^T$：

$$
\mathbf{p}_w = (0.5, 0.2, 0.10)^T - 0.107 \cdot (0, 0, -1)^T = (0.5, 0.2, 0.207)^T
$$

手腕中心在目标上方 10.7cm 处。

**为什么是这个形式**：末端和手腕中心之间是固定长度的连杆 6，方向由末端姿态决定。所以"末端位置 − 方向 × 长度 = 手腕位置"。
:::

### 3.3 Step 2：位置 IK（前 3 关节）

手腕中心 $\mathbf{p}_w$ 只由 $(q_1, q_2, q_3)$ 决定。对不同的前 3 关节构型，有不同的几何解法。以 UR5 为例（所有关节平行或垂直）：

**$q_1$ 的求解**：

$$
q_1 = \text{atan2}(p_{wy}, p_{wx}) - \text{atan2}(d_2, \pm\sqrt{p_{wx}^2 + p_{wy}^2 - d_2^2})
$$

**这个公式在做什么**：从手腕中心在地面的投影坐标 $(p_{wx}, p_{wy})$，解出底座旋转角 $q_1$，同时补偿肩部的横向偏移 $d_2$。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 | 具体是什么 |
|------|------|-----------|
| $p_{wx}, p_{wy}$ | 手腕中心在世界坐标系 $xy$ 平面的坐标 | 由 Step 1 算出的 $\mathbf{p}_w$ 的前两个分量 |
| $d_2$ | 肩部横向偏移 | UR5 的 DH 参数中连杆 2 的横向偏移，约 0.13585 m |
| $\text{atan2}(y, x)$ | 四象限反正切 | 返回 $(-\pi, \pi]$，解决普通 $\arctan$ 的象限歧义 |
| $\pm$ | 左肩/右肩构型选择 | 取 $+$ 对应一种肘部构型，取 $-$ 对应另一种 |

**数值代入**：假设 $\mathbf{p}_w = (0.4, 0.3, 0.5)^T$，$d_2 = 0.136$ m：

- $\text{atan2}(0.3, 0.4) = 0.6435$ rad（约 $36.87°$）
- $\sqrt{0.4^2 + 0.3^2 - 0.136^2} = \sqrt{0.25 - 0.0185} = \sqrt{0.2315} = 0.4811$
- 取 $+$：$\text{atan2}(0.136, 0.4811) = 0.2753$ rad（约 $15.8°$）
- $q_1 = 0.6435 - 0.2753 = 0.3682$ rad（约 $21.1°$）

**为什么是这个形式**：第一个 $\text{atan2}$ 给出手腕投影的方位角，第二个 $\text{atan2}$ 补偿肩部偏移 $d_2$ 造成的角度偏差（肩关节不在底座正上方，而是横向偏了 $d_2$）。
:::

其中 $d_2$ 是肩部横向偏移。$\pm$ 对应左肩/右肩两种构型。

**$q_2, q_3$ 的求解**：类似 2-DOF 平面臂——把 $\mathbf{p}_w$ 投影到关节 1 确定的平面上，在该平面内用余弦定理和 atan2 求解。

### 3.4 Step 3：姿态 IK（后 3 关节）

前 3 关节确定后，$R_0^3$ 已知。目标的残余旋转为：

$$
R_3^6 = (R_0^3)^T R_{\text{target}}
$$

**这个公式在做什么**：去掉前 3 关节已经"解决"的旋转部分，剩下的就是后 3 关节需要提供的旋转。

::: details 📐 逐符号拆解 + 数值代入（点击展开）
**逐符号拆解**：

| 符号 | 含义 |
|------|------|
| $R_0^3$ | 由 $(q_1, q_2, q_3)$ 确定的前 3 关节的累积旋转 |
| $(R_0^3)^T$ | 其逆（正交矩阵的转置就是逆） |
| $R_{\text{target}}$ | 目标总旋转 |
| $R_3^6$ | 需要由 $(q_4, q_5, q_6)$ 实现的旋转 |

$R_3^6$ 是一个已知的 $3 \times 3$ 矩阵。球形手腕的后 3 关节构成 ZYZ（或其他）欧拉角分解，可以直接从矩阵元素读出 $(q_4, q_5, q_6)$：

$$
q_5 = \text{atan2}(\sqrt{r_{31}^2 + r_{32}^2}, \; r_{33})
$$
$$
q_4 = \text{atan2}(r_{23}/\sin(q_5), \; r_{13}/\sin(q_5))
$$
$$
q_6 = \text{atan2}(r_{32}/\sin(q_5), \; -r_{31}/\sin(q_5))
$$

其中 $r_{ij}$ 是 $R_3^6$ 的第 $i$ 行第 $j$ 列元素。

**数值代入**：假设 $R_3^6 = \begin{bmatrix} 0 & -1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1 \end{bmatrix}$（绕 $z$ 轴转 $90°$）：

- $q_5 = \text{atan2}(\sqrt{0^2 + 0^2}, 1) = \text{atan2}(0, 1) = 0$

$q_5 = 0$ 是奇异构型（万向锁），此时 $q_4$ 和 $q_6$ 不独立，只有 $q_4 + q_6$ 是确定的。

**为什么是这个形式**：欧拉角分解的本质是把旋转矩阵"逆向工程"为三次绕固定轴的旋转。ZYZ 约定对球形手腕最自然（三轴交于一点，每轴依次旋转）。
:::

### 3.5 解的数量

6-DOF 球腕臂的解析 IK 通常给出 **8 个解**（$2^3$ 种组合）：
- 前 3 关节：$q_1$ 左/右肩（×2）、$q_3$ 肘上/肘下（×2）
- 后 3 关节：$q_5$ 手腕翻/不翻（×2）

选解策略：
- 选离当前构型最近的解（最小 $\|\mathbf{q}_{\text{new}} - \mathbf{q}_{\text{current}}\|$）
- 选满足关节限位的解
- 选操纵性最高的解

## 4. 解析法的适用条件

| 条件 | 说明 |
|------|------|
| Pieper 条件 | 后 3 轴交于一点 → 位姿解耦 |
| 关节全为旋转关节 | 移动关节需单独处理 |
| 已知精确 DH 参数 | 参数误差直接导致解不准 |
| 目标在工作空间内 | 解析法不能"近似"——不可达就无解 |

**不满足 Pieper 条件怎么办？**
- 7-DOF 冗余臂（如 Franka）：不能直接用 6-DOF 解析法，但可以固定一个冗余参数（如臂角 $\phi$），退化为 6-DOF 再解析求解。IKFast 就用这种方法
- 一般 6-DOF 无球腕：只能用数值方法。Raghavan-Roth 方法把问题化为 16 次多项式，理论上可求所有解，但实现复杂且数值敏感

## 5. IKFast：自动化解析 IK 生成

OpenRAVE 的 **IKFast** 工具能自动为给定的机器人 URDF 生成 C++ 解析 IK 代码：

1. 输入机器人 URDF + 指定自由参数（对 7-DOF 臂需指定一个自由关节）
2. 自动进行符号推导，找到解析解的代数形式
3. 输出高度优化的 C++ 源码，可编译为 IK 模块

**优势**：微秒级求解、精确、可枚举所有解
**局限**：只对满足特定代数结构的机器人有效；生成的代码巨大且难以修改；不处理约束（关节限位需后处理）

## 6. 总结与对比

| 方面 | 解析法 | 数值法（下一章） |
|------|--------|----------------|
| 速度 | μs 级 | ms 级 |
| 精度 | 精确（浮点精度） | 依赖迭代收敛 |
| 完整性 | 可枚举所有解 | 一次只找一个解 |
| 适用范围 | 特殊构型 | 任意机器人 |
| 处理约束 | 不直接支持 | 可集成约束 |
| 处理冗余 | 需固定自由参数 | 自然处理 |
| 奇异处理 | 有退化解（万向锁） | 可用 DLS 绕过 |
