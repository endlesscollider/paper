# 逆运动学深度解析：从原理到工程实战

> 给定末端执行器的目标位姿，如何找到一组关节角让机器人到达那里？这就是逆运动学（Inverse Kinematics, IK）——机器人控制中最基础也最关键的问题之一。本系列从问题定义出发，逐一深入讲解解析法、雅可比迭代法、优化法、学习法等主流方案，最后对比工程实现。

## 系列简介

IK 是连接"任务空间规划"和"关节空间执行"的桥梁。无论你做的是行为克隆、强化学习、还是经典的运动规划，只要你的 action space 是笛卡尔空间（末端位姿/速度），就需要 IK 来把命令转换为关节指令。

本系列覆盖从经典到现代的所有主流 IK 方案，每种方法都会讲透原理、推导公式、给出代码实现、分析优缺点。读完后你应该能：
- 根据场景选择合适的 IK 方案
- 理解 MoveIt / cuRobo / PyBullet 等工具背后在做什么
- 自己实现一个能用的 IK 求解器

**适合读者**：
- 有基本线代知识（矩阵乘法、特征值、伪逆）的本科生/研究生
- 做 VLA/机器人学习但对底层运动学不够了解的 ML 工程师
- 想深入理解 IK 原理以优化控制性能的机器人工程师

## 全局贯穿例子

整个系列将反复使用同一个场景来演示各种 IK 方法：

> **场景：7-DOF Franka Panda 机械臂抓取桌面物体**
>
> 桌面上有一个红色方块在 $(0.5, 0.2, 0.05)$ 处。目标是让末端夹爪到达方块正上方 5cm 处、保持竖直向下的姿态。这意味着：
> - 目标位置：$(0.5, 0.2, 0.10)$
> - 目标姿态：$z$ 轴竖直向下，即旋转矩阵的第三列为 $(0, 0, -1)^T$
>
> Franka 是 7-DOF，比任务空间的 6-DOF 多一个自由度（冗余），所以 IK 有无穷多解——选哪个解、怎么利用冗余度，就是各种方法的核心区别。

## 学习建议

1. **按顺序读**：第 1 章建立问题认知，第 2-5 章是四大类方法，第 6 章是工程落地
2. **对比着理解**：每种方法都有明确的适用场景和局限。理解"为什么 A 方法在 X 场景下不行"比记住 A 方法的公式更重要
3. **跑代码验证**：每章都有可运行的代码片段，建议实际跑一下，改参数看效果
4. **回看前置知识**：如果某处的公式推导看不懂，大概率是 FK 或雅可比的基础没打牢，回头补
