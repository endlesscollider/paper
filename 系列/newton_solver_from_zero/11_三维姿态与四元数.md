# 三维姿态与四元数

> 系列第 11 章。2D 用一个角度就能描述朝向，3D 需要完整的旋转表示；本章沿用已有四元数前置知识，把它放进刚体解算器状态更新。

## 前情提要

第 10 章的 2D 刚体状态是位置、角度、线速度和角速度。3D 的平动部分几乎不变，真正新增的是姿态表示、三维角速度和惯性张量。旋转矩阵、四元数和角速度的完整比较见[三维旋转表示](/前置知识/006a_前置知识_三维旋转表示_旋转矩阵四元数与角速度)，本章不重复推导四元数代数。

## 一、3D 状态和 2D 状态的对应

| 2D | 3D | 作用 |
|-----|-----|------|
| position: Vec2 | position: vec3 | 质心世界位置 |
| angle: float | rotation: quat | 刚体姿态 |
| velocity: Vec2 | velocity: vec3 | 质心线速度 |
| angular_velocity: float | angular_velocity: vec3 | 世界角速度 |
| inertia: float | inertia: mat3 | 绕质心的惯性张量 |

~~~mermaid
flowchart LR
    A[局部顶点] --> B[四元数姿态 q]
    C[质心位置 x] --> D[世界顶点]
    B --> D
    D --> E[3D 碰撞与接触]
    E --> F[线冲量与角冲量]
    F --> G[线速度与角速度]
    G --> H[姿态更新]
    H --> B
~~~

2D 角度只有一个自由度，3D 刚体姿态有三个自由度。不要把四元数的四个分量误认为四个独立自由度；单位四元数有一个归一化约束，实际仍然表示三维旋转。

## 二、为什么教学实现通常选四元数

旋转矩阵适合变换点，但直接积分矩阵容易失去正交性；欧拉角直观，却会遇到万向节锁和组合顺序问题。单位四元数可以紧凑表示姿态、组合旋转，并在每次更新后归一化保持合法。

这一节只保留接口层的关系。四元数 $q$ 对角速度 $\boldsymbol\omega$ 的姿态导数可写成四元数乘法形式：

$$
\dot q=\frac12\,\Omega(\boldsymbol\omega)q
$$

**这个公式在做什么**：把三维角速度转换成四元数姿态在连续时间中的变化率。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\boldsymbol\omega$ | **瞬时转动** | 刚体此刻绕哪个轴、以多快速度旋转 |
| $\Omega(\boldsymbol\omega)$ | **四元数生成器** | 把三维角速度组织成四元数乘法需要的线性算子 |
| $1/2$ | **旋转参数化系数** | 来自四元数表示旋转时的双覆盖关系 |
| $\dot q$ | **姿态变化率** | 下一步积分要使用的四元数导数 |

**用人话读**：角速度告诉姿态往哪转，四元数运算把这个转动写成四个分量的变化。

**为什么不在本章展开矩阵**：四元数乘法和坐标系约定细节较多，权威解释已经在旋转前置知识中独立完成；本系列重点是它在解算器中的位置。
:::

离散时可以用当前角速度计算一个小旋转，再与旧姿态相乘并归一化。Newton 的刚体积分 kernel 也会在更新角速度后处理 quaternion 姿态，而不是把姿态当作普通位置向量逐分量累加。

## 三、惯性张量为什么要换到世界坐标

3D 刚体的惯性通常在局部坐标系中保存为对角或对称矩阵。物体旋转后，世界坐标下的角速度响应要使用旋转后的惯性：

$$
\mathbf I_\mathrm{world}^{-1}=R(q)\mathbf I_\mathrm{body}^{-1}R(q)^\mathsf T
$$

**这个公式在做什么**：把局部惯性响应旋转到世界坐标，让世界接触冲量能正确改变角速度。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\mathbf I_\mathrm{body}^{-1}$ | **局部转动响应** | 形状在自身坐标系下对角速度变化的抵抗 |
| $R(q)$ | **姿态变换** | 把局部方向搬到世界方向 |
| $R(q)^\mathsf T$ | **反向变换** | 把世界方向投回局部响应再组合 |
| $\mathbf I_\mathrm{world}^{-1}$ | **世界转动响应** | 接触求解器实际使用的逆惯性张量 |

**用人话读**：物体转了以后，“绕世界哪个轴容易转”也变了，所以不能永远使用未旋转的局部惯性。

**为什么 2D 看不明显**：平面刚体只有一个垂直平面的转动自由度，惯性是标量；3D 的三个轴会互相耦合，必须使用矩阵。
:::

## 四、3D 接触冲量和 2D 同构

3D 接触点相对质心向量为 $\mathbf r_A,\mathbf r_B$，接触冲量为 $\mathbf J$。两个刚体的线速度和角速度变化是：

$$
\Delta\mathbf v_A=-m_A^{-1}\mathbf J,\qquad\Delta\boldsymbol\omega_A=-\mathbf I_A^{-1}(\mathbf r_A\times\mathbf J)
$$

**这个公式在做什么**：把世界接触点上的三维冲量同时转换成平动和转动速度变化。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $-m_A^{-1}\mathbf J$ | **线速度响应** | 冲量除以质量，沿相反方向改变 A 的平动 |
| $\mathbf r_A\times\mathbf J$ | **角冲量** | 接触点力臂把线冲量转换成绕质心的转动动量 |
| $\mathbf I_A^{-1}$ | **三维转动响应** | 用世界逆惯性张量得到角速度变化 |
| $\Delta\boldsymbol\omega_A$ | **角速度增量** | 接触求解器写回的旋转状态变化 |

**用人话读**：3D 只是在 2D 的“标量力矩”位置换成了向量叉乘和矩阵响应。

**为什么仍然使用接触点**：无论二维还是三维，偏心接触都会产生旋转；几何位置和动力学响应必须通过力臂连接。
:::

因此，2D 教学版的 `effective_inverse_mass(direction)` 可以升级为 3D 的 $J M^{-1}J^T$。两者计算的都是单位约束冲量造成的约束速度变化；求解器的整体架构没有改变，改变的是状态向量的维度和惯性响应的数据结构。

## 五、Newton 中的状态边界

Newton 的 State 会保存刚体位置、姿态、线速度和角速度数组。积分器读取这些数组，接触求解器写回速度，下一轮再用新速度更新位置和姿态。这个状态边界与[Newton 五件套数据模型](/系列/newton_engine_deep_dive/02_五件套核心数据模型_ModelBuilder_Model_State_Control_Contacts)的“静态 Model、动态 State”划分一致。

学习源码时建议固定问四个问题：

1. 姿态使用什么表示，数组中四个数的顺序是什么
2. 角速度在哪个坐标系中，世界系还是局部系
3. 惯性张量在哪个坐标系中存储，什么时候变换
4. 积分前后的 State 是否双缓冲，是否会读写同一数组

只要这四个问题没回答清楚，看到四元数 kernel 时很容易把坐标系错误误认成求解器不稳定。

## 六、从 2D 教学代码迁移到 3D 的顺序

不要一次性重写碰撞、姿态和求解器。建议按以下顺序：

1. 保留 2D SAT 和顺序冲量，先把 RigidBody 的接口抽象成平动/转动两套速度
2. 用一个已知旋转矩阵验证局部点到世界点的变换
3. 用单位四元数替换矩阵存储，逐步验证旋转组合
4. 加入世界逆惯性张量，测试偏心冲量产生的角速度
5. 最后替换 3D 碰撞检测和接触流形

这样每一步只有一个新变量来源，定位 bug 会比直接接 Newton 三维场景容易得多。

### 网页四元数程序怎么读

程序采用 `[w, x, y, z]` 顺序，初始姿态是单位四元数 `[1, 0, 0, 0]`，并把 `omega = [0.7, 1.1, 0.35]` 解释为世界坐标系中的恒定角速度。每一步先用 Hamilton 乘积计算四元数导数，再用 Euler 前进一步，最后立即归一化。

这里有三个容易误读的实现细节：

| 代码位置 | 实际含义 | 观察方式 |
|----------|----------|----------|
| `multiply([0.0] + omega, q)` | 使用世界系角速度的左乘约定 | 交换乘法顺序会变成另一种坐标系约定 |
| `q = [value / norm ...]` | 把数值漂移后的姿态拉回单位四元数 | 注释掉后，旋转轴长度会逐渐失真 |
| `project(rotate(axis))` | 先把局部轴旋转到世界系，再投影到 2D Canvas | 它只影响显示，不参与姿态积分 |

右上角的 `|q|` 是归一化**之前**的长度，因此会略微偏离 1；写回后的 `q` 已经除以这个长度。这个指标用于暴露“为什么每步要归一化”，不是在声称最终姿态仍非单位长度。

## 总结

2D 到 3D 的核心不是重写所有求解逻辑，而是把三个标量推广成结构化对象：

- 角度 theta -> 四元数姿态 q
- 转动惯量 I -> 世界逆惯性张量
- 标量力矩 -> 三维角冲量 r x J
