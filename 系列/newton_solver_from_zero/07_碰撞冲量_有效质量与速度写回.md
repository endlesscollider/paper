# 碰撞冲量

> 速度级冲量法把一份 Contact 逐步变成两份新速度：接触法线选出禁止穿透的方向，法向相对速度判断双方是否仍在撞近，恢复系数规定碰后的目标，冲量与有效质量负责把旧速度推到这个目标。

## 冲量路线的最小问题

[碰撞求解器概览](./06_碰撞求解器概览_输入输出与响应路线)给出了三条接触响应路线。这里选择速度级冲量，并把问题限制为两个只做平动的动态物体、一个接触和一条接触法线。没有旋转意味着接触点速度等于质心线速度，冲量也不会产生角速度；这些限制让一笔冲量从输入到输出的完整因果链可以单独看清。

**相关阅读**：

- [碰撞求解器概览](./06_碰撞求解器概览_输入输出与响应路线)：检测器、求解器和三条接触响应路线的边界
- [冲量与碰撞响应](/前置知识/007c_前置知识_冲量与碰撞响应)：动量、冲量和恢复系数的物理背景
- [XPBD](./05_XPBD)：逆质量如何分配一笔公共约束修正

贯穿算例是一维直线上的正碰：质量 $m_A=1\,\mathrm{kg}$ 的 A 位于左侧，以 $\mathbf v_A^-=+4\,\mathrm{m/s}$ 向右运动；质量 $m_B=3\,\mathrm{kg}$ 的 B 位于右侧，速度 $\mathbf v_B^-=0$。上标 $-$ 表示碰撞响应读取的旧状态，上标 $+$ 表示响应完成后的新状态。

~~~mermaid

    C --> B["B<br/>质量 3 kg<br/>速度 0"]
~~~

> 检测器只给出接触几何。冲量求解器必须利用这条法线和双方状态，判断是否需要响应并计算两份新速度。

## 接触法线选出禁止穿透的方向

两个表面接触时，切向滑动不会让它们沿法线互相穿过，法向靠近才会。碰撞检测器因此提供单位法线 $\mathbf n$，并约定它从 A 指向 B。这个约定同时决定三个符号：沿 $\mathbf n$ 是 B 离开 A 的正方向，沿 $-\mathbf n$ 是继续靠近的方向，法向冲量的正值应该把双方推开。

本例的 $\mathbf n$ 向右。A 向右运动并不自动表示双方正在分离，因为 B 可能静止或移动得更慢。求解器必须比较两边，而不能只看某一个物体在世界坐标中的速度。

## 相对速度判断是否仍在撞近

求解器当前读取的质心线速度分别是 $\mathbf v_A$ 和 $\mathbf v_B$。先用 B 减 A 得到“站在 A 上观察 B”的相对速度 $\mathbf v_B-\mathbf v_A$，再投影到接触法线，便得到当前法向相对速度 $v_n$：

$$
v_n=\mathbf n\cdot(\mathbf v_B-\mathbf v_A)
$$

**这个公式在做什么**：去掉双方共同平移和不造成法向穿透的切向运动，只保留两接触表面沿分离方向的靠近或远离速度。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\mathbf v_B-\mathbf v_A$ | **B 相对 A 的运动** | 消去两物体共有的平移，只保留双方之间的速度差 |
| $\mathbf n\cdot(\cdot)$ | **法向读取器** | 丢掉不会改变法向间距的切向分量 |
| $v_n<0$ | **继续撞近的信号** | B 相对 A 沿 $-\mathbf n$ 运动，表面间距正在缩短 |
| $v_n\ge0$ | **静止或分离的信号** | 法向间距不再缩短，不应增加新的推开冲量 |

**用人话读**：站在 A 上看 B，只测量 B 沿接触分离方向是在靠近还是离开；负数表示仍在撞近。

**为什么使用 B 减 A**：法线已经规定从 A 指向 B。这个减法顺序让靠近统一为负、分离统一为正；若交换顺序，状态判断和冲量写回的全部符号也必须一起交换。
:::

贯穿算例中，法线向右，A 的速度为 $+4\,\mathrm{m/s}$，B 为 $0$，所以碰撞响应读取的旧法向速度是 $v_n^-=0-4=-4\,\mathrm{m/s}$。负号说明 A 与 B 之间的法向间距每秒缩短 $4\,\mathrm m$，求解器确实需要介入。

下面三种状态共享同一套法线和减法约定。图中的 $\mathbf v_A^p$、$\mathbf v_B^p$ 是接触点速度；纯平动模型中，它们分别等于质心速度 $\mathbf v_A$、$\mathbf v_B$。

<img src="/contact_normal_velocity_cases.png" alt="法向相对速度的靠近、切向滑动与分离三种状态" class="img-wide">

> 紫色箭头表示 B 相对 A 的接触点速度，绿色箭头表示从 A 指向 B 的法线。只有 $v_n<0$ 的状态需要新增法向碰撞冲量；纯切向滑动属于摩擦问题，$v_n>0$ 则说明双方已经分离。

只看世界坐标速度会误判同向运动，因此判断必须使用相对值：

| A 的法向速度 | B 的法向速度 | $v_n=v_B-v_A$ | 接触状态 |
|---------------|---------------|----------------|----------|
| $+4$ | $0$ | $-4$ | A 快速追上 B，正在靠近 |
| $+4$ | $+3$ | $-1$ | 两者同向，但间距仍在缩短 |
| $+4$ | $+5$ | $+1$ | B 离开得更快，已经分离 |

## 恢复系数规定碰后的目标速度

知道“正在靠近”仍不足以计算响应，因为停止靠近和弹回去都能解除碰撞。材料系统用恢复系数 $e\in[0,1]$ 指定保留多少法向反弹。求解器在接触刚形成时保存撞击快照 $v_n^{\mathrm{hit}}<0$；这个输入记录冲量介入前的靠近速度。目标 $v_n^\star$ 是响应完成后希望得到的法向分离速度：

$$
v_n^\star=-e\,v_n^{\mathrm{hit}}
$$

**这个公式在做什么**：先把负的靠近方向翻转成正的分离方向，再用材料输入 $e$ 决定保留多少撞击速度作为反弹。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $v_n^{\mathrm{hit}}<0$ | **撞击前快照** | 保存接触创建时双方靠近得多快，不随求解写回而改变 |
| $-v_n^{\mathrm{hit}}$ | **方向翻转器** | 把朝内的靠近速度变成朝外的分离速度 |
| $e$ | **材料恢复比例** | 用户或材料系统提供的输入，决定保留多少反弹 |
| $v_n^\star$ | **固定速度目标** | 碰撞响应要达到的输出条件，不是当前速度读数 |

**用人话读**：把撞进来的速度反向，再按材料弹性保留其中一部分。

**为什么目标来自撞击快照**：冲量会修改当前法向速度。若每次写回后都用新速度重算目标，求解器就会追逐自己刚刚改变的数值，反弹结果将错误地依赖迭代次数。
:::

恢复系数的三个边界给出了清楚的材料行为：

| $e$ | 本例的目标 $v_n^\star$ | 碰撞含义 |
|-----|--------------------------|----------|
| $0$ | $0\,\mathrm{m/s}$ | 完全非弹性，只停止相对靠近 |
| $0.5$ | $+2\,\mathrm{m/s}$ | 以一半撞击速度分离 |
| $1$ | $+4\,\mathrm{m/s}$ | 理想弹性，分离速度等于接近速度 |

$e=0$ 并不要求两个物体都停在世界坐标中，只要求它们不再沿法线相对靠近。工程实现还常设置低速恢复阈值：很小的撞击速度使用零目标，避免静止堆叠被数值噪声反复弹起。

法向、旧速度和材料参数至此共同确定了两个标量：当前值 $v_n^-$ 与目标值 $v_n^\star$。它们说明碰撞结果应该是什么，却没有说明什么动力学作用能产生这个结果。

## 速度目标留下了一个动力学问题

这次碰撞的旧法向相对速度为 $v_n^-=-4\,\mathrm{m/s}$。完全非弹性碰撞要求目标速度为 $v_n^\star=0$，因此碰撞响应必须让法向相对速度增加 $4\,\mathrm{m/s}$。

这个目标只描述了终点，没有给出到达终点的办法。求解器当然可以把两个速度直接改成相同的数，但“相对速度为零”并不是唯一要满足的物理条件。例如，把 A、B 都改成静止也能消除靠近速度，却会让系统总动量从 $4\,\mathrm{kg\,m/s}$ 凭空变成零。碰撞响应不能只追求目标速度，还必须解释这次速度变化由什么作用产生，并保持内部碰撞前后的总线动量一致。

牛顿力学里，速度变化通过动量变化发生。质量为 $m$ 的物体以速度 $\mathbf v$ 运动时，动量状态是 $\mathbf p=m\mathbf v$；接触力先改变动量，动量变化再除以质量，才得到速度变化。因此，新的求解任务是：

> 找到一笔由接触产生的动量转移，使法向相对速度从 $v_n^-$ 到达 $v_n^\star$，同时不给 A、B 组成的系统凭空增加或减少总动量。

这条因果链说明每一个量来自什么物理需求：

~~~mermaid
flowchart LR
    A["当前速度<br/>v_n^-"] --> B["目标留下速度缺口<br/>v_n* - v_n^-"]
    B --> C["需要改变双方动量"]
    C --> D["碰撞力持续时间极短"]
    D --> E["用冲量概括<br/>整段力的累计效果"]
    E --> F["等大反向写给 A、B<br/>保持总动量"]
    F --> G["按各自质量换成速度变化"]
    G --> H["到达目标速度<br/>v_n*"]
~~~

> 冲量不是一条毫无理由的新规则。它是连接“速度缺口”和“动量守恒”的中间量：目标决定需要改变多少相对速度，冲量负责以符合动力学的方式完成这次改变。

## 碰撞为什么用冲量而不是瞬时力

真实碰撞并非真的在一个数学瞬间完成。两个物体会发生极小形变，接触力在很短的时间内迅速增大再减小。若要直接使用力，求解器就必须解析这段远短于普通仿真时间步的过程，还要知道材料刚度、形变和接触力曲线。对于刚体碰撞，我们真正关心的不是力峰值出现在第几个微秒，而是整段接触总共转移了多少动量。

设碰撞从 $t^-$ 持续到 $t^+$，$F_n(t)\ge0$ 是这段时间内法向接触力的大小，单位法线 $\mathbf n$ 从 A 指向 B。求解器把力在这段时间内的累计量记为法向冲量大小 $j$；$\Delta\mathbf p_A=\mathbf p_A^+-\mathbf p_A^-$ 和 $\Delta\mathbf p_B=\mathbf p_B^+-\mathbf p_B^-$ 分别表示双方碰撞后的动量减去碰撞前的动量。A、B 之间没有第三方提供这笔动量，所以 B 得到多少，A 就必须失去多少：

$$
j=\int_{t^-}^{t^+}F_n(t)\,dt,
\qquad
\Delta\mathbf p_A=-j\mathbf n,
\qquad
\Delta\mathbf p_B=+j\mathbf n
$$

**这个公式在做什么**：把难以在普通时间步内解析的短时碰撞力压缩成一笔动量转移；这笔动量以相反方向写给 A、B，使碰撞能够改变相对速度，却不改变双方的总线动量。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\int_{t^-}^{t^+}F_n(t)\,dt$ | **碰撞全过程的总效果** | 累计力的大小与持续时间，得到求解器真正需要的动量转移量 $j$ |
| $-j\mathbf n$ | **A 交出的动量** | 沿法线反方向减小 A 的动量，使追上 B 的一侧慢下来 |
| $+j\mathbf n$ | **B 收到的动量** | 沿法线正方向增加 B 的动量，使被撞的一侧快起来 |
| $\Delta\mathbf p_A+\Delta\mathbf p_B=0$ | **总动量守恒条件** | 两项相加正好抵消，内部碰撞不会推动 A、B 的整体质心 |

**用人话读**：不追踪碰撞力每一瞬间有多大，只记录它最终从 A 转给 B 多少动量。

**为什么要对力积分**：同样大的力持续时间不同，造成的速度变化不同；只看峰值会丢掉持续时间。积分保留了力曲线的总面积，而动量定理说明这块面积正好等于动量变化。

**为什么两边必须使用同一个 $j$**：这是一次内部动量转移，不是两笔互不相关的外力。若两边冲量大小不同或符号相同，双方动量增量便不能抵消，系统质心会在没有外部冲量时自行加速或减速。
:::

不同的接触力曲线只要积分面积相同，就会产生相同的最终动量变化。刚体解算器因此不必先猜出 $F_n(t)$ 的尖峰形状，而是直接求它的积分 $j$。冲量在这里不是一种额外的物理作用，而是接触力对动量的完整累计效果。

这条关系只解释了冲量为什么出现、为什么成对作用，还没有决定 $j$ 应该多大。冲量过小，两个物体仍会靠近；冲量过大，又会得到超过材料目标的反弹。$j$ 的数值必须由速度缺口和双方质量共同决定。

## 冲量怎样变成双方的速度变化

动量更新已经确定为 A 减去 $j\mathbf n$、B 加上 $j\mathbf n$。速度等于动量除以质量，因此同一笔动量转移在轻物体上产生较大的速度变化，在重物体上产生较小的速度变化。求解器预先保存逆质量 $w_A=1/m_A$、$w_B=1/m_B$ 完成这个换算；静态物体不能被冲量改变速度，所以逆质量直接设为零。

完整的速度状态转移是：

$$
\mathbf v_A^+=\mathbf v_A^- - w_Aj\mathbf n,
\qquad
\mathbf v_B^+=\mathbf v_B^- + w_Bj\mathbf n
$$

**这个公式在做什么**：读取双方旧速度，把一笔大小相等、方向相反的冲量按各自逆质量换算成速度增量，再写回两份新速度。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $-j\mathbf n$ | **A 收到的冲量** | 沿法线反方向改变 A 的动量 |
| $+j\mathbf n$ | **B 收到的冲量** | 沿法线正方向改变 B 的动量 |
| $w_Aj$、$w_Bj$ | **各自速度增量的大小** | 同一冲量除以不同质量，轻物体速度变化更大 |
| $\mathbf v_A^-$、$\mathbf v_B^-$ | **旧状态** | 本次写回发生前求解器实际读取的速度 |
| $\mathbf v_A^+$、$\mathbf v_B^+$ | **更新状态** | 加上本次速度增量后的输出 |

**用人话读**：A 把一笔动量交给 B；动量转移量相同，但质量小的一侧速度变化更大。

**为什么使用逆质量**：速度变化等于动量变化除以质量。把 $1/m$ 预存为逆质量后，动态物体直接相乘，静态物体用零自然关闭响应，不需要在核心更新式里增加特殊分支。
:::

这组更新同时满足两个不变量：冲量方向沿接触法线，不会凭空改变切向速度；A、B 的动量增量之和为零，不会凭空改变两物体的总线动量。

下图把“同一笔冲量”和“不同速度响应”分开表示：

~~~mermaid
flowchart LR
    J["法向冲量 j"] -->|"-j n"| PA["A 的动量变化"]
    J -->|"+j n"| PB["B 的动量变化"]
    PA -->|"乘 w_A"| VA["A 的速度变化"]
    PB -->|"乘 w_B"| VB["B 的速度变化"]
~~~

> 动量变化的大小必须相同，速度变化则由逆质量决定。把两边速度改成同样多只有在质量相同时才成立。

## 有效逆质量合并双方的响应

目标速度给出“法向相对速度需要改变多少”，速度更新式给出“冲量怎样修改每个物体”。把两边的更新代回 $v_n=\mathbf n\cdot(\mathbf v_B-\mathbf v_A)$，一单位冲量带来的总相对速度变化是双方逆质量之和。

本章把 $K_n$ 定义为求解器从两份质量计算出的**法向有效逆质量**，把 $m_{\mathrm{eff}}$ 定义为它的倒数，即**法向有效质量**：

$$
\Delta v_n=(w_A+w_B)j=K_nj,
\qquad
K_n=w_A+w_B,
\qquad
m_{\mathrm{eff}}=\frac{1}{K_n}
$$

**这个公式在做什么**：把 A、B 两条平动响应通道合并成一个标量 $K_n$，用于回答“一单位冲量总共能改变多少法向相对速度”；其倒数则回答“改变一单位法向相对速度需要多少冲量”。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $w_A+w_B$ | **双方响应能力之和** | A 向负法线减速、B 向正法线加速，两种变化都会增大 $v_n$ |
| $K_n$ | **有效逆质量** | 求解器根据当前参与物体计算的系数，单位是 $\mathrm{kg}^{-1}$ |
| $K_nj$ | **冲量造成的速度变化** | 把冲量单位 $\mathrm{kg\,m/s}$ 转换成速度单位 $\mathrm{m/s}$ |
| $1/K_n$ | **有效质量** | 衡量这对物体共同改变相对速度有多困难 |

**用人话读**：一边退、另一边进，两边的速度变化都在帮助解除碰撞，所以要把双方的响应能力相加。

**为什么不能只用较轻物体的质量**：冲量同时写给 A 和 B。漏掉任一侧都会低估单位冲量的效果，随后算出的冲量过大，碰撞结果会比目标弹得更开。
:::

$K_n$ 和 $m_{\mathrm{eff}}$ 都不是用户调节的材料参数。用户可以设置质量和恢复系数；求解器根据参与物体自动计算有效质量。贯穿算例中，$w_A=1$、$w_B=1/3$，所以 $K_n=4/3\,\mathrm{kg}^{-1}$，$m_{\mathrm{eff}}=3/4\,\mathrm{kg}$。

几个边界情况可以检查这个结构：

| 情况 | $K_n$ | 物理结果 |
|------|-------|----------|
| A、B 质量相同 | $2/m$ | 两边速度变化大小相同 |
| B 比 A 重很多 | 约为 $1/m_A$ | B 的速度变化很小，接近静态墙 |
| B 是静态物体 | $w_A+0$ | 全部速度响应由 A 承担 |
| A、B 都是静态物体 | $0$ | 没有可更新的自由度，约束无法靠速度求解 |

## 由速度缺口反求冲量

单接触的首次响应中，碰撞前旧速度就是接触创建时的撞击快照，因此 $v_n^{\mathrm{hit}}=v_n^-$。冲量施加后的法向速度等于旧法向速度加上 $K_nj$。为了让更新值准确到达固定目标 $v_n^\star$，需要把“目标减当前”的速度缺口除以单位冲量的响应能力：

$$
j=\frac{v_n^\star-v_n^-}{K_n}
=-\frac{(1+e)v_n^-}{K_n},
\qquad v_n^-<0
$$

**这个公式在做什么**：测量碰撞前法向速度到目标速度之间的缺口，再用有效质量把这段速度缺口换算成所需的法向冲量。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $v_n^\star-v_n^-$ | **待补速度缺口** | 指定法向相对速度必须增加多少才能达到碰撞目标 |
| $1/K_n$ | **速度到冲量的换算器** | 系统越难推动，同一速度缺口所需冲量越大 |
| $-(1+e)v_n^-$ | **停止量加反弹量** | 一份抵消接近速度，额外的 $e$ 份产生目标分离速度 |
| $j$ | **本次碰撞的输出冲量** | 随后按相反方向写回 A、B |

**用人话读**：需要补多少速度，除以每单位冲量能补多少速度，就是该施加多少冲量。

**为什么 $K_n$ 在分母**：$K_n$ 越大，系统对冲量越敏感，同样的速度缺口只需更小冲量。放到分子会得到相反且错误的趋势。
:::

若碰撞检测时已经有 $v_n^-\ge0$，则令 $j=0$。这个分段条件表达了接触的单边性：接触可以推开物体，不能用负冲量把正在分离的物体拉回来。

## 完全非弹性算例

贯穿算例取 $e=0$，目标为 $v_n^\star=0$。完整状态转移如下：

~~~mermaid
flowchart LR
    A["旧速度<br/>v_A^- = 4<br/>v_B^- = 0"] --> B["相对速度<br/>v_n^- = -4"]
    B --> C["目标速度<br/>v_n* = 0"]
    D["逆质量<br/>w_A = 1<br/>w_B = 1/3"] --> E["K_n = 4/3"]
    C --> F["j = 3 N s"]
    E --> F
    F --> G["新速度<br/>v_A^+ = 1<br/>v_B^+ = 1"]
~~~

> 目标只要求停止相对靠近，因此两个物体最终都以 $+1\,\mathrm{m/s}$ 向右移动，而不是都停在原地。这个结果同时回应了开头的反例：直接把两者设为静止虽然也满足目标速度，却不能保持原有总动量。

逐项计算如下：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 撞击速度 | $v_n^-=v_B^--v_A^-$ | $-4\,\mathrm{m/s}$ |
| 有效逆质量 | $K_n=1+1/3$ | $4/3\,\mathrm{kg}^{-1}$ |
| 所需冲量 | $j=[0-(-4)]/(4/3)$ | $3\,\mathrm{N\,s}$ |
| A 写回 | $v_A^+=4-1\times3$ | $1\,\mathrm{m/s}$ |
| B 写回 | $v_B^+=0+(1/3)\times3$ | $1\,\mathrm{m/s}$ |

结果满足三项检查：碰撞后的相对速度为零；总动量从碰撞前的 $1\times4+3\times0=4\,\mathrm{kg\,m/s}$ 变为碰撞后的 $1\times1+3\times1=4\,\mathrm{kg\,m/s}$；A 的速度变化为 $-3\,\mathrm{m/s}$，B 质量是 A 的三倍，所以速度只变化 $+1\,\mathrm{m/s}$。

如果错误地只使用 A 的逆质量，便会得到 $K_n=1$、$j=4\,\mathrm{N\,s}$。这笔冲量实际写入双方后产生的相对速度变化是 $(4/3)\times4=16/3\,\mathrm{m/s}$，碰撞后 $v_n^+=4/3\,\mathrm{m/s}$，无端产生了反弹。漏掉 B 的响应正是错误来源。

## 最小实现

下面的函数只实现本章已经给出的状态转移：读取旧速度，测量接近状态，计算固定目标与有效逆质量，求出冲量，最后写回双方速度。它不处理穿透位置、多接触迭代、摩擦和旋转，因此每一行都能和上面的算例一一对应。

~~~python
def solve_one_collision(v_a, v_b, mass_a, mass_b, restitution):
    inv_a = 0.0 if mass_a == float("inf") else 1.0 / mass_a
    inv_b = 0.0 if mass_b == float("inf") else 1.0 / mass_b

    normal_speed = v_b - v_a
    if normal_speed >= 0.0:          # 已在分离，接触不能施加拉力
        return v_a, v_b, 0.0

    target_speed = -restitution * normal_speed
    effective_inv_mass = inv_a + inv_b
    if effective_inv_mass == 0.0:   # 两边都不能运动
        return v_a, v_b, 0.0

    impulse = (target_speed - normal_speed) / effective_inv_mass
    new_v_a = v_a - inv_a * impulse
    new_v_b = v_b + inv_b * impulse
    return new_v_a, new_v_b, impulse
~~~

调用 `solve_one_collision(4.0, 0.0, 1.0, 3.0, 0.0)` 应得到 `(1.0, 1.0, 3.0)`。若输出速度不满足 `new_v_b - new_v_a == target_speed`，优先检查法线方向、相对速度的减法顺序和两边冲量符号。

## 总结

单次双物体碰撞的计算链已经闭合：

1. 接触法线选出不能继续穿入的方向，法向相对速度判断双方正在靠近还是分离。
2. 撞击快照和恢复系数确定固定目标 $v_n^\star$，但这个目标只规定碰撞终点。
3. 速度缺口必须通过动量变化来填补；冲量正是短时接触力累计出的动量转移。
4. 同一笔法向冲量以相反方向写给 A、B，保证内部作用不改变总线动量。
5. 逆质量把动量变化转换成双方各自的速度变化，有效逆质量 $K_n=w_A+w_B$ 合并两条响应通道。
6. 速度缺口除以有效逆质量得到所需冲量；若 $v_n^-\ge0$，双方已经没有靠近，不应增加推开冲量。

## 多个接触会互相影响

一对物体只有一个接触时，一笔冲量可以准确命中目标。三个物体排成一列时，一个接触写回速度后会改变另一个接触刚刚使用的速度，单次计算不再足够。[顺序冲量](./08_顺序冲量_从单个接触到接触组)通过保存累计冲量并反复处理各个接触，让相互影响的速度目标逐渐同时成立。
