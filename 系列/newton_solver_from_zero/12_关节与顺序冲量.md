# 关节与顺序冲量

> 系列第 12 章。碰撞约束要求“两个接触点不能沿法线靠近”，关节约束要求“两个锚点保持距离、姿态或相对运动关系”；底层求解框架其实是同一个。

## 前情提要

第 6-8 章的接触约束已经建立四个组件：约束速度、有效质量、累计冲量、顺序迭代；第 10 章又加入完整刚体的旋转响应。本章不另造一套关节算法，而是把关节写成同样的接口。Newton 的铰接体运动学还会进一步使用广义坐标和最大坐标，详见[Newton 铰接体运动学](/系列/newton_engine_deep_dive/03_铰接体运动学_广义坐标与最大坐标)。

- [刚体平面运动](./10_刚体平面运动)：力臂、角速度与完整有效质量
- [雅可比矩阵与微分运动学](/前置知识/003b_前置知识_雅可比矩阵与微分运动学)：约束雅可比的数学背景

## 一、统一视角：约束在禁止什么运动

接触、绳子、距离关节、固定关节都可以先用自然语言描述：

| 约束 | 禁止的运动 |
|------|------------|
| 地面接触 | 接触点沿法线继续进入地面 |
| 距离关节 | 两个锚点之间距离改变 |
| 固定关节 | 两个锚点相对平移和相对旋转 |
| 铰链关节 | 除绕指定轴旋转外的相对运动 |

然后把这句话转换成约束函数 C(q) 或约束速度 Jv。矩阵雅可比的一般概念见[雅可比矩阵与微分运动学](/前置知识/003b_前置知识_雅可比矩阵与微分运动学)；本章只关心它如何接到冲量循环。

~~~mermaid
flowchart LR
    A[关节类型] --> B[选择约束观测量]
    B --> C[计算相对速度]
    C --> D[求有效质量]
    D --> E[更新累计冲量]
    E --> F[施加到双方刚体]
    F --> G[下一轮重新读取]
~~~

## 二、距离关节

两个刚体各有一个局部锚点。把锚点变换到世界坐标后，距离关节要求它们之间的距离保持为 L。这和第 4 章的两粒子绳长约束相同，只是点不再固定在世界中，而是跟着刚体姿态移动。

$$
C(\mathbf q)=\|\mathbf p_B(\mathbf q)-\mathbf p_A(\mathbf q)\|-L
$$

**这个公式在做什么**：记录两个刚体锚点的距离偏离目标长度多少。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $\mathbf p_A(\mathbf q),\mathbf p_B(\mathbf q)$ | **世界锚点** | 局部锚点经过当前姿态和位置变换后的结果 |
| $\|\mathbf p_B-\mathbf p_A\|$ | **当前距离** | 测量关节两端现在相隔多远 |
| $L$ | **目标距离** | 关节允许的长度 |
| $C(\mathbf q)$ | **位置约束误差** | 零表示距离满足 |

**用人话读**：把两个刚体上的标记点当成一根看不见的杆，比较它们现在离得是否正确。

**为什么锚点要随姿态更新**：刚体旋转时，局部锚点的世界位置会改变；如果仍把锚点当成质心，关节就不会产生正确的力矩。
:::

速度求解时，只需要读取两个锚点的相对速度，并把它投影到锚点连线方向。有效质量自动包含平动和转动，代码结构与 Contact 一致。

## 三、固定关节和铰链关节

距离关节只约束一个标量距离。固定关节要约束两个锚点的三个相对平移分量，以及三个相对旋转分量；2D 中则是两个平移分量加一个相对角度。

~~~mermaid
flowchart LR
    A[距离约束] --> B[1 个标量]
    C[2D 固定关节] --> D[2 个平移 + 1 个角度]
    E[3D 固定关节] --> F[3 个平移 + 3 个旋转]
    G[铰链关节] --> H[固定其余相对自由度]
~~~

一个多自由度关节不是调用一次求解器，而是产生多条标量约束行。顺序冲量每次仍然处理一行：当前约束有一个标量速度、一个有效逆质量和一个累计乘子。

## 四、约束雅可比的统一接口

对第 k 条标量约束，定义：

- velocity_error：当前约束速度
- effective_inverse_mass：单位冲量造成的约束速度变化，由质量、转动惯量和约束方向计算，不是调参输入
- target_velocity：本轮希望达到的速度
- accumulated_impulse：已经施加的冲量
- apply_impulse：把冲量增量写回刚体

第 7、10 章已经把法向接触的单位冲量响应记为 $K_n$。这里的下标 $k$ 不再表示“法线”，而表示“第 $k$ 条标量约束行”：$K_k$ 就是这一行的有效逆质量。它不是新物理量，只是把接触的同一个结构推广到距离关节、固定关节和马达。于是顺序冲量的核心仍然只有一个公式：

$$
\Delta\lambda_k=\frac{v_k^\star-v_k}{K_k}
$$

**这个公式在做什么**：对所有关节或接触约束使用同一个局部求解步骤。

::: details 📐 公式详解（点击展开）

| 子表达式 | 它是谁 | 它在干嘛 |
|---------|--------|---------|
| $v_k$ | **第 k 条约束当前速度** | 当前这条约束看到的违反程度 |
| $v_k^\star$ | **目标约束速度** | 接触、马达或关节希望达到的值 |
| $K_k$ | **第 k 条约束的有效逆质量** | 一单位冲量能让该约束速度改变多少；由当前刚体和约束雅可比现算 |
| $\Delta\lambda_k$ | **局部冲量增量** | 本轮对这条约束的修正额度 |

**用人话读**：无论它叫碰撞还是关节，求解器都只问“这条约束现在错多少、推一下要花多少冲量”。

**为什么能统一**：不同约束的差别被封装在“如何观测速度”和“如何施加冲量”里，迭代控制流无需知道几何类型。
:::

## 五、马达约束只是非零目标速度

如果铰链希望以目标角速度 omega_star 旋转，就把相对角速度约束的目标从零改成 omega_star。它不需要重写碰撞求解器，只需要增加一个目标速度来源和最大马达冲量。

这说明约束不仅能表达“不能动”，也能表达“按指定速度动”。关节马达、阻尼和限位都可以在同一接口上增加目标值或冲量上下界。

## 六、约束顺序和收敛

多个关节组成串联机械臂时，一个关节的冲量会改变相邻关节看到的速度。顺序冲量的迭代次数决定误差能传播多远；遍历顺序也会影响每轮的中间状态。

常见策略包括：

| 策略 | 特点 |
|------|------|
| 固定顺序 | 简单、可复现，适合教学 |
| 随机顺序 | 减少某些固定偏差，但不利于复现 |
| 分岛并行 | 只在互不连接的刚体岛内求解 |
| 颜色分组 | 同一颜色的约束可并行，避免写冲突 |

Newton 面向 GPU 时会更重视约束布局、批处理和并行写回；算法思想仍然是局部约束反复修正。更宽的求解器选型可参考[Newton 六种求解器全景对比](/系列/newton_engine_deep_dive/05_六种求解器全景对比_怎么选)。

### 可运行距离关节同时修正什么

旧版网页程序只把粒子位置投影回固定长度，虽然动画像摆锤，却没有实现本章所讲的速度约束。现在的程序把两部分明确分开：先用重力预测位置与速度，再构造一条沿“锚点到粒子”方向的标量约束行。

这条约束行读取两个量：`error = distance - rest_length` 是位置漂移，`radial_speed` 是沿绳方向的速度。`joint_impulse = -(radial_speed + bias)` 先消除径向速度，并用 `bias` 带回一部分位置误差；随后单独执行一次几何清理，把剩余长度误差投影掉。切向速度没有被约束，所以粒子仍能绕锚点摆动。

~~~mermaid
flowchart LR
    A[重力预测<br/>position velocity] --> B[计算距离误差 C]
    B --> C[计算径向速度 Jv]
    C --> D[速度冲量<br/>消除径向运动]
    D --> E[位置清理<br/>消除长度漂移]
    E --> F[保留切向速度<br/>形成摆动]
~~~

> 右上角 `radial v` 是施加本轮冲量前的径向速度，`joint J` 是本步写回的双边关节冲量，`C(x)` 是位置清理后的剩余误差。单条约束行一次就能直接求解；多个相连关节才需要顺序遍历并反复迭代。

## 七、从接触代码抽象出 ConstraintRow

当你真正实现自己的解算器时，可以先不做继承层次，把每条约束压成一组数：

~~~python
class ConstraintRow:
    # 当前测得的约束速度 Jv
    velocity_error: float

    # 接触、马达或稳定化项要求达到的速度
    target_velocity: float

    # 单位冲量对本约束速度的响应，也就是有效逆质量
    effective_inverse_mass: float

    # 单边接触、摩擦和马达使用不同的冲量上下界
    lower_impulse: float
    upper_impulse: float

    # 跨求解迭代保存，实际只施加新旧累计量之差
    accumulated_impulse: float

    # 把本轮冲量增量写回参与刚体的线速度与角速度
    apply_impulse: callable
~~~

接触法向行的下界通常是 0；摩擦行的上下界依赖法向累计量；距离关节可能是双边约束，允许冲量为正或负；马达还要设置力矩上限。求解器只处理“算候选值、裁剪、施加增量”。

这就是从“写一个地面碰撞”迈向“写一个刚体约束解算器”的关键抽象。

## 总结

关节章节的核心结论是：碰撞不是独立的魔法模块，它只是约束系统中的一类单边约束。距离、固定、铰链和马达都可以被拆成 ConstraintRow，再交给同一个顺序冲量循环。
