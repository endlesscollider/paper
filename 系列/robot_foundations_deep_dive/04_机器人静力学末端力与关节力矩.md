# 第 4 章：机器人静力学：末端力与关节力矩

> **本章目标**：理解末端受力时，各关节需要提供多大的力矩来维持平衡——答案就藏在雅可比的转置里。

## 1. 问题：末端受力，关节出多少力矩

机器人抓住一个物体，物体的重力作用在末端执行器上；或者末端主动施加一个力（推、拉、拧）。问题是：**为了维持这个末端力，每个关节的力矩应该是多少？**

这是静力学问题：机器人静止不动，所有加速度为零，只需要平衡外力。

---

## 2. 虚功原理：功率守恒给出答案

设末端受到广义力（力+力矩向量）$\mathbf{F} \in \mathbb{R}^6$，关节力矩向量 $\tau \in \mathbb{R}^n$。

**关键约束**：如果机器人进行一个虚位移，末端产生虚速度 $\delta\mathbf{x}$，关节产生虚速度 $\delta q$，则：
- 末端力做的虚功：$\delta W_{ext} = \mathbf{F}^T \delta\mathbf{x}$
- 关节力矩做的虚功：$\delta W_{int} = \tau^T \delta q$

静力平衡要求这两个功相等（虚功原理）：

$$
\tau^T \delta q = \mathbf{F}^T \delta\mathbf{x}
$$

把雅可比关系 $\delta\mathbf{x} = J(q)\,\delta q$ 代入右边：

$$
\tau^T \delta q = \mathbf{F}^T J(q)\, \delta q
$$

对任意虚位移 $\delta q$ 都成立，因此：

$$
\boxed{\tau = J(q)^T \mathbf{F}}
$$

**用人话读**：末端力 $\mathbf{F}$ 乘以雅可比的转置，就是维持这个末端力所需的关节力矩向量。

---

## 3. 为什么转置而不是逆

雅可比正向是"关节速度 → 末端速度"（$6 \times n$）；转置是"末端力 → 关节力矩"（$n \times 6$）。

这不是巧合，而是**对偶性**：速度空间和力空间天然对偶。把一个量从末端空间"拉回"关节空间，用的是转置，而不是逆。

好处：转置永远存在（不需要矩阵可逆），计算简单，不受奇异性影响（从数学上），只是在奇异位形下关节力矩会无法产生某个方向的末端力（奇异方向的末端力分量被映射到零）。

---

## 4. 数值例子

平面两连杆臂，连杆长 $l_1 = l_2 = 1\,\text{m}$，当前构型 $q_1 = 45°$，$q_2 = 90°$。末端受向下的重力 $F = (0, -10\,\text{N})^T$（忽略角力矩分量）。

先计算当前雅可比（只取线速度部分 $J_v \in \mathbb{R}^{2\times 2}$）：

```
q1=45°, q2=90°
末端位置相对基座：
p = (cos45 + cos135, sin45 + sin135) = (0, 1.414) m

J_v = [[-l1 sin(q1) - l2 sin(q1+q2),  -l2 sin(q1+q2)],
       [ l1 cos(q1) + l2 cos(q1+q2),   l2 cos(q1+q2)]]
    = [[-0.707 - (-0.707), -(-0.707)],
       [ 0.707 + (-0.707),  (-0.707)]]
    = [[ 0,      0.707],
       [ 0,     -0.707]]
```

关节力矩：

```
τ = J_v^T × F = [[0, 0], [0.707, -0.707]] × [0, -10]
  = [0, 0.707×(-10) + (-0.707)×(-10)]  ← 不对，手动展开：
τ1 = 0×0 + 0×(-10) = 0
τ2 = 0.707×0 + (-0.707)×(-10) = 7.07 N·m
```

**解读**：在这个构型下，只有关节 2 需要出力（7.07 N·m）来抵抗末端的重力；关节 1 不需要出力——因为在这个构型下，末端恰好在关节 1 正上方，重力线通过关节 1，关节 1 的力矩臂为零。

---

## 5. 与力控制的关系

$\tau = J^T F$ 是**力控制**（force control）的核心公式。要让机器人末端施加一个预定的力，只需在关节力矩命令里加入 $J^T F_{desired}$。

实际力控制：

$$
\tau = J^T F_{desired} + \tau_{gravity} + \tau_{friction}
$$

补偿重力和摩擦后，剩余力矩用来产生期望末端力。这是力矩控制模式下（见 [H02 电机驱动与控制](/硬件基础/H02_电机驱动与控制)）阻抗控制的基础。

---

## 6. 本章小结

- 虚功原理给出静力学的核心结论：$\tau = J^T \mathbf{F}$，关节力矩 = 雅可比转置 × 末端力。
- 转置来自速度-力对偶性，永远存在，计算简单。
- 奇异位形时，某些方向的末端力无法由关节力矩产生（对偶于"某些方向的末端速度产生不了"）。
- 力控制的核心就是在关节力矩命令里注入 $J^T F_{desired}$。
