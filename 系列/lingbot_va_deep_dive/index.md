# LingBot-VA 代码深度解析：因果视频-动作世界模型的完整实现

> 从"Wan2.2 怎么变成机器人的物理想象引擎"，到"视频流和动作流怎么共享注意力但各走各的 FFN"，再到"KV Cache 如何给机器人装上长程记忆"，完整拆解 Robbyant 开源的 5.3B 参数因果视频-动作世界模型 LingBot-VA 的设计原理与工程实现。

## 系列简介

LingBot-VA 是 Robbyant（蚂蚁技术团队）开源的一个 5.3B 参数视频-动作（Video-Action）世界模型（[arXiv 2601.21998](https://arxiv.org/abs/2601.21998)，[GitHub](https://github.com/robbyant/lingbot-va)）。如果说 [LingBot-VA 论文精读](/论文综述/176_LingBotVA_因果视频动作世界模型) 讲的是"它做了什么、为什么这么做"，那这个系列讲的是"设计到底怎么落地的"——每一个架构选择、每一段数据流、每一个训练技巧背后的工程考量都讲清楚。

它和同团队的 [LingBot-VLA 2.0](/系列/lingbot_vla2_deep_dive/) 走的是完全不同的路线——VLA 让语言模型直接输出动作，VA 让视频模型先"想象"未来再反推动作。两者的实验都在同一批双臂机器人上做，但架构、训练方式、推理逻辑完全不同。

LingBot-VA 有几处很有代表性的设计，也是这个系列的重点：

- **Wan2.2 视频模型作为物理骨架**：不是从头训一个世界模型，而是直接复用 5B 参数的预训练视频生成模型，它已经学会了"物体被推会怎么动"这类物理先验
- **MoT 不对称双流**：视频流 3072 维、动作流 768 维（4 倍小），每层共享注意力但各走各的 FFN——用最少的新参数（350M）获取视频流的全部信息
- **FlexAttention 四类 token 掩码**：训练时把带噪 token 和干净 token 的可见性规则编码成 block mask，用 `torch.compile` 编译成高效 kernel
- **噪声历史增强**：50% 概率给历史视频 token 掺噪，推理时只需半去噪就够——一个训练技巧直接砍掉一半推理计算量
- **KV Cache 长程记忆**：推理时自回归地缓存所有历史 token 的 Key/Value，让机器人"记住"之前发生过什么
- **两阶段去噪 + 异步流水线**：先去噪视频、再去噪动作，配合前向动力学校正避免开环漂移
