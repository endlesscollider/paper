# 代码实战：从图像到 3D 的完整链路

这一章以可运行代码为主，把前面讲过的所有组件串起来。先从最简单的入口 `example.py` 读起，再逐层深入到每个关键的工程细节，最后给出调参指南和常见问题。

---

## 最简入口：example.py

`/home/flageval/projects/TRELLIS.2/example.py` 是最小可用示例，10 行核心代码：

```python
from PIL import Image
from trellis2.pipelines import Trellis2ImageTo3DPipeline

# 加载预训练模型（首次运行会从 Hugging Face 下载权重）
pipeline = Trellis2ImageTo3DPipeline.from_pretrained("microsoft/TRELLIS.2-4B")
pipeline.cuda()

# 读取条件图像（建议去背景，白色或透明背景效果更好）
image = Image.open("input.png").convert("RGBA")

# 运行推理
outputs = pipeline.run(
    image,
    seed=42,
    # 以下为可选参数，使用默认值时可省略
    sparse_structure_sampler_params={"steps": 12, "cfg_strength": 7.5},
    slat_sampler_params={"steps": 12, "cfg_strength": 3.0},
)

# 解码导出
glb = outputs["mesh"].export_glb()   # trimesh.Scene → GLB bytes
with open("output.glb", "wb") as f:
    f.write(glb)
```

`pipeline.run()` 返回一个字典，包含：

| 键 | 类型 | 内容 |
|----|------|------|
| `mesh` | `trimesh.Scene` | 含 PBR 材质的 3D 网格 |
| `gaussian` | `Gaussians` | 3DGS 格式输出（如果配置了高斯解码头） |
| `slat` | `SparseTensor` | 原始生成的 SLat（供进一步编辑） |

## 推理链路的完整调用栈

跟踪 `pipeline.run()` 内部做了什么，对应 `trellis2/pipelines/trellis2_image_to_3d.py`：

```python
def run(self, image, seed=0, **sampler_params):
    # 1. 图像预处理
    image = self.preprocess_image(image)          # 去背景、resize、归一化

    # 2. DINOv3 特征提取（512px）
    cond = self.get_cond([image])                 # → {DINOv3 patch features}

    # 3. 阶段一：稀疏结构生成
    coords = self.sample_sparse_structure(
        cond, **sparse_structure_sampler_params   # 默认 steps=12, cfg=7.5
    )                                             # → 活跃体素坐标 (N, 3)

    # 4. 阶段二：形状 SLat 生成（含级联上采样）
    slat = self.sample_slat(
        cond, coords, **slat_sampler_params       # 默认 steps=12, cfg=3.0
    )                                             # → SparseTensor (N, 32)

    # 5. DINOv3 特征提取（1024px，用于纹理阶段）
    cond_1024 = self.get_cond([image], resolution=1024)

    # 6. 阶段三：纹理 SLat 生成
    tex_slat = self.sample_tex_slat(
        cond_1024, slat, **slat_sampler_params
    )                                             # → SparseTensor (N, 6)

    # 7. 解码
    return self.decode(slat, tex_slat)            # → {"mesh": ..., ...}
```

每个 `sample_*` 函数内部是一个 ODE 求解循环（`torchdiffeq` 或内置 DDIM），在噪声向量上迭代 `steps` 步整流流推理。

## 关键参数调试指南

### steps（采样步数）

默认 12 步。减少到 6–8 步速度快一倍，但细节损失明显。对形状要求高时可以增加到 20–25 步，收益递减明显。纹理阶段比形状阶段对步数更敏感（颜色渐变需要更多步数才准确）。

### cfg_strength（CFG 引导强度）

控制输出和输入图像的相似程度。`sparse_structure_sampler_params` 里默认 7.5，`slat_sampler_params` 里默认 3.0。

- 提高 cfg_strength → 更忠实于图像，但可能过度拟合、损失多样性
- 降低 cfg_strength → 更有创造性，但可能偏离图像

如果输入是有复杂背景的照片（没有去背景），建议把 cfg_strength 稍微降低到 5–6，避免背景干扰几何生成。

### pipeline_type

```python
outputs = pipeline.run(image, pipeline_type="1024_cascade")  # 默认
outputs = pipeline.run(image, pipeline_type="1536_cascade")  # 最高质量
outputs = pipeline.run(image, pipeline_type="512")           # 最快速度
```

`1024_cascade` 在质量和速度之间平衡最好，是推荐的生产用配置。

## 独立纹理化：给自己的网格贴 PBR 材质

如果已有一个网格文件，只需要 TRELLIS.2 的纹理生成能力：

```python
from trellis2.pipelines import Trellis2TexturingPipeline
from PIL import Image

pipeline = Trellis2TexturingPipeline.from_pretrained("microsoft/TRELLIS.2-4B")
pipeline.cuda()

ref_image = Image.open("reference.png").convert("RGBA")

outputs = pipeline.run(
    image=ref_image,
    mesh_path="my_geometry.glb",   # 已有网格
    seed=42,
    slat_sampler_params={"steps": 12, "cfg_strength": 3.0},
)

glb = outputs["mesh"].export_glb()
```

pipeline 会把 `my_geometry.glb` 体素化为 O-Voxel，跳过阶段一和二，直接运行阶段三的纹理 SLat 生成。适合场景：

- 有 3D 扫描数据，只缺材质
- 在 Blender/CAD 里建好了模型，想用图像参考快速生成材质风格
- 对同一个几何体生成多种材质变体

## 显存要求与优化

4B 参数的 TRELLIS.2 对显存要求较高。弹性显存管理（`ElasticSLatFlowModel`）会根据可用显存自动调整：

| GPU 显存 | 推荐配置 | 备注 |
|---------|---------|------|
| 80GB（A100） | `1024_cascade` | 全速，不需要梯度检查点 |
| 40GB（A100） | `1024_cascade` | 弹性模式自动开启，稍慢 |
| 24GB（RTX 3090/4090） | `512` | 只能跑低分辨率 |
| <20GB | 不支持 | 需要 CPU offloading（未实装） |

显存不足时的现象：CUDA OOM 错误，通常出现在阶段二高分辨率精细采样步骤。解决方式：降低 `pipeline_type` 或减少 `steps`。

## 已知限制

**镜面/高透明物体**：玻璃杯、镜面金属表面在 DINOv3 特征里的响应很弱（反射光线破坏了跨视角一致性），生成结果的材质准确性比漫反射表面差。

**极细长结构**：发丝、天线、钢丝在 1024³ 体素下可能不满一个体素宽，导致几何断裂。

**多物体场景**：TRELLIS.2 针对单个孤立物体训练，输入包含多个物体或复杂背景时，生成的几何可能把背景也建进去。建议预先去背景（`rembg` 或类似工具）。

**条件图像视角依赖**：生成的几何以输入图像的视角为主，图像里看不到的部分（背面、内部）由模型"猜测"补全，可能与真实形状不符。

## 系列总结

经过九章的拆解，TRELLIS.2 的每一层设计都有了清晰的来龙去脉：

- **O-Voxel** 解决了等值面方法无法表示任意拓扑的根本问题
- **SLat** 把稀疏体素格式和连续潜向量结合，支持区域级编辑和多格式解码
- **SC-VAE** 用 DINOv3 的 3D 感知特征绕过昂贵的 per-asset 3D 优化
- **Rectified Flow Transformer** 在稀疏体素上高效运行生成，少步采样质量超过 DDPM
- **三阶段流水线**（结构→形状→纹理）把几何和材质的生成分开，支持独立的纹理化应用
- **级联上采样**在不成倍增加计算量的前提下，把输出分辨率推到 1024/1536

这套体系的最终目的是让"给一张图片，得到一个可以直接用于游戏引擎的带材质 3D 资产"成为一个 10 秒内可以跑完的自动化流程。
